# CDM 业务模型参考与内部适配

本目录先解决两件事：**以行业模型确定业务对象怎样组织；确定哪些实体、属性和关系值得采用。** 内部表、字段、码值及加工逻辑的适配另行开展。

这是独立资料目录，可以整体迁出。它不依赖 semantic-workflow，不接入 data-graph 构建，也未安装 CDM 或 Legend 运行环境。

## 本次已经落地什么

- 固定参考基线为 **CDM 7.0.0**，对应官方发布提交 `a6ffe777bc12ef3d289579cb3a86d1cbffea63d2`。它是官方明确标识的生产发布版；这里选择稳定基线，不宣称它永远是最新版本。
- 保存 22 份上游原文件：13 份模型定义/函数文件、6 份文档、README、LICENSE、NOTICE，总计 772,800 字节；来源和 SHA-256 见 manifest。
- 中文整理涵盖公共对象、经济条款与产品组合、交易/事件/状态、法律协议和数据映射职责。
- 核实 4 个金融机构案例；具体状态以公告日期为准，没有把协会成员或试点名单当作生产客户名单。

## 当前采用判断

**采用 CDM 的组织方法，并逐项选择适用定义，是有实际机构先例的路线。** 高盛的产品模型与消费模型映射、BNP 的内部数据转 CDM，直接支持这条路径；JPMorganChase 和 JSCC 则提供明确的运行案例，详见案例文件。

CDM 定义是外部基准。内部含义与它一致时采用；存在实质差异时保留差异并说明对应关系。这里的采用清单仍是建议，不代表内部映射已经确认。

业务阅读入口仍可按期权、互换、期货等组织。底层的公共定义由多个入口共同引用，目录不必复制成 CDM 的命名空间树。
