# 实验：多表起点的上游范围

本模块只消费已发布图谱，不改变发布器、图数据库、既有全域查询或血缘遍历。前端模块位于 `packages/data-graph-ui/src/experimental-upstream-scope`。默认未应用范围，首个输入预填 `%t01\_%`。

## 使用与边界

在左侧“上游范围 · 实验”输入起点表/LIKE 模式，每行一条，点击“应用范围”。多个模式取并集。无点号时匹配短表名，有点号时匹配完整表名；大小写不敏感，`%` 匹配任意字符，`_` 匹配单个字符，反斜线转义下一个字符。因此 `%t01\_%` 匹配包含字面量 `t01_` 的短表名。同名但不同物理节点保留各自身份。

取所有匹配起点及表级输入输出关系可达的上游，按节点 ID 去重并处理循环。只跟随当前表的生产任务及该任务读取的表，不加入任务的其他输出或上游表的其他消费者。它是 TABLE_IO 范围，不代表字段、分区、运行实例的精确因果。

范围算完后再应用隐藏表规则：隐藏中间表不会阻断上游收集；它的直接关系从显示中移除，不补跨节点连线。区域表数与任务数由范围内读写组合重新聚合。点击区域只列出范围内且未隐藏的表。点击具体表进入原有血缘探索，原有血缘查询行为不受实验约束；界面明确提示已进入独立探索。

“退出范围”恢复原全域骨架。实验范围只保留当前页面会话，刷新退出，不写入探索专题和 localStorage。

## 计算完整性

限制：最多 25 个模式、1000 个起点、20000 张表、100000 个读写组合、30 秒计算检查。超限报错，不返回冒充完整范围的前缀。循环通过已访问表集合终止。开始与结束校验图谱版本一致。范围收集不设深度上限。

收集完成与画布完整展示分别标记：画布最多展示 100 个区域、150 条区域关系，超过会明确标记画布截断。`scope.status=COMPLETE` 仅指已发布 TABLE_IO 图的上游收集完成。端点使用最多 4 份按图谱版本和模式区分的进程内缓存，隐藏规则仅影响后续投影。

## 拆卸

快速停用前端入口：将前端模块的 `UPSTREAM_SCOPE_ENABLED` 改为 `false`。

彻底移除只涉及：

1. `App.tsx` 中该模块的 import、范围状态、面板/状态提示、overview/region 查询分支和范围标题。恢复走原 `api.overview` / `api.region`。
2. `service.ts` 中该模块的 import 和 `/api/experimental/upstream-scope` 路由分支。
3. 删除前后端两个 `experimental-upstream-scope` 目录及 `tests/experimental-upstream-scope.test.ts`。

既有隐藏模块、overview.ts、store.ts、发布合同和图数据无需修改。

## 接口

`GET /api/experimental/upstream-scope` 参数：`patterns`（JSON 字符串数组，必填）、`hiddenTables`（JSON 数组，可选）、`schema`（可选，有值时返回区域成员）、`offset`（成员分页偏移）。区域页固定 50 条。全部参数经校验，模式编译为转义后的正则并通过参数传入查询。
