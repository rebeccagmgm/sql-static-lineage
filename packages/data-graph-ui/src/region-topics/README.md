# 区域关联调度主题

查看 schema 区域成员后显示默认折叠的“关联调度主题”。展开时才调用 `/api/region-topics`，仅展示主题名称；技术主题名作为悬浮提示。不增加画布节点、连线或卡片统计。

关联口径：当前 schema 中未隐藏的表 ← 写入任务 → 本地调度目录中的实际主题。实验范围开启时只纳入范围内物理表。读取任务不混入；主题缺失或超限明确提示不完整，不猜主题与 schema 一一对应。

最多读取 5000 个不同写入任务、显示 100 个不同主题。图谱版本变化拒绝旧结果；切换区域或规则取消旧请求。主题名称来自已有 SchedulerTaskNameResolver。

App.tsx 只有组件导入与区域列表中的挂载点；后端为独立 region-topics.ts 和一条 service.ts 路由。主题详情下钻暂未实现。

卡片通过 CardTopics 批量动态查询，按当前范围及隐藏规则内的写入任务关联调度主题，按覆盖的去重物理表数降序展示前两个；同一表可涉及多个主题。没有固定 schema 业务名称映射。主题描述来自本地调度主题目录，不代表已确认的业务归属。
