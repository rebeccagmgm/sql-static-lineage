# 节点逐步隐藏

## 全局表规则

左侧“全局隐藏表”支持动态添加 `schema.table`、恢复单张表和清空规则。首次使用预置 `dm_index_n.grp_def`；清空后不会重新加回。按完整表名匹配所有同名来源，不做模糊匹配，不递归隐藏上下游表或任务。

规则保存在当前浏览器的 localStorage，适用于全域骨架、区域表列表和表/字段血缘画布，刷新保留。它不是服务器共享配置，不影响其他浏览器、图数据库、发布产物或原始查询证据。

全域骨架及区域列表通过 `hiddenTables` JSON 数组查询参数，在服务端聚合、排序和分页之前排除表及其入出关系。区域里其他表保留，区域没有剩余表时才消失。跨区域关系的任务数可能下降，也可能因同任务还有其他表而不变。血缘画布在既有显示投影上隐藏表卡及其入出边，保留原有遍历语义。

`GlobalVisibility.tsx` 管理规则与左侧面板，`global.ts` 负责存储读取和画布投影；服务端的 `asset-graph/node-visibility.ts` 集中负责规则校验与查询条件。规则限定最多 100 个完整表名。

## 当前画布逐步隐藏

血缘画布顶部点击“选择隐藏”，逐个点击节点卡片进行选择或取消，再点击“隐藏所选”。可以继续选择下一批；“撤销上次隐藏”按批次回退，“恢复全部”恢复所有手动隐藏的节点。

选择模式拦截卡片点击，结束选择后恢复原有节点探索和字段点击行为。隐藏节点时同时隐藏关联连线，不生成跨越隐藏节点的替代边，也不修改查询结果和血缘证据。字段滚动导致的连线隐藏仍独立生效。

状态仅保留在当前画布会话中，新的查询结果、离开血缘画布或刷新页面会重置；暂不保存到探索专题。恢复节点保留原布局。

- `state.ts`：纯函数，负责分批隐藏记录与显示投影。
- `NodeVisibility.tsx`：选择模式、工具栏和会话生命周期。
- `style.css`：模块样式。
- `App.tsx` 仅通过 render prop 接入，继续负责原有 React Flow 与探索行为。
