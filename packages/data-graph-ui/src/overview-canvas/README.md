# 骨架画布实验

全域和上游筛选范围共用 OverviewCanvas，颜色沿用原页面的浅色。只消费 OverviewResult，不修改节点、关系、统计、隐藏规则或范围计算。

## 布局与关系

按已有阶段分块，每块内部多列排列；将块按大小装入横向区域，避免同层几十个节点排成一条竖线。未分类保持原标签。块的位置不代表上下游方向。

总览保留全部返回区域，默认收起连线。单击区域显示并突出直接入出关系与任务数，其他区域淡化；“全部连线”可恢复所有返回关系。“取消突出”回到总览。连线箭头保留原方向，不补连接、不合并业务节点。

“全图”适配全部卡片，“阅读大小”放大查看，“展开画布”使用窗口空间。点击卡片里的成员按钮自动收起展开画布，显示原有区域成员列表。数据变化后重新布局，截断提示保留。

## 模块边界

App.tsx 仅懒加载该组件并传入 overview 和 onOpenRegion。布局、样式、交互均在本目录。已移除 Dagre 依赖。替换组件调用即可切换或拆卸；后端、隐藏和上游范围模块不需要修改。

大量节点同时适配小屏幕时文字仍会缩小，可用阅读大小与平移；紧凑总览不保证打开全部连线后零交叉。

选中区域后，蓝色为流入、橙色为流出，同时在线条标签与工具栏中标明方向；取消选中恢复普通样式。卡片层级高于连线，确保成员按钮可点击。
