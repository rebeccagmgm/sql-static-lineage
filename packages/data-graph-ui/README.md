# data-graph-ui

切换到字段血缘时，立即清空旧加工依据、SQL 和画布选中项，再加载字段列表；切换前尚未返回的详情请求不得重新填充面板。“分析此调度”与下拉框入口采用相同的详情清理行为。

任务内的“字段怎么加工”默认按当前字段的已记录取值依赖展示主线，保留临时表、中间表、分支及不同写入。卡片显示字段、加工方式、表达式摘要和 SQL 语句序号；查看中间字段时称为“当前查看终点”，不暗示它是任务最终目标。关联键自己的取值链不会混入所选字段主线；“显示关联与过滤关系”可恢复接口返回的全部阶段和关系。条件、待确认依据与内部身份默认折叠，原始状态和证据不变。加工方式只做简单表达式展示分类，完整 SQL 仍可在步骤详情查看。

字段血缘展示“物理表字段 → 调度 → 物理表字段”。表卡按完整物理身份组织，不按读写任务或查询深度拆成重复卡片；身份不足时保留证据分组，不凭同名表合并。表卡只展示表与字段，读写调度、写入实例和范围在连线及右侧证据中查看。不同范围的原始字段端点、映射和停止边界完整保留，不因表卡合并产生新血缘。

点击字段继续追溯时，已确认接续的读写别名按方向选择入口：向上沿写入端，向下沿读取端，避免重复查询。已选字段数量按物理字段计数。重复查询返回同一写入时，即便响应深度不同，也只保留一个显示归属；读取证据仍按原始身份可查。每条字段映射保留独立调度端口，高亮依据原始字段路径；仅有明确常量证据的无输入字段补画产出调度，不从缺边推断生成字段。

从任务进入普通表血缘时，每一跳只连接直接调度邻居中有对应读写证据的任务。共享表卡保留当前任务的展开归属，保存入口、重新打开和追加分支均沿用该标识；表说明与字段列表仍读取原物理表。任务详情中的“配置中的调度上下游”可查看没有当前表读写证据的配置邻居，不将其补成表血缘边。该改动不涉及 Facts 生成和显式分区查询。

“定位任务或表”：纯数字或 `task:数字` 精确匹配任务 ID，并保留集群筛选；其他文本继续模糊搜索。任务结果名称来自调度目录，缺失时显示“名称未收录”，不使用旧描述字段充当名称。

浏览器性能记录会每 5 秒检查变更并同步到本地 `/api/diagnostics/browser`，无变更时每分钟重送一次，便于服务重启后恢复。服务端 `/api/diagnostics` 的 `browsers` 区分 Edge/Chromium 等浏览器类型，最多保存 8 个页面会话各 200 条指标；只接收同源 JSON、最多 64 KB，复用字段白名单，不接收业务内容。同步失败不会阻塞页面，原记录仍保留在浏览器中。

左侧“定位任务或表 → 性能记录”可导出性能日志。浏览器自动保留最近 200 条接口、操作和卡顿记录，保存在当前浏览器，刷新后保留；服务端 `/api/diagnostics` 保留最近 200 条请求及尚未完成请求，服务重启后清空。两端通过响应请求编号关联，记录不含查询参数、表名、SQL 或业务内容。`Server-Timing` 是服务处理时间，浏览器记录还包括传输、响应解析及主线程等待；长任务与事件循环停顿辅助定位页面卡顿，不代表已确定原因。

本地有界压力测试：`node scripts/data-graph-performance.mjs --concurrency=1,4 --out=tmp/graph-performance.json`。每档执行 8 类查询各 3 次，最多允许 8 并发；出现失败或 P95 超过 5 秒时停止升压。包含搜索、字段清单、分区、两层/四层血缘、任务证据；该测试不等于浏览器绘制或生产容量验收。

“加工证据”内的任务内加工链按 `taskId + writeId + column` 展示源表、每次临时写入及 UNION 分支，点击阶段可查看完整表达式、过滤/连接条件和可核验的 create/query 行号。`/api/explain` 与 `lineage-graph.ps1 explain --task-id <id> --write-id <id> --column <name>` 共用同一解释器，只读取发布版本冻结的 evidence-v4；界面固定 `publicationVersion`，版本变化时拒绝混用结果。默认限制为 32 层、500 个阶段、1000 条边；CLI 可用 `--max-depth`、`--max-nodes`、`--max-edges` 调整。缺少证据显示 PARTIAL，预算停止显示 TRUNCATED，并保留具体缺口和前沿。普通字段取值追溯的 CONDITION 排除规则不变。

“分析范围”支持物理表与调度混选，从任意节点继续展开上下游、点击高亮、收起展开，并保存起点与展开步骤。包含 TIT → T01 和当事人分类入口，读取期间显示进度并支持取消。操作与查询边界见 [分析范围说明](src/analysis-scope/README.md)。

自由探索和分析范围均将节点高亮与进入分析分开：单击表或调度只高亮关联关系，节点下方显示“分析此表 / 分析此调度”和“查看加工证据”。自由探索还在“展开”下方常驻显示这两个入口，未选中节点时禁用；选中后显示对象名称。“分析此表”以准确物理身份重新开始，退出原任务范围并保留显式集群筛选；分析范围会查询该表直接上下游并提供字段选择和“返回上一分析范围”，自由探索沿所选方向查询新起点。调度分析保留既有字段选择流程；查看加工证据仅更新详情。点击画布空白处收起节点操作。按钮保持屏幕字号，不随画布缩小。

界面层数按一次完整的表到表加工计数：`表 A → 任务 → 表 B` 为 1 层。前端请求 `/api/trace?depthUnit=table-hop`；字段取值计一层，跨任务接续不另计层。未指定该参数的调用方保持原始边深度。关系数量上限仍可能截断一层，并明确显示提示。

基于 React Flow 的 data-graph 局部血缘探索器。直接调用现有服务的 `/api/status`、`/api/search`、`/api/fields`、`/api/trace`、`/api/task`，不复制图谱、不预加载全图，也不发布 Neo4j 数据。

字段来源说明复用当前发布证据：可证明原样沿用本表同一字段的分支显示“沿用本表原值”，不作为来源缺失告警；计算、身份歧义和缺失的临时表绑定仍保留未知。常量、参数和原值说明使用普通提示色，仅未定位来源使用黄色。选中字段路径时，已折叠的临时物化连线按已有桥接证据显示“经 N 个中间步骤”，原始 SQL 仍在字段证据面板查看。

## 启动

左侧“集群筛选”支持多选，默认全部集群。应用后筛选总览、搜索、区域分页、关联加工主题以及表/字段血缘画布；共享物理表不会把未选集群的调度重新带入画布。集群列表及任务数来自当前发布图谱和本地调度元数据，缺失值单列“未收录”。主页面保留原始查询证据，按集群过滤显示并提示被过滤调度数量，不跨被过滤任务补连线。主页面和“分析范围”共享当前筛选，刷新后从浏览器存储恢复；打开旧分析范围时沿用当前全局筛选。

定位搜索先匹配任务/表名称及表说明，再仅对命中对象检查集群读写关系，最后排序分页。搜索期间按钮显示“查找中”并阻止重复提交；更改关键词或集群时中止旧请求的接收，旧结果不会覆盖新查询。加载更多沿用已完成查询的关键词，空关键词不发起搜索。

表级输入连线为蓝色，输出连线为紫色，箭头与线同色；候选关系仍为橙色虚线。主页面和分析范围页面均可拖动节点。主页面在同一查询结果内保留手动位置，高亮、隐藏或集群筛选不重置位置；重新查询后使用自动布局，手动位置不跨刷新保存。

单击表卡片仅高亮直接相连的读写调度及连线，不递归扩散到多级上下游；字段路径高亮仍按字段证据追踪。主页面拖动状态在独立画布组件内更新，不在鼠标移动时重跑页面投影。血缘页面应用集群筛选时只更新当前显示，不额外查询全域总览；进入总览时才加载总览数据。

交互更新与结构投影分离：两种工作区均缓存分组、布局和字段证据，仅在点击时更新高亮样式及端点状态，复用未变化的节点和连线。隐藏投影复用同输入、同状态的对象；节点内容不因拖动坐标变化重绘。字段卡片滚动/尺寸观察合并到每帧一次测量，仅在几何变化时刷新端点，隐藏字段批量上报。性能验证应分别记录图转换计算和浏览器渲染耗时，单元测试不代表浏览器交互帧率。

表血缘默认两层。选中表或调度后，可通过节点旁的“向上展开一层 / 向下展开一层”追加当前分支；只沿选定方向合并当前集群内的关系，重复节点和边按原始 ID 去重。旧节点位置、视口和隐藏状态保留，新节点在选中分支旁避让放置。图谱换版或合并后超过 400 条关系时保留原图并提示。重新查询恢复自动布局，追加分支不跨刷新保存。

加工证据只展示已发布投影确认的最终输出字段及注释，中间表字段不展示，也不保留折叠入口。最终输出范围未取得时仅显示加载提示，不回退到全部字段；不按表名前缀或注释是否存在判断输出范围。

页面 `/api/task` 接口也只返回最终输出字段，避免旧前端收到中间字段后再次混排。CLI 的原始加工证据和按需 SQL 原文保留完整内容。

本机 Neo4j、API 和前端的完整启停及故障排查见
[data-graph 本机启停操作手册](../../docs/data-graph-local-runbook.md)。

在仓库根目录启动后端和前端：

```powershell
npm --prefix packages/data-graph-ui ci
npm run graph:serve
npm run graph:ui
```

默认页面为 `http://127.0.0.1:8792`，`/api` 代理到 `http://127.0.0.1:8791`。可通过 `DATA_GRAPH_UI_PORT` 和 `DATA_GRAPH_API_ORIGIN` 调整；不要在配置中写入账号或密钥。

## 验证

```powershell
npm --prefix packages/data-graph-ui test
npm --prefix packages/data-graph-ui run typecheck
npm --prefix packages/data-graph-ui run build
```

当前支持 `/api/overview` 的区域加工骨架、`/api/regions` 的区域成员分页，以及表/字段血缘、上下游、深度、400 条边上限、候选接续开关、任务和字段证据、SQL 懒加载、返回恢复视口。进入字段血缘时会带版本校验地分页加载当前锚点的全部字段，但不会默认选择或自动查询；用户可以一键选择全部字段，或按精确调度 ID 和字段名筛选后选择。前端顺序执行单字段查询，按原始身份去重，将合并结果限制在 400 条原始血缘关系；超过上限且深度大于 1 时，自动以 1 层重查一次。1 层仍超限会明确提示。分页前后及后续追溯均校验图谱版本。区域阶段是后端按当前规则推导的视图，无法分类的区域明确显示为 `UNCLASSIFIED`；区域关系只是 `TABLE_IO` 聚合，不能当作字段因果证据。节点保留 API 原始 `id`。字段视图允许将不同任务的写入展示为同一张卡片，但必须具有相同的完整物理身份、相同的明确分区、相同的消费读取实例集合和显示深度，且接续均已确认。卡片标注生产任务数量，字段明细保留每个任务的写入证据与原始路径；不同来源、未知范围、候选状态及不同消费实例不会据此合并。

搜索、字段和区域成员都采用有界分页。表搜索返回同名物理节点时，UI 使用原始 `nodeId` 请求字段，避免跨物理身份合并。图谱在请求间换版时，UI 会拒绝混合展示旧画布与新证据。

调度任务卡片以本地任务目录 `horae_task_catalog.topic` 关联主题字典 `horae_topic_catalog.topic`，展示“中文主题描述（主题标识）”。无中文描述时保留主题标识，无主题时显示“未收录”，长内容可悬停查看。任务归属统一取自任务目录，不混用详情快照中的 `topicName`；主题仅用于展示归属。

主题字典支持导入含“主题、主题描述、任务数量、操作”列的 UTF-8 制表文本（允许空行和重复分页表头）：

```powershell
node --import tsx scripts/input/mainline/import-horae-topic-catalog.ts --source <文件路径> --database <schedule-evidence.sqlite路径>
```

导入先完整校验，再事务更新字典；不删除未出现在文件中的已有主题，也不修改任务或原始证据。`description` 保留原始主题描述，`task_count_snapshot` 仅表示导入文件中的数量快照；`source_path`、`source_sha256`、`imported_at` 记录来源与导入时间。重复导入相同文件不改写记录。

## 探索入口

左侧“探索入口”可以把当前局部探索保存为一个可命名、带简短说明的专题。专题保存的是原始任务/物理表身份、当前表/字段层级、方向、深度、候选开关、已选字段、候选展开状态和视口；它不保存旧画布或旧证据。一个专题可通过“加入当前起点”保留多个明确选择的任务或表，并在成员列表中逐个回到原有画布继续探索。

入口仅写入当前浏览器的 `localStorage`，使用带格式版本的记录；不会共享给其他浏览器或用户。打开专题时会读取当前已发布图谱并重新执行原有有界查询：若图谱版本已变更，会明确提示且丢弃旧画布；若保存的原始起点或字段已不存在，会提示恢复失败或退回表血缘，绝不会按同名对象替换。使用“更新当前状态”后，才会将新的查询和展示状态写回该专题。

字段选择面板支持独立、精确的起点调度 ID 筛选和字段名搜索，作用于已加载范围。起点调度 ID 同时限制本次展开的已选字段；其他调度的勾选保留，但不参与查询，清除调度筛选后恢复。字段名搜索仅过滤候选列表。按钮显示本次实际参与查询的字段数量。调度筛选不裁剪真实上游或下游路径中的其他任务；返回历史页面恢复原筛选，保存专题记录实际参与查询的字段。点击画布字段时高亮当前子图内该字段的上游来源、下游去向及连线；分别沿正向和反向遍历，不扩散到仅共用来源的旁支；再次点击该字段或画布空白处取消高亮。高亮不请求新血缘。

多起点结果中的重复写入卡片，仅在完整原始写入字段节点集合、物理身份、明确分区范围和显示层级一致时进行展示去重，合并写入证据并保留全部原始连线。不同写入实例不会因表名相同而合并。卡片依据已确认接续关系显示“供调度 … 读取”，帮助区分同名表的消费上下文；候选接续不作此标注。

字段视图采用“表 → 调度任务 → 表”。每条取值关系经过任务形成两段显示连线，因此显示连线数量可能超过原始关系上限。仅凭已确认 CONTINUES 接续、同名限定表及确认的物理身份合并表卡片，字段 alias 保留原始身份和证据。候选生产者默认折叠到来源表入口，可展开查看；普通取值路径不会被任务节点的共享外观扩散成无关字段的血缘。

右侧调度明细展示本地任务目录 `owner` 中的负责人账号，多人按逗号拆分展示；缺失时显示“未收录”。物理表卡片保留表说明，任务身份在调度节点及证据中展示。写入字段自身身份不完整时，注释查询可使用经该次写入关联到的物理表完整身份；已有身份不确定或冲突时保留缺失状态，不按表名猜测。

右侧明细支持拖动左边分隔线调整宽度，当前浏览器会记住宽度；分隔线可用左右方向键微调、Home/End 调到边界、双击恢复默认。视口缩小时会限制详情宽度，保留画布空间。展开“读取 SQL 原文”后，使用 SQL 语法高亮、行号、横向滚动和复制按钮阅读原文；复制内容保留原始空白与换行，不格式化或执行 SQL。

加工证据中的字段名旁展示当前元数据目录的目标字段注释，并标出实际目标表；注释按已发布投影中的写入实例和物理表身份匹配，缺少身份的临时表字段不会借用正式表的同名字段注释。未加载、未收录和读取失败分别显示。字段表达式与加工条件使用浅色 SQL 高亮，保留原始文本。

“最终输出字段”附近提供默认折叠的“目标表 DDL”。展开时通过 `/api/task?ddl=1` 按最终写入的物理身份读取 Table Input Pack 原文，显示表名、写入实例、来源、采集时间并支持复制。读取值必须与元数据目录的 DDL hash 一致；身份缺失、文件不可读或材料变化会明确提示，不按同名表猜测，不根据字段列表重建 DDL。DDL 按需读取不改变元数据目录的常规查询路径。

字段卡片按字段名统一排序；连线仅在两端字段端口均处于卡片可视范围内时展示，页面提示收起数量。点击字段会把相关卡片的首个高亮字段滚入视野；字段路径通过调度节点分成输入、产出两段，标签只在高亮时展示；任一原始字段滚出卡片时，两段同时收起。达到关系预算后尚未查询的字段显示数量提示，不预先画成孤立字段。

字段卡片及写入明细根据当前发布版本的表达式证据展示来源原因：只有明确 `NO_PHYSICAL_INPUT`、且没有已确认/候选/未解析字段输入的表达式才标注。明确字面量显示具体值（空字符串单独注明）；函数、运行时模板和其余表达式统一显示“表达式生成（无物理字段输入）”。证据按任务、写入实例及字段精确关联；缺失证据或仅没有图上连线时不推断常量。

当 Facts 明确标为 `SQL_CANDIDATE`、只有候选字段输入而没有已确认字段输入时，展示“来源待确认（候选字段输入）”，不把它归为常量或无物理输入。

表血缘展示本次有界接口返回的全部节点及读写关系，不因候选写入状态在前端再次截断；候选关系仍以虚线和原始状态展示。这表示任务级 SQL 读写概览，不升级为分区或字段级已确认因果。字段视图继续保留候选折叠和未确认接续边界。

“自由探索”和“分析范围”的表级画布共用物理表合并规则：同一已确认物理 ID 显示一张表卡，同名异源或身份未知不合并。原始任务上下文及每次读写记录保留；点击连线查看该线记录，点击表卡的“查看加工证据”查看当前范围内全部记录，并可打开指定写入的加工证据。

自由探索中，合并表卡继续展开时，向上优先查询读取上下文、向下优先查询写入上下文；没有对应方向时使用该卡已有上下文，仅独立物理表起点沿用全表查询。多个上下文查询全部成功才更新画布，失败、换版或合并超过 400 条关系时保留原图，截断结果明确提示。显式点击“分析此表”则改用物理表起点，不再携带旧上下文；返回和保存重开仍恢复各自原始身份，兼容旧的上下文入口。用户对同一物理表显式选择的分区范围继续保留。此修改仅影响前端，不修改发布图、调度约束或 Agent/API 契约，无需 publish。

任务卡片及任务详情展示本地 Horae SQLite 目录中的调度集群；缺失时显示“未收录”。该标签不改变物理表节点身份或合并规则。
# 表分析的分区范围

在表血缘工具栏打开“分区范围”，可按已发布写入证据选择一个或多个分区组合。应用后，表血缘沿选定写入及已发布读取接续查询；每层使用该层的实际读取范围，不把起点分区条件复制给所有上游表。集群筛选同时生效，切换字段血缘保留选择，并在字段合并前限定具体写入。返回及保存探索入口后重开保留分区选择；图谱换版时要求重新选择，避免静默扩大范围。

日度维度仅在选择器中合并，日期证据仍参与已发布接续判断。动态或缺失分区单独显示为待确认范围，不枚举推测值；多值写入作为整体范围选择，不宣称已隔离其中某一行。未找到可绑定的读取证据时停止，不退回整表补连。分区选项来自静态写入证据，不代表线上当前实际存在的分区目录。

### 请求退出行为
切换追溯方向、层数、候选设置或离开血缘视图时，取消旧血缘请求；离开全景时取消全景请求。相同全景请求在进行中共享，只有所有使用方退出才取消底层请求。服务端在全景数据库阶段之间及主题结果处理前检查断开状态；已提交的当前数据库查询可能运行至本阶段结束，不宣称立即终止。
