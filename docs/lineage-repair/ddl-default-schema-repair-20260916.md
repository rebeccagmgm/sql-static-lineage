# 裸建表语句默认库修复（2026-09-16）

## 规则与代码

不带库名的 CREATE TABLE 先复用 `inferTaskDefaultSchema` / `qualifyBareTableName` 补全库名，再匹配完整表名。调度名称提供默认库，目标表配置用于校验；默认库缺失或冲突时不按裸表名跨库匹配。已明确限定库名的 CREATE 保持原身份。

离线与 SparkIndex 采集入口均传入该上下文。拒绝错库 CREATE 后，查询输出列只允许补全该任务的目标表，不能回退成任意源表的结构。

代码范围：

- `scripts/input/shared/sparkindex-table-evidence.ts`
- `scripts/input/shared/offline-table-resolver.ts`
- 两个对应的采集测试文件。

## 历史证据修复范围

从此前 82 个任务的诊断表集合筛出 12 份裸 CREATE 结构，核对已发布任务的 SQL 与默认库，确认其中 11 份结构被挂到了错误库的同名表。另 1 份证据不足，本轮未改。再检查全部已发布 PROJECTED 任务的结构快照，找到这 11 份结构的 16 个使用方。

- 4 张表替换为正确生产任务的证据：2 张使用其明确限定库名的 CREATE；2 张使用该任务查询的输出列与明确配置的 busi_date 分区，仍标记合成结构，未冒充平台 DDL 或真实字段类型。
- 其余 7 张没有正确的本地结构证据：撤下错误 Table Pack，保留备份，相关字段保留待确认。
- 16 个任务正式 Facts 全部 SUCCESS，正式结构快照与隔离验证结果一致；16 个投影全部 PROJECTED。
- 全图清单保留 7,478 个任务，只替换 16 项，其余 7,462 项逐项保持，删除 0 项。
- 本轮未改前端或多上游接续判定，没有把正常多上游强行变为唯一上游。
