1. **Spark lineage 2021**：先看，因为最像你每天做的 data engineering，重点看 Figure 3–6 和 coarse/fine-grained navigation。[Spark Lineage 论文](https://link.springer.com/article/10.1007/s13222-021-00387-7?utm_source=chatgpt.com)
