1. Graph-Scaling
   1. **建立多维度对比框架** 从「输出形式」「保留信息的来源（原图 / 训练完成的模型）」「输出生成方式（修改原图 / 合成生成）」三个维度，系统对比了图缩放、图浓缩、图约简、图蒸馏、图粗化、图采样、图摘要、图池化等多个相近研究主题的差异与关联。
   2. **提炼领域核心共性** 指出图浓缩（Condensation）、图约简（Reduction）、图蒸馏（Distillation）、图粗化（Coarsening）四个方向拥有本质共通性：
   3. 输入输出范式一致：都遵循「原图输入 → 小规模图输出」的映射逻辑。 基于这一共性，该领域有必要建立统一的定义与分析框架，明确图数据中 “有价值信息” 的判定标准，系统探索缩放图的生成方法，从而更好地梳理现有方法、指引未来研究。
