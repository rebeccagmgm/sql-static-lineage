# 依托图的业务加工知识库

本目录已有固定版本的表级、字段级基础统计、角色分类、候选组和局部加工说明。当前方法将这些成果组织为图的解释层：一方面沿节点、路径和簇理解加工，另一方面按业务对象及用途形成跨单元专题。结构候选不等于已验证业务簇，尚未完成全网业务语义解释；先前试写的正文保留各自证据状态。

## 方法与组织

2026-09-09 重组后的方法以 [执行方法](02-analysis-method.md) 为准，接续委托见 [执行说明](03-executor-brief.md) 与 [接续 prompt](04-start-prompt.md)。本次更新了方法文档，尚未交付新的簇级综合或完整专题。

| 阅读方式 | 知识依托                                     | 要获得的认识                                                 |
| -------- | -------------------------------------------- | ------------------------------------------------------------ |
| 沿图学习 | 真实节点、确定加工路径、固定成员的簇及其边界 | 对象如何形成和使用，内部加工怎样协作，输出与其他单元如何衔接 |
| 横向专题 | 同一业务对象在不同图位置的字段与用途证据     | 例如哪些业务按账簿筛选、选取哪些值、不同分支的规则有何差异   |

WHERE 中的字段和取值具有认知价值。`Book_Agt_Id IN (...)` 可同时进入字段用途说明、对应加工路径和“账簿筛选”专题；专题不限于账簿维表的直接消费者，每条仍回链实际表字段、任务、分支及证据。

总体图范围和交付目标先登记，实施主线为：**图上定位 → 核读具体加工行为 → 归纳规则及差异 → 验证职责并综合成单元 → 横向组织专题 → 按既定范围验收。** 节点和候选簇帮助定位，深度取证从具体输出／写入及相关分支开始；用实际路径核对簇的职责边界。正文与专题共用规则证据，保留各发生位置及完整条件，不以先建设全量规则库为前提。

既有统计、分类和解释继续复用；新发现可修订边界或进入后续候选，范围变化显式登记。验收分别检查来源范围是否已取得／核读证据，以及已取得关键规则是否已解释；已提取规则都有去向不证明源范围已全部覆盖。整体按事先确定的交付范围收尾。
