## 5. 完整追源与 Excel 口径

2026-09-18：[TIT 端到端供数清单-按来源系统.xlsx](TIT端到端供数清单-按来源系统.xlsx) 为更新后的主清单。181 张是 DM 准备表数；7 个直接采集主题、60 张直接贴源输入仅反映直接输入层，不代表原始来源全貌。

本版按 31 个来源系统分 Sheet，纳入 380 张采集表：362 张有确认的业务输入路径，2 张仅作配置辅助，16 张仅候选接续。362 张中按源表内容分为资讯 158 张、其他类型 203 张、类型待确认 1 张。类型依据与供数路径的确认状态分列，表名／链路初分不是生产业务确认。

原接口主题为 103 条资讯、79 条其他业务，共 182 条细化接口，仍由 33接口去向完整保留；柜台 20 条属于交叉视角。源资讯表数与输出接口主题数量不是同一统计单位。另登记 190 个其他 TIT 接收任务。源表、Schema、接口、目标表和调度 ID 分别去重，不相互替代。

追源使用固定发布版本的读取实例和写入接续：排除 DISJOINT 与明确剪枝的写入；候选单列；显式 SRC_TBL 限制用于收窄共享模型的来源。保留字典／码表与业务输入的区别。源端视图通过采集 SQL 确认读取时作为已到达的来源边界，不能因 Schema 名包含 cfg 就误认其业务数据全是辅助配置；也不据此断言视图内部无加工。

来源系统采用调度目录名称与实际采集 Schema；01资讯总分按数据内容与来源系统给出总分，00总览给出各系统数量，02—32 分系统列采集表。不再将供应商、转供系统、文件接入方式混排，也不以 Schema 数代替供应商数。

采集调度 ID 取写入该采集表的已知步骤，不把下游读取任务当采集任务。缺少采集生产者的记“未收录”。系统页的中间表／目标表超过 5 项时节选，完整接口编号保留，全集见 33接口去向与 34逐段调度；35源端表清单保留原 1208 条表与接口关联记录。

部分模型（例如 `pdata_news_n.t02_fnd_base_info` 的 WD 分支）可由消费 SQL 确认来源代码，但当前绑定任务只有建表材料，未闭合到原始基金表；QX 企业关系资料也保留对应模型缺口。4 张 DM 表仍无准备生产者，不能省略或猜源。
