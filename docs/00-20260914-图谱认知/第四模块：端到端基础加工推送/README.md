# 第四模块：系统间供数与流转

本模块说明系统之间提供什么数据、怎样加工、由谁接收。本批以 TIT 为中心，分为“各系统向 TIT 供数”和“TIT 向各系统供数”。简单适配、多表建模、业务规则加工属于具体链路的加工属性，不再作为模块收录范围的限制。

现有 [TIT 端到端供数清单-按来源系统.xlsx](TIT端到端供数清单-按来源系统.xlsx) 是按来源系统展开的表级上游盘点。一个来源系统一个 Sheet，表内区分数据类型。本批涉及的 31 个系统分别列页，指定的 16 个系统放在前面；同时保留 TIT 向下游供数。

**现有表级上游范围不等于实际供数清单。** 工作簿中的“已确认业务输入”表示所展开路径上的表级接续，不证明该表的字段进入最终 TIT 接口。共享模型的全部上游不能自动归为该接口的主体来源；供数内容需要区分主体结果、补充资料与仅上游依赖。

系统页一行一张采集表，包含数据类型、内容细分、原表注释、分类依据、源端、中间表、TIT 目标、采集／中间加工／准备／推送调度 ID。多去向的表在系统页节选，完整对应关系由接口编号连接明细页。

**资讯按表自身内容判断，系统名称不决定类型。** RCC 与广发期货均有资讯和内部业务数据；托管、TA、产品中心的内部产品资料另归“产品与合约”。分类依据包括原注释、字段核对以及表名／链路初分，未判定的保留“待确认”。旧版 103 是接口主题数量，本版 158 是采集表数量，不能比较增减。

“大集中”按实际目录保留：`ODATA_YGT` 为大集中柜台采集，`ODATA_N_RCC` 为零售柜台采集。本批路径确认了 RCC 等柜台供数，尚未确认 YGT → TIT；不合并名称、不以未命中断言不存在。
