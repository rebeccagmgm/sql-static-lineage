## 2. 资讯的总与分

公开的证券与产品基础资料、行情、公司股权、公司行为、基金指数与宏观资料均归资讯。**本批已确认业务输入的采集表中，158 张归资讯，203 张归其他类型，1 张类型待确认。** “已确认”描述表级供数路径；数据类型的判断依据另列，部分为表名与链路初分。

系统页把“原表注释”与“内容细分／分类依据”分开。元数据没有注释的写“注释未收录”，不把推测的中文释义包装成原注释。

## 4. 从源表找到接口与调度

每张采集表列出源端或上一级输入、采集任务、中间模型及加工任务、关联接口编号、准备任务和推送任务。没有找到采集生产者的保留“未收录”；下游读取任务不能充当采集调度 ID。文件源保留文件生成端缺口。

Excel 33接口去向保留全部 **182 条入向接口**：181 张 DM_OTC_N 准备表，加 1 条模型直写，涉及 183 张 TIT 目标表和 278 个推送任务。完整逐段读写见 34逐段调度，完整源端关联见 35源端表清单。

其中 **229978** 读取 `pdata_n.t99_marg_ass_scr_info`（两融标的券信息）及 `pdata_news_n.t02_scr_base_info`（证券基本信息），限定 RCC 来源、整理状态和标记，直接写入 `titans_etl.trans_marg_ass_scr_info`（大集中柜台-担保证券）。它没有经过 DM_OTC_N，保留为 IN182。目标表注释中的“大集中”不改变源端实际属于 RCC 的证据。

目录中的 `ODATA_YGT` 大集中与 `ODATA_N_RCC` 零售柜台分别保留。本批尚未确认 YGT 到 TIT 的路径，不由未命中推断不存在。其他 190 个 TIT 接收任务另列 37其他接收入口。

## 5. 加工性质与核对范围

第四模块改为“系统间供数与流转”。收录范围包含简单适配、多表建模及业务规则加工，以下原分类只描述已核对的段落，不能据此给整条链路贴“简单加工”标签。

35 条接口已核对准备／推送表达式或针对性 SQL，归为接口段基础适配；79 条复用原清单的简单加工判断及其核对范围；64 条仍待确认，另有 3 条复杂加工、1 条派生标签加工。合计 182 条。

系统页的加工判断属于关联接口，不代表采集源视图或所有上游模型都简单。承接既有估值或盈亏结果，也不等于在接口重新计算。未闭合模型、源端视图内部与文件生成端见 38待补证据。
