# 雪球（Snowball）基础
## 1. 产品定义
雪球（Snowball）是一类结构化衍生品，通常属于自动赎回型期权（Autocall）。
其核心结构：
- 投资者获得固定票息收益机会；
- 产品定期观察标的表现；
- 若满足敲出条件，则提前终止；
- 若触发敲入条件，则承担标的下跌风险。
本质：
> 通过卖出下行风险换取较高票息收益的结构化期权产品。
---
# 2. 产品核心组成
一个雪球合约由以下业务对象组成：
```
Snowball Contract
        |
        +-- Underlying（标的资产）
        |
        +-- Coupon Term（票息条款）
        |
        +-- Knock Out Term（敲出条款）
        |
        +-- Knock In Term（敲入条款）
        |
        +-- Contract Terms（合约基本信息）
```
---
# 3. 标的资产 Underlying
雪球的收益与某个标的挂钩。
常见标的：
- 股票
- 指数
- ETF
- 股票篮子（Basket）
例如：
```
雪球合约
    |
    +-- 中证500指数
```
或者：
```
雪球合约
    |
    +-- 股票篮子
            |
            +-- 英伟达
            +-- 特斯拉
```
数据建模中：
```
Option Contract
        |
        underlying_instrument_id
        |
        +-- Instrument
        |
        +-- Basket Constituent
```
---
# 4. 票息 Coupon
## 定义
票息是雪球产品约定的收益率。
例如：
```
Coupon Rate = 12%
```
表示：
满足产品收益条件时，投资者按照约定票息获得收益。
数据字段：
```
COUPON_RATE
```
来源：
```
Coupon Terms
```
---
# 5. 敲出 Knock Out（KO）
## 定义
敲出表示：
> 标的达到上涨目标，产品提前结束。
例如：
```
初始价格：100
敲出线：100%
观察日：
如果价格 >= 100
触发敲出
```
结果：
```
产品结束
投资者获得票息
```
数据：
```
Knock Out Term
- Observation Date
- UP_KO_BARRIER_PCT
```
---
# 6. 敲入 Knock In（KI）
## 定义
敲入表示：
> 标的大幅下跌，触发风险事件。
例如：
```
初始价格：100
敲入线：80%
期间跌破80
触发敲入
```
数据：
```
Knock In Term
- DOWN_KI_BARRIER_PCT
```
雪球中通常：
```
KO = 上敲出
KI = 下敲入
```
---
# 7. 收益路径
```
开始
 |
 |
每日/每月观察
 |
 +----------------+
 |                |
达到KO          未达到KO
 |                |
提前结束          继续观察
 |
获得票息
期间触发KI
 |
 |
到期承担标的风险
```
---
# 8. 一个简单案例
假设：

|条款|参数|
|---|---|
|标的|中证500|
|期限|1年|
|票息|12%|
|敲出|100%|
|敲入|80%|
情况1：
```
第3个月上涨达到100%
=> 敲出
=> 产品结束
=> 获得票息
```
情况2：
```
期间一直没有敲出
到期标的上涨
=> 获得票息
```
情况3：
```
期间跌破80%
=> 敲入
到期继续看标的表现
```

# 9. 数据模型映射（titans）
对应：

|金融概念|数据对象|
|---|---|
|雪球合约|option_base|
|标的资产|option_underlying|
|经营分类|option_classified|
|票息条款|coupon_terms|
|敲出条款|knockout_terms|
|敲入条款|knockin_terms|
|权利金计提|first_premium_fee|
最终形成：
```
Snowball Contract
{
 contract,
 underlying,
 coupon,
 knockout,
 knockin,
 fee
}
```
---
# 10. 关键术语
|术语|含义|
|---|---|
|Underlying|挂钩标的|
|Coupon|票息收益|
|Autocall|自动赎回|
|KO|敲出|
|KI|敲入|
|Barrier|障碍水平|
|Observation Date|观察日|
|Notional|名义本金|

---
这篇作为你后续“期权领域知识地图”的第一篇比较合适，因为后面看 SQL 时基本都能映射回来：
- `COUPON_RATE` → 票息
- `UP_KO_BARRIER_PCT` → 敲出
- `DOWN_KI_BARRIER_PCT` → 敲入
- `underlying_instrument_id` → 标的
不会陷入字段记忆。
