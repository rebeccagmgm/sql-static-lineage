# 公共结果如何进入收入与规模

销售基础、归属和逐日金额相同，并不意味着下游口径相同。本篇只说明公共结果被怎样使用，以及业务专题应从哪里继续；各收入公式和指标定义由后续专题完整解释。

## 三份日报怎样使用同一组基础

| 公共输入 | 交叉118141 | 对内114013 | 香港220979 |

| 销售基础 | 本次快照，排除费用互换、FAST分组、香港部门等；使用已有经营分类 | 本次快照，结束边界不早于2023-01-01、排除两个指定客户及FAST；另算对内分类 | 本次快照，结束边界不早于2025-12-01、限定六个账簿；另算香港分类 |

| 客户资格 | 该主线没有对内／香港所用的独立客户资格INNER JOIN | 境内来源客户须符合监控、未删除条件，另有指定客户例外 | 香港来源客户须未删除且“涉及交叉销售收入标志”为1 |
| 管理归属 | 本次快照；取普通经办、三组关系及比例，另有机构范围条件 | 本次快照；取内部经办角色，收入按有无内部引入经办决定100/0或40/60 | 本次快照；取普通经办和三组关系，至少一组机构通过非8846条件 |

共同输入并不保证三份日报覆盖相同合约或相同日期。客户资格、期末边界、账簿与分组是消费自己的范围条件，不向公共生产脚本补上这些过滤。全部实际条件与例外保留在各自完整SQL。

**归属资料只提供角色和比例，收入专题决定如何使用。** 118141和220979的40/60作用于本金；114013的40/60作用于收入，并读取`Inr_Main_* / Inr_Intro_*`。105743不能因此被解释成已经算完收入分成的公共结果。

**金额字段相同，也要追到本次公式真正采用的值。** 220979返息费用互换在年化项中使用源“本日计息基数”乘当日汇率；佣金又使用期初本金或当日事件发生额。它们不是把107491动态本金改名后的值，应在香港主线分别展开。

三份收入的共同与独有步骤见[收入阅读入口](../销售与经营分析/00-全貌.md)。参数来源归入[价差](04_经营系数_价差/README.md)、[基准](05_经营系数_基准/README.md)、[资金成本](06_经营系数_资金成本/README.md)和[佣金](08_经营系数_佣金/README.md)，实际匹配及公式继续在各消费主脚本中定位。

## 三条需要保留的差别

**参数查询结果与收入计算是分别生成的消费。** 三份日报自行连接参数，有些按计提日匹配，有些按期初定价日匹配。共享参数来源不证明两个DM输出之间存在直接生产关系。例如113993展示计算方式时先取价差参数，114013普通收入却先取类型基础参数；220981会展示佣金计算方式，220979的佣金金额没有据此选择年化／绝对分支。也不能用“参数快照避免重算历史”替代对具体日期连接的解释。

**相同结束日会有不同边界。** 107491的01/02金额分支在“计提日大于结束日”时归零，因此结束日自身不走该归零条件；171370要求结束日严格大于统计日。一个字段是否有金额与某指标是否纳入该合约，是两个步骤。

**当前归属与历史金额可以在同一个消费中相遇。** 206208读取当前参数日的管理关系，将三槽位展开。它没有在这一段根据每个历史计提日分别选择当时关系。因而“按历史当日人员归属统计”仍不能从该SQL推出。

## 206208提供了一个需要继续解释的期间口径入口

当前表达式为：

```sql
sum(t1.Dyna_Nom_Prin) / max(t0.actl_days)
```

而 `actl_days` 采用：

```sql
datediff(
  if(coalesce(Early_Term_Date, End_Pric_Date) <= 参数日,
     参数日, coalesce(Early_Term_Date, End_Pric_Date)),
  Strt_Pric_Date
)
```

按这段表达式，日期差的结束端取参数日与合约结束边界中较晚的一方，不能直接改写成“截至当天已存续天数”。金额明细连接同时限制计提日不晚于参数日、也不晚于明细结束日，但没有显式要求计提日从当年1月1日开始；上游一次重算的150日窗口，也不能证明全年历史分区是否齐全。

这些是当前SQL中需要解释或核验的边界，尚不等于已经用数据证明的金额错误。后续期间规模专题应把日期集合、分母、零天数、重复连接、分组覆盖和归属时点放在一起核对，不能直接沿用旧文“年度日均”的通用公式。[206208 L1–24](99_证据/206208-query.sql)
