# 经营分类精确条件对照

本表是[四个生产分支](../01_合约主信息/README.md)的分类附表，按SQL CASE顺序排列，**首次命中即停止**。NULL遵循SQL原表达式，不把`NOT IN`或不等号自动解释为“包含NULL”。这里只整理 `Contr_Type_Cd`；中文说明以原SQL／所连字典为准。

| 记号  | 01期权                                     | 02普通互换                  |
| --- | ---------------------------------------- | ----------------------- |
| T   | `ds.contract_type`                       | `rt.trs_type`           |
| S   | `ds.contract_sub_type`                   | 不使用此记号                  |
| F   | `coalesce(bc.ins_family,ins.ins_family)` | `his_ini.ins_family`    |
| C   | 不使用此记号                                   | `his_ini.currency`      |
| P   | `deal.PRIVATE_PLACEMENT`                 | `rtl.Private_Placement` |
| IPO | 不使用此记号                                   | `rtl.ipo_type`          |

F、C可能是聚合后的字符串。SQL用整串等值或IN判断，不表示逐个列表元素匹配。

## 02：普通互换

按`substring(rt.START_DATE,1,10) <= '2025-03-31'`选择旧分支；否则进入新分支。依据：[86841 L21–42](../../../../attachments/02.1-销售基础经营分类规则/IMG-02.1-销售基础经营分类规则-20260921105055616.sql)。

### 新分支

| 顺序 | 命中条件 | `Contr_Type_Cd` |
| --- | --- | --- |
| 1 | T=LEND_SWAP且F∈EQUITY/GDR | `TRS_SHORT_SELL` |
| 2 | F=QIS | `TRS_S_CROSS_QTF_STRG_IDX` |
| 3 | T=S_CROSS_FUTURE_SWAP | `TRS_S_CROSS_FUTURES` |
| 4 | T∈S_CROSS_SWAP/S_CROSS_OPTION_SWAP，F∈EQUITY/GDR，C<>CNY，IPO=Y | `TRS_S_IPO` |
| 5 | 同一类型集合，F∈EQUITY/GDR，且IPO=N或NULL | `TRS_S_CROSS_STOCK` |
| 6 | `rb.company=GFS_HK`且T=INDEX_ENHANCE_SWAP | `TRS_N_CROSS_INDEX_ENHANCE` |
| ELSE | 未命中上述条件 | `TRS_OTHER_SWAP` |

### 旧分支

| 顺序 | 命中条件 | `Contr_Type_Cd` |
| --- | --- | --- |
| 1 | `rb.department=OTC_HK`，T∈CROSS_LEND_SWAP/HK_LONG_HOLD_SWAP/N_CROSS_FUTURE_SWAP/N_CROSS_QFII_SWAP | `'TRS_' + T` |
| 2 | T=N_CROSS_SWAP | `TRS_N_STOCK` |
| 3 | T∈CALL_SWAP/PUT_SWAP | `TRS_LONG_SHORT` |
| 4 | T=S_CROSS_FUTURE_SWAP | `TRS_S_CROSS_FUTURES` |
| 5 | T=S_CROSS_SWAP且`his_ini.interotc_underlying_category=BONDS` | `TRS_S_CROSS_BOND` |
| 6 | T=S_CROSS_SWAP，F∈EQUITY/GDR，C<>CNY，IPO=Y | `TRS_S_IPO` |
| 7 | T=S_CROSS_SWAP，F∈EQUITY/GDR，C<>CNY，IPO=N或NULL，P=Y | `TRS_S_STOCK_LIMITED` |
| 8 | T=S_CROSS_SWAP，F∈EQUITY/GDR，C=HKD，IPO=N或NULL，P=N或NULL | `TRS_S_CROSS_HK` |
| 9 | T=S_CROSS_SWAP，F∈EQUITY/GDR，C不在HKD/CNY，IPO=N或NULL，P=N或NULL | `TRS_S_CROSS_OTHER` |
| 10 | `rb.company=GFS_HK`，T=FEE_SWAP，`rt.contract_use=REBATE_INTEREST` | `FEE_SWAP_HK` |
| 11 | `rb.company=GFS_HK`且T=INDEX_ENHANCE_SWAP | `TRS_N_CROSS_INDEX_ENHANCE` |
| ELSE | 未命中上述条件 | `TRS_OTHER_SWAP` |

第7–9行中的“IPO=N或NULL”“P=N或NULL”分别作为整体条件，与同一行其他条件取AND。
