# RISKY/AIRBAGX：融资、成本与保证金关联怎样改变香港收入

[02_原始当日收入](02_原始当日收入.sql)最先判断RISKY、AIRBAGX，再判断关联保证金LONG_HOLD_SWAP归零。命中这些分支后不会继续加普通期权价差/基准，也不会加普通TRS佣金。**香港这里的名单只有RISKY和AIRBAGX**，不因产品名称类似就扩大到AIRBAG、AIRBAGM或AIRBAGL。

本页保留这一组相关分支，沿同一份合约看“无关联 → 有关联 → 抵扣”的结果；不为三个CASE臂创建三套独立流水线。它们后面都承接[05保底层](05_保底与历史奖励.sql)、[06分配累计](06_分配与累计.sql)及[07日报输出](07_日报输出.sql)。

## 一、先让这份合约命中真实来源和参数

`HK_RISKY_DEMO`是构造数据：09-18期初、09-20结束、09-21加工，提前终止日NULL，处在允许的香港期权账簿内，客户和机构准入通过。金额假设同一计价单位，每一路参数唯一匹配，非生产记录。

| 业务/源类型/源标的/限售标志 | OPTION / RISKY / EQUITY / 0 | [01](01_合约日与资料.sql)重算香港分类为OPTION_RISKY_AIRBAGX_CIR_STOCK、香港标的EQUITY |
| 初始本金 | 3,650,000 | 主信息；用于本金分配展示，当前特殊日收入使用det动态本金 |

## 二、没有保证金合约关联：每天120

命中条件是源类型RISKY/AIRBAGX、非DEDUCTION、保证金合约号为空。直接使用实际[02第二个WHEN](02_原始当日收入.sql)：

```text
动态本金       3,650,000
融资比例       1 − 初始保证金0.2 = 0.8
调整后费率     0.106 ÷ 1.06 = 0.1
净费率         0.1 − 资金成本0.05 = 0.05
原始日收入     3,650,000 × 0.8 × 0.05 ÷ 365 × 0.3 = 120
```

0.3和1.06是原SQL固定系数，现有证据只证明使用方式，不能直接写成已经核实的制度分成或税务规则。

三天原始收入120/120/120，21日由于本例det本金0而收入0。这一特殊分支自身**没有普通期权那层存续日期IF**；如果det在结束后仍为非零，本分支不会仅凭结束日期自动归零。

香港分类OPTION_RISKY_AIRBAGX_CIR_STOCK不在05的两类保底名单，因此调整后收入仍120/120/120/0；06总累计120/240/360/360，第1组累计84/168/252/252，第2组36/72/108/108。07的20日输出当日120、总累计360、三组累计252/108/0，`Fee_Rate=0.106`、`Fin_Rati=0.8`。

## 三、只补上关联保证金合约：每天变105

其他输入不变，`Marg_Agt_Id=MARGIN_DEMO`，命中第三个WHEN：

```text
采用的融资比例       1 − 基础保证金率0.1 = 0.9
重新折算费率         0.106 × (1−0.2) ÷ (1−0.1) ÷ 1.06
                    = 0.0888888889
原始日收入           3,650,000 × 0.9 × (0.0888888889−0.05) ÷ 365 × 0.3
                    = 105
```

这个公式把初始保证金比例用于费率折算，基础保证金率用于外层本金比例及折算分母，不是简单把0.8换成0.9。这里只看关联号是否存在，没有读取MARGIN_DEMO的本金再相加。

之后仍不做期权保底，三天105/105/105，总累计105/210/315；第1/2组最后220.5/94.5，21日保持315。20日的 `Curr_Prvs_Sales_Income=105`、`Accum_prvs_sales_income=315`；展示 `Fin_Rati` 仍来自01的 `1−Init_Marg_Prop=0.8`，**不能拿展示0.8替换实际收入公式的0.9**。

初始本金主经办1,460,000、引入2,190,000没有随120变105而改变；本金40/60与收入70/30依然独立。

## 四、抵扣与关联LONG_HOLD_SWAP为什么先归零

只把HK_RISKY_DEMO的抵扣模式改DEDUCTION，第一个WHEN立即返回0，不再查看保证金关联或成本是否存在，日报日收入和累计均0。它不是先算120或105再在后面扣一次。

另一条相邻分支的条件是 `Busi_Type=TRS AND Src_Contr_Type=LONG_HOLD_SWAP AND Marg_Agt_Id非空`，原始收入同样直接0。比如把[普通TRS案例](08_普通互换与返息费用贯通.md)仅切到这个条件，原来3750/445/50/0全部变0，不再加其佣金。该判断是源类型LONG_HOLD_SWAP，不能因为香港分类名单含HK_LONG_HOLD_SWAP就把两者当成同一个条件。

如果源类型改成AIRBAG，最前面RISKY/AIRBAGX名单不会命中；之后是否进入普通OPTION/TRS公式与是否保底仍要分别看业务类型和重新生成的香港分类。不能从“名字含AIRBAG”推断套105/120公式。

## 五、缺值和边界怎样读

- **仅缺资金成本**：没有COALESCE补0，正常融资分支收入NULL；即使某日det本金为0，乘NULL仍为NULL。06当日输出保持NULL，累计按其原COALESCE处理为0。
- **比例为NULL**：运算继续传播NULL，不能因为融资比例展示为空就自行回退另一种保证金比例。
- **基础保证金率等于1**：有关联公式存在除以0分母。阅读版保留原式，不用SQLite对除零的行为证明Hive/UDF或生产结果。
- **重复成本匹配**：LEFT JOIN会扩行，窗口累计随输入变动；不是对每个合约自动选一条成本。成本配置的真实唯一性仍需行数据证据。

算例执行交付02、05、06、07的真实表达式，并验证抵扣优先、关联与非关联、成本NULL、AIRBAG名单边界；它们说明冻结SQL的计算路径，不等于真实经济制度和生产数据已验收。金额、日期、字段原注释见[来源字段证据](来源字段证据.json)，完整主线回到[00_主脚本](00_主脚本.sql)。
