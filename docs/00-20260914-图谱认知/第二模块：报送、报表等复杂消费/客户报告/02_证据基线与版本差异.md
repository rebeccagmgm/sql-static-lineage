## 四、关键中文注释的证据边界

金仕达三张来源表按精确表名与物理来源核对，使用 2026-09-16 构建的表元数据目录，原始 DDL 采集于 2026-08-23：

| 字段 | 实际注释／冲突 | 本专题采用的表达 |
| --- | --- | --- |
| `S_GF_BK_CONTRACT.actual_occupy_amt` | 实际占资金额 | 沿用来源注释 |
| `S_GF_BK_CONTRACT.remain_contract` | `【AI】合约保证金余额` | 保留 AI 标记；程序扣减的具体字段，经济含义仍待确认 |
| `S_V_CONFIRMATION_OVERVIEW.ks_other_profit` | 字段中文注释为空 | 说明当前 SQL 用其前减后差分作为利息，不冒称元数据定义 |
| `M_T_CMP_AGENT_STAT.cust_total_fee` | 交易对手方报盘费用总计；原 SQL 行注释称未结 | 说明总计字段日差分并保留冲突；不改用另一个 `cust_unsettle_fee` 字段 |

普通互换使用的 `gfgreatest`／`gfleast` 在函数知识库有“取最大／最小”的普通数值说明，来源为 `wiki:75614191`（2025-10-01），没有给全 NULL、非法字符串和隐式转换语义。数值算例可以推演，不得用 JavaScript 对 NULL 的转换冒充生产 UDF。
