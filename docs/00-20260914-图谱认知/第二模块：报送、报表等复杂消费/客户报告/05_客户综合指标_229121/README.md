## 三、看懂结果必须记住的三个区别

**第一，客户底座不等于当前持仓客户。**01从报告日创收快照筛“上一年元旦到报告日”的01/02/03计提行，按公司名＋USCC分组。没有要求当日仍持仓、创收为正。来源中缺了客户，这里的并列LEFT JOIN不会凭空补出他。

**第二，按USCC计算不代表全线都按USCC连接。**02/03/04/05/06按USCC回接，07至13中的额度、规模、资料、追保、文字和费用等按公司名回接。02内部还按名称＋USCC分组，外层只按USCC连接；同USCC多名称可能扩行。底座“一客户一行”的愿望不能替代实际唯一性核验。

**第三，列名不等于完整业务定义。**这里的胜率不是都在衡量客户投资盈利；已用额度没有独立查额度占用；平台费/券息从腿累计收益分类得到；垫资文字里的托管流水描述是硬编码。每一项应回到实际来源和条件解释，不按名称自行补制度。
