4. **报送入口不等于口径已解释。** 207789、223239、205224承接源报送视图，本轮保留材料入口，继续追溯源计算。
5. **91973、132277需要复核图表达。** SQL读取DM结果而图内输出观察指向同表，本轮不据此解释反向生产。
6. **保留依赖有两种对象。** 有物理身份的是结果表/写入依赖；无输出的977个占位只是调度参考。筛选时用登记类型区分，不把调度关系当作数据因果。
