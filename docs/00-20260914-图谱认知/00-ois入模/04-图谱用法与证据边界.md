## 2. 哪些结果可以怎样使用

| 证据 | 可以支持 | 不自动支持 |
|---|---|---|
| 显式 SQL 读取及写入 | 本任务引用哪些来源、执行何种投影或筛选 | 每个输入都给每个输出提供值 |
| 注释或宏的来源声明 | 定位 ${src_table} 等候选来源 | 已证明运行时宏绑定、唯一物理来源 |
| 字段 VALUE 路径 | 当前静态投影记录了字段值依赖 | 数据到达、运行成功、业务正确 |
| CONTINUES / CONFIRMED | 当前规则下确认的跨任务字段接续 | 所有分区、所有运行时间都对应同一生产者 |
| CANDIDATE / UNKNOWN | 保留进一步核对的接续候选 | 确定生产关系 |
| 本地 DDL、字段注释 | 结构和对象描述线索 | 行数据唯一性；含【AI】注释的业务定义已核验 |
| 本地码值 | 指定代码域、代码值及快照日期下的含义 | 任意同码通用，或已取得全部源码转换实值 |

字典选录来自本地资产库，标为 UNVERIFIED_LOCAL_SNAPSHOT。来源名称 OIS/TIT 记录日期为 2021-06-18；当事人类别为 2021-01-11；同一当事人关系为 2021-06-30；报告执行状态为 2024-03-04。[字典选录](证据/字典选录.json)。

图中的固定版本证据与本地 SQL 不预设为同一次生产快照。本文将它们分别引用，167 项哈希核对也没有被当作“全部 SQL 与图内 Facts 同版本”的证明。

## 4. 图外任务的处理

图外的 62 个 T01～T10 候选都有本地 SQL。其中 1 个目录标为手工任务；10 个与图内候选同名，但任务 ID 和类型可能不同。目录启停状态为空，不能认定这些同名任务已经废弃、互相替代，也不能直接据此新增 62 个图任务。

本次按已有材料解读选中的图外任务，不改变图范围。其余候选保持附录状态，未冒充已确认入模链。目标未限定 schema 时，附录明确保留“未定库”；不根据任务名称补造物理身份。

## 5. 本版保留的具体空白

- OIS 本地源名的完整发现清单已列出，但 60 个未命中任务源名的实际用途尚未建立。
- T06～T10 中未命中主题的间接路径未系统闭合；T00/T98/T99 保留候选入口与必要案例，没有扩展为完整下游分析。
- 主协议条件到逐笔交易、报告配置到真实发送结果、参数到收入计算的完整业务闭环没有被现有证据全部证明。
- 转码实值、同号跨来源匹配、Join 唯一性、金额与比例正确性需要相应业务数据；本次没有查询或验证这些行数据。
- 18 份 SQL 按正文问题选读，未宣称全量字段解析、代码审计或运行验收完成。

这些空白作为当前认知边界保留，不要求本阶段继续扩图。后续若业务重点回到某一条路径，可以直接从附录的源表、任务和现有 SQL 继续。
