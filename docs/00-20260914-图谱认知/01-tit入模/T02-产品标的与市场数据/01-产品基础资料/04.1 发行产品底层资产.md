# 04.1 发行产品底层资产

**这张表的核心是一条对应关系：哪款发行产品，关联哪个金融工具，以及哪笔内部交易。**

它让产品主档能够继续找到合约和估值。这里的“底层资产”是相对于发行产品而言，关联到的工具可以是场外合约工具；还不能直接读成最终挂钩的股票。

## 1. 从哪里取，进入哪张表

| 取数原表 | 入模表 | 来源范围 | 调度 |
| --- | --- | --- | --- |
| `ODATA_N_TIT.P_PRD_PRODUCT_ASSET` | `PDATA_NEWS_N.T02_TIT_PRD_ASSET_INFO` | `SRC_ID='TIT'、GRP_ID='01'` | 160753、211486 |

取处理业务日 `BUSI_DATE` 的来源关系，按工具内码左关联 `T02_SCR_BASE_INFO` 的 TIT 资料补统一证券编号。未匹配到统一编号的来源记录仍保留。

## 2. 三个业务编号各接到哪里

| 取数原字段 → 入模字段 | 表示什么 | 连接方向 |
| --- | --- | --- |
| `KEY_PROD_ID` → `PRD_ID` | 发行产品 ID | 产品主档 `T02_TIT_PRD_INFO.PRD_ID` |
| `KEY_INSTRUMENT_ID` → `UNDRL_SCR_CD` | 在入模中按 TIT 工具内码使用 | `T02_SCR_BASE_INFO.IN_CODE`，或回原表 `D_REF_INSTRUMENT.KEY_INSTRUMENT_ID` 查类型和名称 |
| 关联取得 → `UNDRL_SECU_ID` | 上述工具的统一证券编号 | 用于模型内证券身份关联 |
| `INTERNAL_TRADE_ID` → `INR_TRD_JOUR_NO` | 内部交易流水号 | 下游用来找对应合约或互换估值 |
| `ID` → `REC_ID`、`SRC_REC_ID` | 来源关系记录主键 | 追溯这条关系 |

**`UNDRL_SCR_CD` 虽然叫“标的证券代码”，在这一分支实际装的是 TIT 工具内码。** 源元数据又把 `KEY_INSTRUMENT_ID` 注释成“场外合约交易流水号”，但已查 SQL 明确拿它匹配工具主数据 `IN_CODE`；真正单独保存的内部交易号是 `INTERNAL_TRADE_ID`。使用时以这条实际关联区分两者。

## 3. 为什么关联到合约以后还要继续查

查询路径可以这样读：

```text
产品主档 PRD_ID
    └─ 产品底层资产 PRD_ID
         ├─ UNDRL_SCR_CD → 工具内码 → 名称、INS_FAMILY
         └─ INR_TRD_JOUR_NO → 内部交易号 → 合约或估值
```

若工具类别查到 `TRS`，得到的是互换工具身份。要回答“互换具体挂钩哪只股票”，继续查合约结构或互换腿持仓中的标的编号，再回金融工具主数据查名称。

这张关系表没有数量、权重、持仓市值或收益字段；**它提供连接路径，不在这里计算资产配置和产品净值。**

## 4. 已确认的两条实际使用路径

### 4.1 产品怎样找到合约利率

香港票据明细 **163640**、香港负债 **176443** 使用的路径是：

1. 按 `PRD_ID` 连接产品与底层资产关系，取得 `INR_TRD_JOUR_NO`。
2. 关联 `PDATA_N.T03_AGT_STATI_INFO_H.STATI_CONT_DESC`，限定来源 `D_TRD_OTC_TRADE`、信息类型 `09` 及处理日有效区间，取得 `AGT_ID`。
3. 用 `AGT_ID` 关联 `T03_OTC_SWAP_COMP_LEG_INFO.SWAP_COMP_AGT_ID`，取得利息腿的固定利率、计息方式、付息频率等。

这解释了为什么产品主档没有完整利息腿字段，下游仍能补出这些内容。

**这两项消费都按产品内 `UNDRL_SCR_CD` 降序取一条资产关系来找合约。** 这是该报表的取数选择，不表示一个产品业务上只能关联一个资产，也不表示已经汇总全部底层资产。

### 4.2 产品怎样接到 AMCNote 价格

财务价格 **199871** 按 `PRD_ID` 取得内部交易号，再用它关联 `PDATA_NDS.FIN_TRS_PLREPORT.CONTRACTCODE`。

该 TIT 分支限定 `AMCNote`、到期日不早于处理日、发行数量转换后非零，估值取处理日及指定票据账簿。随后计算：

> 单价 =（动态名义本金 − 结构腿未实现损益）÷ 产品发行数量。

资产关系在这里负责**确定产品对应哪份估值**，发行数量来自产品主档，动态名义本金与损益来自估值。该查询按产品与内部交易号去重后关联，没有先把一个产品的全部资产估值汇总，因此不能把此公式直接推广为任意多资产产品的净值算法。

财务票据交割 **202510** 也使用同一内部交易号连接估值，计算相关日期的利息变动；这是进一步的消费计算。

依据：入模 SQL 160753、211486；消费 SQL 163640、176443、199871、202510；源字段元数据。见 [底层资产消费图谱](../消费核对/投影-t02_tit_prd_asset_info.json)。
