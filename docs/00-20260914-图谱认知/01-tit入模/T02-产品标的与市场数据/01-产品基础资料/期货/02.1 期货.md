# 02.1 期货

**期货属性说明一份期货合约的具体规则：是什么合约、在哪个市场交易、合约乘数是多少、什么时候停止交易和交割。**

金融工具主数据提供编号、名称和类别；期货属性继续补充合约参数。识别一份合约时，应把标准合约代码、交易代码、合约类型和日期放在一起看。

## 1. 从哪里取，进入哪张表

| 资料          | 取数原表                                                    | 入模表                                  | 调度            |
| ----------- | ------------------------------------------------------- | ------------------------------------ | ------------- |
| 期货基础资料      | `ODATA_N_TIT.D_REF_FUTURE_PROPERTIES`                   | `PDATA_NEWS_N.T02_FUT_BASE_INFO`     | 105612、105862 |
| 期货基础资料的另一批次 | `ODATA_N_TIT.D_REF_FUTURE_PROPERTIES_PB`，`GRP_ID='h15'` | 同上                                   | 144301、211516 |
| 期货扩展资料      | `ODATA_N_TIT.D_REF_FUTURE_PROPERTIES`                   | `PDATA_NEWS_N.T02_FUT_BASE_INFO_EXT` | 105745、105746 |

目标均为 `SRC_ID='TIT'、GRP_ID='01'`。主表和扩展表各自从源属性表取数，扩展表单独承接交割月份、交易代码、英文简称及来源等字段。

## 2. 取数逻辑

1. 按 `BUSI_DATE` 取处理业务日的期货属性；PB 分支另限定源 `GRP_ID='h15'`。
2. 用 **`KEY_INSTRUMENT_ID = T02_SCR_BASE_INFO.IN_CODE`** 关联 TIT 来源的工具身份，取得 `SECU_ID`、`SRC_SYS_PRDNO`。
3. 主表将 `FUTURE_TYPE` 对照 `T02_PUB_COVT_CONST` 中 TIT／`var00001` 的规则转换为期货类型代码。其他参数主要直接承接，日期统一格式。
4. **主表和扩展表都只保留 `SECU_ID` 非空的记录。** 因而源属性存在、通用身份未补齐时，这条属性不会进入相应目标。

关联通用身份时仅限定 TIT 来源，没有按通用表的业务日期等值关联；入模也没有额外按“未到期”过滤。

## 3. 主要保存哪些规则

| 业务内容           | 取数原字段                              | 入模去向／理解方式                                                                     |
| -------------- | ---------------------------------- | ----------------------------------------------------------------------------- |
| 合约代码与名称        | `SCCODE_WITH_SUFFIX`、`NAME`        | 主表 `STD_CONTR_CD`、`STD_CONTR_NAME`；标准代码保留后缀                                   |
| 市场             | `EXCHMARKET`                       | 主表 `EXCH_ABBR`，保留源市场代码                                                        |
| 合约乘数           | `CONTRACT_MULTIPLIER`              | 主表 `CONTR_MULPLR`，用于表达合约数量与价值尺度的参数                                            |
| 上市、最后交易、最后交割日期 | `LISTDATE`、`DELISTDATE`、`LTDLDATE` | 主表 `CONTR_LIST_DATE`、`LAST_TRD_DATE`、`DELI_DATE_INTRO`                        |
| 涨跌限制           | `PRICE_LIMIT`                      | 主表 `MAX_PRIC_VOLA_INTRO`，按源值承接                                                |
| 期货标的编号         | `UNDERLYING_INS_ID`                | 主表 `UNDRL_SCR_CD`，这里保存的仍是源标的编号                                                |
| 期货类型           | `FUTURE_TYPE`                      | 转为主表 `FUTR_TYPE_CD`                                                           |
| 合约类型、连续合约类型    | `TYPE`、`CCTYPE`                    | 分别放入主表 `REMARK.TYPE`、`REMARK.CCTYPE`                                          |
| 交割月份           | `DLMONTH`                          | 主表 `REMARK.DELI_MTH`；扩展表 `DELI_MON`                                           |
| 交易代码、英文简称      | `CODE`、`ENAME`                     | 主表备注中的 `TRD_CD`、`STD_CONTR_ENAME`；扩展表 `DEAL_CD`、`SCR_EN_ABBR`                 |
| 来源与创建时间        | `DATA_SOURCE`、`CREATED_DATETIME`   | 主表备注中的 `SRC_DATA_SOURCE`、`SRC_CREATE_TIME`；扩展表 `SRC_DATA_SRC`、`SRC_ESTB_TIME` |

`DELISTDATE` 的源字段含义是 **最后交易日期**，该分支写入 `LAST_TRD_DATE`。主表另有 `DELIST_DATE` 字段，但本分支将它写空。

交易计量单位、每手交易单位、最小变动价位、最低保证金、交割方式等通用字段，在该 TIT 入模分支中也写空。查询参数时，需看实际承接字段。

### 期货类型怎么读

`FUTURE_TYPE` 表示期货的业务类型；`TYPE` 表示合约类型；`CCTYPE` 表示连续合约类型。三者是不同字段。

源字典 `D_CFG_DICTIONARY_DESC.FutureType`（业务日期 `2026-09-14`）给出：

| 源代码 | 含义 | 源代码 | 含义 |
| --- | --- | --- | --- |
| `COMMODITY_FUTURE` | 商品期货 | `EQUITY_INDEX_FUTURE` | 股指期货 |
| `EQUITY_FUTURE` | 股票期货 | `TREASURY_FUTURES` | 国债期货 |
| `PRECIOUS_METAL_FUTURE` | 贵金属期货 | `FX_FUTURE` | 汇率期货 |
| `OPTION_FUTURE` | 期货期权 | `BOND_FORWARD` | 标债远期 |
| `OTHERS` | 其他 | | |

这些是源代码。目标 `FUTR_TYPE_CD` 使用 TIT／`var00001` 的转换结果，具体源—目标码值应查该转换表。

## 4. 怎样与自身、标的关联

```text
D_REF_FUTURE_PROPERTIES
    KEY_INSTRUMENT_ID ─→ 期货自身的工具身份 → SECU_ID
    UNDERLYING_INS_ID ─→ 期货标的的工具身份
```

本分支给期货自身补统一编号；标的编号直接写入 `UNDRL_SCR_CD`，**没有在这里补成标的的 WIND 代码或统一编号**。目标 `UNDRL_SECU_ID` 在该分支中为空。若要取得标的名称、类别和代码，再按标的内码查询金融工具资料。

## 5. 下游实际怎么用

| 消费方与目标 | 具体使用 | 调度 |
| --- | --- | --- |
| 风控 `DM_RSK_N.FUTR_BASE_INFO` | 取主表的日期和合约代码，从备注提取合约类型、连续合约类型、交割月份、英文简称，再关联 TIT 工具资料补名称、市场和 WIND 代码 | 164500 |
| 香港 `DM_HK_N.REF_FUTURE_PROPERTIES` | 还原期货属性，包括乘数、标的和备注中的参数；将模型期货类型反向转换为源代码。该消费限定来源表为普通 `D_REF_FUTURE_PROPERTIES` | 160530 |

这说明主表 `REMARK` 中的参数有实际用途。它们与扩展表存在内容重合，但已确认的上述消费读取的是主表及其备注。

期货扩展表的 TIT 分支尚未确认明确业务读取。期货日行情另走共用行情资料，由任务 164723 输出风控 `FUTR_MKT_QUOT`，见后续行情章节。
