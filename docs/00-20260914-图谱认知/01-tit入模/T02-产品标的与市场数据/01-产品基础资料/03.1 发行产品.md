# 03.1 发行产品

**`P_PRD_PRODUCT` 是发行产品主档：围绕一款产品，保存发行部门、产品代码、期限、本金、发行数量、认购情况和状态。**

例如，下游会从这里识别 `FundingNote` 融资型票据，或筛选 `AMCNote` 进入对应财务价格分支。至于产品关联哪份场外合约、合约又挂钩什么资产，需要沿底层资产关系继续查。

## 1. 从哪里取，进入哪张表

| 取数原表 | 入模表 | 来源范围 | 调度 |
| --- | --- | --- | --- |
| `ODATA_N_TIT.P_PRD_PRODUCT` | `PDATA_NEWS_N.T02_TIT_PRD_INFO` | `SRC_ID='TIT'、GRP_ID='01'` | 160750、211488 |

两项调度的已查入模查询一致：取源表处理业务日 `BUSI_DATE` 的记录，直接承接产品资料并转换日期格式。**没有按产品状态、是否到期或是否已认购筛选。**

## 2. 一条记录在描述什么

源字段 `ID` 是记录主键，写入 `REC_ID`；**`KEY_PROD_ID` 是产品业务主键，写入 `PRD_ID`**。跨产品、票据和底层资产表连接时，使用产品业务编号。

| 内容 | 取数原字段 → 入模字段 | 业务含义 |
| --- | --- | --- |
| 产品编号 | `KEY_PROD_ID` → `PRD_ID` | 产品业务身份 |
| 内外部代码 | `INNER_CODE`、`EXTERNAL_CODE` → `PRD_INR_CD`、`PRD_EXT_CD` | 产品的内部及外部标识；香港票据消费将外部代码用于 ISIN 输出 |
| 部门与账簿 | `DEPARTMENT`、`KEY_BOOK_ID`、`BOOK_NAME` → `ISS_DEPT`、`BOOK_ID`、`BOOK_NAME` | 发行部门、归属账簿；源注释说明账簿 ID 用于区分权限 |
| 产品类型与状态 | `PRODUCT_TYPE`、`PRODUCT_STATUS` → `PRD_TYPE`、`PRD_STAT` | 保留源代码，入模不另做类型／状态转换 |
| 销售与起息 | `TRADE_DATE`、`START_DATE` → `SALE_DATE`、`VAL_DATE` | 销售日期与开始计息日期，分别保留 |
| 到期与结算 | `END_DATE`、`SETTLEMENT_DATE` → `MATY_DATE`、`SETT_DATE` | 到期日期与结算日期，分别保留 |
| 期限与延期 | `INVEST_MATURITY`、`PAYMENT_DATE_DELAY` → `PRD_TERM`、`PAY_DAY_DELAY` | 产品期限（天）、兑付日延期参数 |
| 币种 | `SETTLEMENT_CURRENCY` → `SETT_CRRC` | 源结算币种直接承接 |

源注释说账簿 ID 用于权限区分，不能仅凭这个字段就把发行产品名义本金视为该账簿的实际持仓。

## 3. 本金、价格、数量和认购金额怎样区分

| 想了解什么 | 取数原字段 → 入模字段 | 读取要点 |
| --- | --- | --- |
| 产品总名义本金 | `TOTAL_NOTIONAL` → `PRD_TOT_NOM_PRIN` | 产品本金规模 |
| 发行数量 | `ISSUE_SIZE` → `ISS_QTY` | 发行的数量，后续单价计算会使用 |
| 单位面值 | `DENOMINATION` → `PRD_PAR_VAL` | 产品面值 |
| 发行及到期价格 | `ISSUE_PRICE`、`MATURE_PRICE` → `ISS_PRIC`、`MATY_PRIC` | 源元数据标注单位为 `%`；入模不换算，也不是每日市场价 |
| 认购限制 | `MIN_ORDER_AMOUNT`、`MAX_ORDER_AMOUNT` → `MIN_SCRP_AMT`、`MAX_SCRP_AMT` | 认购起点和认购上限 |
| 已认购数量 | `ORDERED_SIZE` → `SCRP_QTY` | 来源维护的已认购数量 |
| 累计已认购金额 | `ACCUMULATED_ORDER_AMOUNT` → `ACCUM_SCRP_AMT` | 来源维护的累计金额 |

**入模直接读取这些字段，没有用面值乘数量重算本金，也没有用发行价重算认购金额。** 阅读时保留各自口径；不能先假定总名义本金、发行金额和认购金额必然相等。

## 4. 类型和状态怎么看

### 4.1 已在消费中确认的产品分类

| 值 | 已确认的含义或使用方式 | 证据 |
| --- | --- | --- |
| `FundingNote` | 融资型票据；香港负债任务的 TIT 产品分支专门取这一类 | 176443 |
| `AMCNote` | 财务单独处理的一类发行产品；价格分支结合关联互换的估值和发行数量计算单价 | 199871、202510 |
| `StructureNote` | 香港票据明细把非 `FundingNote` 产品归到这一输出类别 | 163640；这是消费层分类，不能据此当作源 `PRODUCT_TYPE` 的完整枚举 |

这里列出实际消费口径；`AMCNote` 的完整产品定义还应结合具体发行条款，不能只凭类型名称补出收益规则。

### 4.2 源状态字典

本地 TIT 字典 **`ProductStatus`**（业务日期 `2026-09-14`）有以下含义，产品入模原样保留状态：

| 源码 | 含义 |
| --- | --- |
| `DRAFT` | 草稿 |
| `TOEFFECT` | 待生效 |
| `EFFECTIVE` | 生效 |
| `TERMINATED` | 终止 |
| `CANCELED` | 作废 |

这些是状态解释，不是本篇推导出的状态流转顺序。163640、176443 实际使用 `PRD_STAT != 'CANCELED'`，其 SQL 中原先“仅生效”的限制已注释；因此这两个消费也不能概括为“只取有效产品”。

## 5. 实际怎样使用

- **香港票据明细（163640）**：以产品为主表，补票据利息类别、交易对手和合约利息腿。非融资型分支以“面值 × 已认购数量”计算发行金额，融资型分支有自己的金额取法。
- **香港负债（176443）**：取融资型票据的本金、币种和期限，再从关联利息腿补固定利率、计息方式、付息频率。
- **AMCNote 价格（199871）**：取 `PRD_TYPE='AMCNote'`、到期日不早于处理日、发行数量转换后非零的产品，沿底层资产的内部交易号关联当日指定票据账簿估值。该分支的单价为 **（动态名义本金 − 结构腿未实现损益）÷ 发行数量**，结果保留两位小数。价格在消费层计算。
- **逐笔认购／交易**：继续查来自 `P_PRD_NOTES_TRADE_RECORD` 的 T05 产品交易流水；产品主档本身不提供逐笔交易对手明细。

依据：入模 SQL 160750、211488；消费 SQL 163640、176443、199871、202510；源表字段元数据。状态含义见 [TIT 源字典](../../../../../../数综基础信息/原信息/关键表信息/D_CFG_DICTIONARY_DESC_合并_中英文字段.csv) 的 `ProductStatus`。
