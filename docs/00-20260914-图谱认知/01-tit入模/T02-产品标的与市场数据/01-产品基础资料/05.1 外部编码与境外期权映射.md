# 05.1 外部编码与境外期权映射

**同一项金融工具在不同系统中可以使用不同代码。外部编码资料保存“工具内码 ↔ 编码体系 ↔ 编码值”；境外期权映射再补充交易代码、市场和 `BB_ROOT` 等配置。**

## 1. 从哪里取，进入哪张表

| 资料 | 取数原表 | 入模表 | 来源范围／调度 |
| --- | --- | --- | --- |
| 通用外部编码 | `ODATA_N_TIT.D_REF_INSTRUMENT_CODE` | `PDATA_NEWS_N.T02_TIT_SCR_BASE_INFO` | TIT／02；103236、103237 |
| 境外期权映射 | `ODATA_N_TIT.R_CFG_ICE_LISTEDOPTION` | `PDATA_NEWS_N.T02_STK_OVERSEAS_OPT_CD_MAP` | TIT／01；218469 |

两类都读取处理业务日 `BUSI_DATE`。前者补工具的多套外部代码，后者保存境外期权相关配置。

## 2. 外部编码怎么读

| 取数原字段 → 入模字段 | 含义 |
| --- | --- |
| `KEY_INSTRUMENT_ID` → `IN_CODE` | TIT 工具内码，连接主数据 |
| `SEC_CODE` → `DATE_SRC` | 编码体系，例如 `WIND`、`ICE`、`ISIN` |
| `CODE_VALUE` → `SRC_CD` | 该体系下的代码值 |
| `UPPER_CODE_VALUE` → `UPPER_SRC_CD` | 来源提供的大写代码值；本次入模直接承接 |

入模按工具内码左关联 `T02_SCR_BASE_INFO` 的 TIT 资料，补 `SECU_ID`、名称、类别、币种等。没有命中统一身份时，源编码记录仍保留。

**`DATE_SRC` 在这里表示编码体系，字段名中的 DATE 不表示日期。** `SRC_ID='TIT'` 表示这条资料经 TIT 入模，`DATE_SRC='WIND'` 表示它记录的是 WIND 编码，两者可以同时成立。

同一个工具可以保存多套代码。查 WIND 代码时，应同时限定：

```text
T02_TIT_SCR_BASE_INFO
    SRC_ID = 'TIT'
    GRP_ID = '02'
    DATE_SRC = 'WIND'
    IN_CODE = 要查询的工具内码
```

`GRP_ID='01'` 保存工具本身的 TIT 扩展属性，`GRP_ID='02'` 保存外部代码；两组虽然共用表名，读取目的不同。

### 编码体系字典

本地 TIT 字典 `SecCode`（业务日期 `2026-09-14`）列出：

| 代码 | 字典说明 | 代码 | 字典说明 |
| --- | --- | --- | --- |
| `WIND` | 万得 | `ICE` | ICE |
| `ISIN` | ISIN | `SEDOL` | SEDOL |
| `EMSX` | 彭博代码 | `RIC` | 路透代码 |
| `ATP` | ATP | `CTP` | 综合交易平台 |
| `CLOUD` | 云行情 | `ES` | 易盛 |
| `GFTG` | 托管部代码 | `ROOTNET` | 根网 |
| `MANUAL` | 手工添加 | — | — |

这是编码类型字典，不代表每个工具都具有以上全部代码。

## 3. 境外期权映射保存什么

| 取数原字段 → 入模字段 | 含义 |
| --- | --- |
| `UNDERLYING_INSTRUMENT_ID` → 拼接 `SRC_SYS_PRDNO`，并关联取得 `SECU_ID` | 被配置标的的工具身份 |
| `UNDERLYING_CODE`、`UNDERLYING_SHORT_NAME` → `SRC_TRD_CD`、`SCR_ABBR` | 源交易代码与简称 |
| `ICE_UNDERLYING_CODE` → `OVERSEAS_OPT_TRD_CD` | 境外期权交易代码 |
| `ICE_UNDERLYING_EXCHANGE` → `OVERSEAS_OPT_MKT_IDTY_CD` | 境外期权市场标识 |
| `BB_ROOT` → `OVERSEAS_BB_ROOT` | 下游匹配期权行情所用的根代码 |
| `ENABLE` → `WHTH_ENABLE` | 是否启用配置 |

源工具类别和源市场另存入备注。入模补统一身份，但**不根据 `ENABLE` 剔除记录**。

这张配置表也没有行权价、看涨／看跌、到期日等完整期权合约要素。实际推送查询使用 `BB_ROOT` 匹配行情，因此读取时不能把一条根代码配置理解为唯一一份具体期权合约。

## 4. 实际用在哪里

**OTC 标的定义 119976**把 TIT／01 的工具资料与 TIT／02／WIND 的代码连接，再补工具标签。该消费只取 `EQUITY`、`FUND`、`INDEX`、`FUTURE`，且要求匹配到非空 WIND 代码。

**境外期权推送 234508、96471**读取 `DM_OTC_N.NDS_OVERSEA_LISTED_OPT_QUOT`，按 `BB_ROOT=OVERSEAS_BB_ROOT` 连接本配置，并限定 `WHTH_ENABLE='Y'`。行情还要满足相应日期及成交价／结算价非空条件，输出进入 `TITANS_ETL.TRANS_OVERSEA_LISTED_OPTION`。配置在这里决定哪些根代码进入推送范围，价格来自行情表。
