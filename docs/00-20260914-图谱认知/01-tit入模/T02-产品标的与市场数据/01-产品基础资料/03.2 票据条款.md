# 03.2 票据条款

**`P_PRD_NOTES` 补充发行产品的票据资料：票据编号、序列号、ISIN、按名义金额还是数量交易，以及利息和赎回采用什么基准。**

产品主档告诉我们发行了什么；票据资料继续描述这款产品以票据形式记录的具体条款。

## 1. 从哪里取，进入哪张表

| 取数原表 | 入模表 | 来源范围 | 调度 |
| --- | --- | --- | --- |
| `ODATA_N_TIT.P_PRD_NOTES` | `PDATA_NEWS_N.T02_TIT_NOTE_INFO` | `SRC_ID='TIT'、GRP_ID='01'` | 160751、211487 |

两项调度的已查查询一致：取处理业务日 `BUSI_DATE` 的票据资料，逐项承接。入模不关联产品主档，也不根据产品状态过滤票据。

## 2. 哪些编号负责什么

| 取数原字段 → 入模字段 | 含义 | 怎样关联 |
| --- | --- | --- |
| `ID` → `REC_ID` | 来源记录主键 | 追溯这条来源记录 |
| `KEY_NOTE_ID` → `NOTE_ID` | 票据 ID | 识别票据 |
| `KEY_PROD_ID` → `PRD_ID` | 所属产品 ID | 关联产品主档的 `PRD_ID` |
| `SERIES_NUMBER` → `SEQ_NUM` | 序列号 | 具体消费可能再用于匹配产品内部代码 |
| `ISIN` → `ISIN` | ISIN 标识 | 保留票据的外部标识 |

源元数据写 `SERIES_NUMBER` 默认 ISIN，表示源端默认规则，不能把序列号和 ISIN 永远视为相等。**香港票据明细 163640 实际同时按 `PRD_ID`、`PRD_INR_CD=SEQ_NUM` 关联票据，不能只看“同一个产品”就忽略第二个条件。**

## 3. 条款字段讲的是什么

| 内容 | 取数原字段 → 入模字段 | 业务含义 |
| --- | --- | --- |
| 交易方式 | `TRADING_METHOD` → `TRD_METHOD` | 元数据列出 `Nominal`、`Unit`，分别按名义金额、按数量理解 |
| 名义金额 | `AGGREGATE_NOMINAL_AMOUNT` → `PRD_TOT_NOM_PRIN` | 票据层保存的总名义金额 |
| 发行数量 | `AGGREGATE_ISSUE_SIZE` → `ISS_QTY` | 票据层保存的发行数量 |
| 发行价格 | `ISSUE_PRICE` → `ISS_PRIC` | 源元数据标注 `%`，入模不换算 |
| 净募集金额字段 | `NET_PROCEEDS_AMOUNT` → `ACCUM_SCRP_AMT` | 目标名为“累计已认购金额”，但这一路具体来自 `NET_PROCEEDS_AMOUNT` |
| 面值 | `SPECIFIED_DENOMINATION` → `PRD_PAR_VAL` | 指定面值 |
| 利息基准 | `INTEREST_BASIS` → `INTR_BSC` | 固定／浮动利息类别，不是实际票息数值 |
| 赎回基准 | `REDEMPTION_PAYMENT_BASIS` → `REDP_BSC` | 到期或赎回支付采用的条款基准 |

**同名模型字段，要结合来源读。** 产品表的 `ACCUM_SCRP_AMT` 来自 `ACCUMULATED_ORDER_AMOUNT`，票据表同名字段来自 `NET_PROCEEDS_AMOUNT`，不能仅凭目标名认定两者同口径。

源注释说明部分票据金额、数量和面值联动产品基础要素；但当前入模只读取源值，不重新计算或检查两张表是否一致。

## 4. 条款里的文字代码

以下取自源字段元数据列举的值，入模原样保留：

| 字段 | 值 | 含义 |
| --- | --- | --- |
| `TRADING_METHOD` | `Nominal` | 按名义金额；源注释标为默认 |
| `TRADING_METHOD` | `Unit` | 按数量 |
| `INTEREST_BASIS` | `Fixed Rate` | 固定利率类别 |
| `INTEREST_BASIS` | `Floating Rate` | 浮动利率类别；源注释标为默认 |
| `REDEMPTION_PAYMENT_BASIS` | `Redemption at par` | 按面值赎回；源注释列出的默认值，完整枚举未在该元数据中给出 |

“默认”描述字段维护规则，不代表每份票据的实际值。`INTR_BSC` 虽注释为“利息基数”，在已查消费中用于输出 `Rate_Type`；具体固定利率、浮动基准、利差和付息频率继续从关联的合约利息腿取得。

## 5. 实际用在哪里

**香港票据明细（163640）**从本表取得 `INTR_BSC`，输出为利率类型。它还读取产品主档、产品交易流水及底层资产关系，才拼出完整票据明细。

**资料分发（181140）**把本表复制到 `DM_OTC_N.T02_TIT_NOTE_INFO`。这条用途是票据基础资料分发，当前 SQL 本身没有计息或赎回金额计算。

依据：入模 SQL 160751、211487；消费 SQL 163640、181140；`ODATA_N_TIT.P_PRD_NOTES` 元数据。下游入口见 [票据消费图谱](../消费核对/投影-t02_tit_note_info.json)。
