# 02 品种属性与条款

**金融工具主数据回答“它是什么”，品种属性与条款接着回答“这个工具按什么规则交易、行权、计息或维护”。**

例如，主数据可以告诉我们某个编号代表一份期权；期权属性进一步告诉我们它挂钩什么、看涨还是看跌、行权价多少、什么时候到期。

## 2. 与金融工具主数据怎样配合

```text
金融工具主数据：这个编号代表什么工具
    └─ KEY_INSTRUMENT_ID → T02_SCR_BASE_INFO.IN_CODE
                           ↓ 取得 SECU_ID 等统一身份
品种属性表：补充这个工具的具体规则
    ├─ 期货：合约乘数、交割月份、最后交易日……
    ├─ 场内期权：标的、行权价、看涨看跌……
    ├─ 货币利率：期限、计息与结算惯例……
    ├─ 策略指数：子标的、初始基准、版本……
    └─ AUTOCALL：观察日、风险障碍……
```

这些属性通常以工具内码连接通用身份。涉及另一只工具时，还要区分“自身编号”和“标的编号”：场内期权使用 `UNDERLYING_INS_ID` 表示标的，策略指数使用 `KEY_UNDERLYING_INS_ID` 表示子标的。

## 3. 阅读时抓住什么

每篇按 **业务含义 → 来源与入模 → 主要字段 → 关联方式 → 实际用途** 阅读。先理解规则，再按需查字段和码值。

- **交易与行权规则**：一份合约怎么交易、如何行权、何时到期，查期货或场内期权属性。
- **计息规则**：某个利率采用什么期限、日算惯例和日历，查货币利率属性。
- **维护与观察规则**：策略由哪些标的和版本构成、AUTOCALL 在什么日期观察哪些障碍，查相应维护或条款资料。

每日价格、利率报价、指数点位行情、Greeks 等数值在“02 行情与市场参数”中继续阅读；发行产品和票据的发行、认购、兑付资料见“03 发行产品与票据”。
