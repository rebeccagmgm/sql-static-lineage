# 04 底层资产与组合关系

**这一部分回答：一个发行产品关联哪份工具和交易，一份多标的期权的篮子里又有哪些成分。**

“底层”要看相对于哪个对象：发行产品的下一层可能是场外合约工具；合约再往下才可能关联股票、指数等挂钩标的。沿关系逐层查，不能跳过中间对象。

## 1. 两类关系分别看

| 子篇 | 关系是什么 | 取数原表 | 入模表／调度 |
| --- | --- | --- | --- |
| [04.1 发行产品底层资产](04.1%20发行产品底层资产.md) | 发行产品 → 金融工具，同时记录内部交易号 | `P_PRD_PRODUCT_ASSET` | `T02_TIT_PRD_ASSET_INFO`；160753、211486 |
| [04.2 多标的期权篮子](04.2%20多标的期权篮子.md) | 期权合约 → 篮子 → 成分标的，同时带篮子类型和权重 | `D_V_RISK_OPTION_BASKET_INFO` | `T02_OPT_MULT_BASK_INFO`；104478、104481 |

原表位于 **`ODATA_N_TIT`**，模型表位于 **`PDATA_NEWS_N`**；两类入模均使用 `SRC_ID='TIT'、GRP_ID='01'`。

## 2. 先认清关系两端

```text
发行产品 KEY_PROD_ID
    └─ 产品底层资产记录
         ├─ KEY_INSTRUMENT_ID → 金融工具主数据：这个工具是什么
         └─ INTERNAL_TRADE_ID → 合约资料／估值：关联哪笔内部交易

多标的期权 KEY_OTC_TRADE_ID
    └─ BASKET_INS_ID：该合约的篮子
         └─ UNDERLYING_INS_ID：篮子中的一项成分及其权重
```

| 容易混在一起的问题 | 应怎样分开查 |
| --- | --- |
| 产品关联的工具是不是股票？ | 先按该工具内码查 `D_REF_INSTRUMENT.INS_FAMILY`；若查到合约工具，再沿合约结构查挂钩资产 |
| 产品底层资产表能否直接算组合比例？ | 该表提供产品、工具和交易的关系，没有数量或权重字段 |
| 期权篮子有权重，是否就是加权收益？ | 还要看篮子类型和合约结构；权重字段本身不能代替收益规则 |
| 看到多个成分，是否是重复数据？ | 先保留产品／合约、篮子、成分的维度，再判断来源是否重复 |

## 3. 与其他章节怎么接

- **发行产品的身份、发行数量、票据条款**：见 [03 发行产品与票据](03%20发行产品与票据.md)。
- **关系中每个工具叫什么、是什么类型**：见 [01 金融工具主数据](01%20金融工具主数据.md)。
- **策略指数由哪些子标的构成，配置如何随版本变化**：见 [02.4 策略指数](02.4%20策略指数.md)。策略配置有数量和版本，期权篮子有篮子类型和权重，应按各自含义读取。
- **普通互换的具体挂钩资产**：前面的主数据说明已列出互换腿持仓 `D_POS_TRS_LEG_HIS_POS.UNDERLYING_INS_ID` 入口，不能把本章的发行产品资产关系当作所有互换持仓的明细。

## 4. 这两类关系现在用在哪里

发行产品底层资产关系已经进入香港票据明细、香港负债、AMCNote 财务价格和票据交割资料。它的实际作用是**把产品主档接到合约条款或估值数据上**。

多标的期权篮子入模保存了合约与成分关系；现有发布图中尚未检出这张 T02 表的直接消费。关系本身可以解释，具体业务系统如何读取还需对应消费证据。

依据：入模 SQL 160753、211486、104478、104481；消费 SQL 163640、176443、199871、202510。图谱入口：[产品底层资产](../消费核对/投影-t02_tit_prd_asset_info.json)、[期权篮子](../消费核对/投影-t02_opt_mult_bask_info.json)。
