# 05.2 金融工具标签

**标签回答的是：这个工具是否属于某个范围、具有某种属性。** 例如是否沪深 300 成分、是否两融标的、是否沪／深港通标的。

主数据的 `INS_FAMILY` 区分股票、基金、期货等工具类别；标签继续描述该工具同时具有哪些特征。

## 1. 从哪里取，进入哪张表

| 取数原表 | 入模表 | 来源范围 | 调度 |
| --- | --- | --- | --- |
| `ODATA_N_TIT.D_REF_INSTRUMENT_TAG` | `PDATA_NEWS_N.T02_SCR_LBL` | `SRC_ID='TIT'、GRP_ID='01'` | 127897 |

取处理业务日 `BUSI_DATE` 的记录，按 `KEY_INSTRUMENT_ID` 左关联 TIT 通用工具资料补 `SECU_ID`。源工具内码保存在 `REC_ID`、`SRC_REC_ID`，`SRC_SYS_PRDNO` 为 `TIT-`＋工具内码。

## 2. 有哪些标签

| 标签 | 取数原字段 | 入模字段 |
| --- | --- | --- |
| 沪深 300 成分股 | `IS_CSI300` | `SHSZ_300_COMPNT_FLAG` |
| 中证 500 成分股 | `IS_CSI500` | `CSI_500_COMPNT_FLAG` |
| 中证 800 成分股 | `IS_CSI800` | `CSI_800_COMPNT_FLAG` |
| 恒生大型股指数成分股 | `IS_HSLI` | `HS_LARG_STK_IDX_COMPNT_FLAG` |
| 原油期货 | `IS_OIL_FUTURE` | `CRU_OIL_FUTR_FLAG` |
| 商品期货 | `IS_COMMODITY_FUTURE` | `COMD_FUTR_FLAG` |
| 两融标的 | `IS_FINANCING_SECURITY` | `MARG_UNDRL_FLAG` |
| 南向准入标的 | `IS_SOUTHWARD_ADMITTANCE` | `SOUTH_ACS_UNDRL_FLAG` |
| 港股通，针对香港股票 | `IS_HKSC` | `MHS_FLAG` |
| 沪股通或深股通，针对 A 股股票 | `IS_SHSC` | `NTL_FLAG` |
| 深港通 | `IS_SZSC` | `SZHK_SC_FLAG` |
| 沪港通 | `IS_SSC` | `SHHK_SC_FLAG` |

各列是独立属性，入模没有将其合成一个互斥分类。`IS_SHSC` 与 `IS_SSC` 尤其容易看混，应结合上表完整字段含义读取。

## 3. 标志值怎样转换

| 源值 | 入模值 | 含义 |
| --- | --- | --- |
| `Y` | `1` | 是 |
| `N` | `0` | 否 |
| 空值或其他未匹配值 | `NULL` | SQL 没有给出是／否结果 |

**空值没有被补成“否”。** 这是入模 `CASE` 的实际取法；看标签时应保留“否”和“未给出结果”的区别。

这些标签只能说明某项属性。例如“是沪深 300 成分”不提供完整指数成分权重，“是南向准入标的”也没有给出某个交易对手、业务方案下的全部交易条件。后者继续看标的池和白名单。

## 4. 实际用在哪里

**OTC 标的定义 `DM_OTC_N.OTC_UNDRL_DEF`，调度 119976**：

1. 从 TIT／01 工具扩展资料取身份、名称、类别和市场。
2. 从 TIT／02／WIND 编码资料取标的代码。
3. 按工具内码关联本标签表的 `REC_ID`。
4. 将 `SHHK_SC_FLAG`、`SZHK_SC_FLAG` 的 `1/0` 转回 `Y/N`，输出为 `IS_SSC`、`IS_SZSC`。

该消费只取指定四类工具且要求有 WIND 代码；并非标签表中每个工具都会输出。消费图另记录 `OTC_COMP_DURA_CHG_EVT`（146386）的读取关系，可沿该事件用途继续查。
