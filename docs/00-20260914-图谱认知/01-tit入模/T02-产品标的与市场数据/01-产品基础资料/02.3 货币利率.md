# 02.3 货币利率

**货币利率属性说明一个利率工具按什么规则使用：什么币种、什么期限、怎样计息、怎样确定结算日和处理非工作日。**

例如，知道一个编号对应某个利率之后，还需要知道它采用哪套日算惯例、日历及日期调整规则，才能正确理解相关计息和结算。具体某天的利率数值由报价资料提供。

## 1. 从哪里取，进入哪张表

| 取数原表 | 入模表 | 来源范围 | 调度 |
| --- | --- | --- | --- |
| `ODATA_N_TIT.D_REF_RATE_PROPERITES` | `PDATA_NEWS_N.T02_TIT_IRA_CRRC_ATTR` | `SRC_ID='TIT'、GRP_ID='01'` | 170648 |

原表名称实际拼写为 **`PROPERITES`**，查询时按原表名使用。

## 2. 取数逻辑

1. 按 `BUSI_DATE` 取处理业务日的利率属性。
2. 用 **`KEY_INSTRUMENT_ID = T02_SCR_BASE_INFO.IN_CODE`** 左关联 TIT 工具身份，取得 `SECU_ID`、`SRC_SYS_PRDNO`。
3. 币种、期限和计息规则等主要原样写入目标，没有在这一层重新计算利息或利率。

未匹配到通用身份的源属性仍保留。入模任务本身没有再按 `INS_FAMILY='RATE_INDEX'` 筛选，风控消费时会按该工具类别选择范围。

## 3. 各组规则分别表示什么

| 业务问题 | 取数原字段 | 入模字段 | 阅读要点 |
| --- | --- | --- | --- |
| 这个利率工具对应什么 | `UNDERLYING`、`DESCRIPTION` | `UNDRL_CD`、`UNDRL_NAME` | 标的代码及描述；不把 `UNDERLYING` 默认当作工具内码 |
| 属于哪个币种 | `CURRENCY` | `CRRC_NAME` | 这里直接承接源币种值，虽然后缀叫 NAME，也没有在入模转成中文名称 |
| 期限和到期日 | `TENOR`、`MATURITY` | `TERM`、`MATY_DATE` | 描述期限及到期信息 |
| 如何复利、多久复利一次 | `COMPOUNDING_TYPE`、`COMPOUNDING_FREQ` | `COMPD_INTR_REGU`、`COMPD_INTR_FREQ` | 保存复利规则和频率 |
| 计息天数按什么规则算 | `DAYCOUNTCONV` | `DAY_CONVN` | 日算惯例，例如实际天数配 360 或 365 的年基准 |
| 按什么规则结算 | `SETTLEMENT_CONV` | `SETT_DAY_CONVN` | 结算日惯例 |
| 日期落在非工作日如何调整 | `BUS_ADJ_CONV` | `WORK_DAY_ADJ_CONVN` | 工作日调整惯例 |
| 是否采用月末规则 | `EOM` | `MONTH_END_REGU` | 月末规则，直接保存源值 |
| 哪些日期算工作日 | `CALC_CAL` | `CAL` | 适用日历 |

**日算惯例决定计息时间如何折算，日历和工作日调整规则决定日期如何落定。** 这些属性需要一起阅读，单独看期限或币种不足以理解完整规则。

### 常见规则代码

源字典 `D_CFG_DICTIONARY_DESC`（业务日期 `2026-09-14`）中的部分对应如下：

| 字典 | 代码 | 含义 |
| --- | --- | --- |
| `DayCount` | `ACT360` | Actual/360 |
| `DayCount` | `ACT365` | Actual/365 |
| `DayCount` | `THIRTY360` | 30/360 |
| `DayCount` | `BUSINESS252` | Business days/252 |
| `CompoundFrequency` | `ANNUAL` | 年 |
| `CompoundFrequency` | `QUARTERLY` | 季 |
| `CompoundFrequency` | `MONTHLY` | 月 |
| `CompoundFrequency` | `WEEKLY` | 周 |

这些是理解源代码的入口。入模保留原规则，不在 SQL 中展开完整计息算法。

## 4. 与主数据、报价怎样配合

| 资料 | 回答什么 | 主要入口 |
| --- | --- | --- |
| 金融工具主数据 | 这个利率编号叫什么、属于什么类别 | `D_REF_INSTRUMENT`，T02 扩展表保留 `SCR_TYPE_SRC='RATE_INDEX'` |
| 货币利率属性 | 期限、计息、结算及日历规则是什么 | 本篇 `T02_TIT_IRA_CRRC_ATTR` |
| 利率报价 | 某个报价日期的利率是多少 | `M_REF_CBOND_RATE` → `T02_IRA_INDX_INFO`，在行情章节展开 |

身份通过工具内码关联；进入模型后，下游可以用 `SECU_ID` 将身份和属性接起来。实际报价仍需结合其报价日期。

## 5. 下游实际怎么用

风控任务 **171040** 输出 **`DM_RSK_N.CRRC_MKT_INTRT_BASE_INFO`**，取数方式是：

1. 从 TIT 扩展工具资料的 01 组中选择 **`SCR_TYPE_SRC='RATE_INDEX'`**，确定要输出哪些利率工具。
2. 按内码关联 02 组的 WIND 编码，补市场数据代码。
3. 按 `SECU_ID` 左关联本篇属性表，取得期限、日算惯例、结算规则和日历等。
4. 属性中的名称为空时，用工具简称补充；属性中的币种为空时，用工具标准币种反查源币种补充。

**这个输出以利率工具身份为主，属性负责补规则。** 因此，缺少属性记录时，利率工具仍可能出现在该输出中，部分规则字段为空。

利率数值另由报价链输出到风控 `CRRC_MKT_INTRT`，与这里的基础规则分别使用。
