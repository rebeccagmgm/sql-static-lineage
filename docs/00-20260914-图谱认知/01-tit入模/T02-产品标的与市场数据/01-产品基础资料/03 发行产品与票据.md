# 03 发行产品与票据

**这一组资料讲的是：发行了一款什么产品，它的期限、本金、发行和认购情况是什么；如果以票据形式发行，票据采用什么编号、计息和赎回条款。**

先抓住三个对象：**产品主档、票据条款、产品底层资产关系**。前两个放在本章，第三个在 04 展开。

## 1. 分哪几篇读

| 子篇 | 主要讲清什么 | 取数原表 | 入模表／调度 |
| --- | --- | --- | --- |
| [03.1 发行产品](03.1%20发行产品.md) | 产品身份、类型和状态，发行与认购金额、数量、期限 | `P_PRD_PRODUCT` | `T02_TIT_PRD_INFO`；160750、211488 |
| [03.2 票据条款](03.2%20票据条款.md) | 产品对应的票据编号、交易方式、利息类别和赎回基准 | `P_PRD_NOTES` | `T02_TIT_NOTE_INFO`；160751、211487 |
| 延伸：[04.1 发行产品底层资产](04.1%20发行产品底层资产.md) | 发行产品关联哪个金融工具、哪笔内部交易 | `P_PRD_PRODUCT_ASSET` | `T02_TIT_PRD_ASSET_INFO`；160753、211486 |

本章原表均位于 **`ODATA_N_TIT`**，模型表均位于 **`PDATA_NEWS_N`**，上述入模目标均为 `SRC_ID='TIT'、GRP_ID='01'`。

## 2. 产品、票据和金融工具怎样分清

| 对象 | 识别字段 | 用来回答什么 |
| --- | --- | --- |
| 发行产品 | `P_PRD_PRODUCT.KEY_PROD_ID` → `PRD_ID` | 哪一款发行产品？发行了多少、认购了多少、何时到期？ |
| 票据 | `P_PRD_NOTES.KEY_NOTE_ID` → `NOTE_ID`；另带 `KEY_PROD_ID` | 这份票据属于哪个产品，采用什么条款？ |
| 金融工具 | `D_REF_INSTRUMENT.KEY_INSTRUMENT_ID` | 产品关联的那个工具到底是什么、叫什么？ |
| 交易记录 | 通过产品交易流水或底层资产中的内部交易号连接 | 谁交易了这款产品，或产品关联哪份场外合约？ |

**`KEY_PROD_ID` 与 `KEY_INSTRUMENT_ID` 是两套对象编号。** 产品的 `PRD_ID` 不经过 `TIT-` 拼接，也不直接当作金融工具主数据的 `IN_CODE` 使用。

```text
发行产品 KEY_PROD_ID
    ├─ 票据条款：KEY_PROD_ID → KEY_NOTE_ID、ISIN、计息和赎回基准
    ├─ 底层资产：KEY_PROD_ID → KEY_INSTRUMENT_ID、INTERNAL_TRADE_ID
    └─ 产品交易流水：认购／交易记录 → 交易对手、数量和金额
```

主档中的“已认购数量、累计已认购金额”是产品层汇总字段。要查逐笔交易和交易对手，需继续查 T05 产品交易流水；不能从主档中反推出每笔认购。

## 3. 入模以后具体用在哪里

| 用途 | 怎样使用这组资料 | 消费目标／调度 |
| --- | --- | --- |
| 香港票据明细 | 产品提供期限和发行信息；票据提供利息类别；底层资产关系帮助找到合约利息腿 | `DM_FMS_N.GFHK_FND_NOTE_DETAIL`；163640 |
| 香港融资票据负债 | 取 `FundingNote` 产品，结合交易对手和合约利息腿补齐负债资料 | `DM_RSK_N.TRD_RSK_HK_LIAB_BASIC_DAY` 的 TIT 分支；176443 |
| AMCNote 财务价格 | 产品提供发行数量，底层资产提供交易关联，再结合互换估值形成单价 | `DM_FIN_N.CIV_MARKET_PRICES_SPT_CP_T` 的 TIT 分支；199871 |
| 财务票据交割明细 | 产品、票据交易流水和估值共同提供交割与利息变动信息 | `DM_FIN_N.CIV_TRD_BILL_DELI_DTL_DAY_HK`；202510 |
| 基础资料分发 | 分别复制产品、票据、底层资产资料 | `DM_OTC_N` 对应同名表；181136、181140、181142 |

各消费有自己的范围。例如票据明细排除作废及指定测试产品，AMCNote 价格分支限制产品类型、到期日和发行数量。这些筛选与计算发生在消费层，产品入模承接的是当日来源主档。
