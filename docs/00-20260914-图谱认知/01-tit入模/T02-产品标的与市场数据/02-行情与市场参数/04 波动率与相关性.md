# 04 波动率与相关性

**波动率描述一个标的的波动程度；相关性描述两个标的之间的联动程度。这一组保存源端提供的参数对象、结构和日期数值，供定价与风险资料继续使用。**

查询某份期权所用的波动率，先要知道它选哪张曲面，再看对应日期、期限和执行价。查询相关性，则要同时认出两端标的，不能只拿一个“因子编号”去找数值。

## 1. 两篇分别讲什么

| 主题 | 核心问题 | 阅读入口 |
| --- | --- | --- |
| 波动率曲面 | 曲面是谁的、结构怎样定义、某日节点数值在哪里，以及哪些节点进入风控因子行情 | [04.1 波动率曲面](04.1%20波动率曲面.md) |
| 相关性 | X、Y 到底是什么编号，怎样查两端工具，怎样进入相关性因子和期权结果 | [04.2 相关性](04.2%20相关性.md) |

**这两类入模接收已有参数，不在 SQL 中重算历史波动率、拟合曲面或计算相关系数。**

## 2. 来源、分组与内容

以下原表均在 `ODATA_N_TIT`，目标表均在 `PDATA_NEWS_N`。

| 内容 | 原表 → 入模表 | 来源／分组 | 调度 |
| --- | --- | --- | --- |
| 曲面定义 | `D_REF_VOL_SURFACE` → `T02_FIN_VOL_CURV_SURF` | TIT／01 | 103242 |
| 曲面结构 | `D_REF_VOL_SURFACE_STRUCTURE` → `T02_FIN_VOL_CURV_SURF` | TIT／02 | 103245 |
| 曲面实例 | `D_REF_VOLSURFACE_INSTANCE` → `T02_FIN_VOLA_INSTC` | TIT／01 | 103248 |
| 相关性数值 | `D_REF_CORRELATION_DAILY_INFO` → `T02_OTH_CORRE_FCTR` | TIT／01 | 117794 |

定义和结构分别保存曲面规则、节点维度；实例再把日期和波动率数值放到这些维度上。三者通过曲面编号连接，不能只查定义表就认为已经查到了波动率。

## 3. 先认对编号，再取数值

| 编号 | 指向什么 | 读取方式 |
| --- | --- | --- |
| `KEY_VOL_SURFACE_ID`／`CURV_SURF_ID` | 一张波动率曲面 | 连接曲面定义、结构和实例 |
| 曲面定义的 `KEY_INSTRUMENT_ID` | 这张曲面的标的工具 | 回金融工具主数据识别标的 |
| `CORRELATION_X/Y` → `FCTR_X/Y` | 相关性两端的 **TIT 工具内码** | 分别关联工具 `IN_CODE`，不是 LBR 的 `FCTR_ID` |
| LBR `FCTR_ID` | 风控因子自身 | 通过相应因子定义对应曲面或标的对 |

相关性模型字段虽叫“因子 X／Y”，源注释明确它们是两端标的的 `keyInstrumentId`。这也是相关性消费能回到工具代码表查询名称和代码的原因。

## 4. 已确认的使用方式

- **波动率因子行情（176548）**：选定 LBR 处理方法与期限型曲面后，按曲面编号接 TIT 实例；该分支将 `INTRPN ÷ 100` 输出。
- **财务曲面资料（226123、226134）**：分别接收定义／结构和指定曲面日期的实例数值。
- **相关性因子行情（194609）**：将 LBR 因子定义中的标的对，与 TIT 相关性的 X／Y 顺序对应。
- **相关性视图及期权结果（163633、176827）**：补两端工具代码；其中期权结果进一步匹配标的与相应币种兑人民币汇率工具的相关性。

查日期时，曲面以 `CURV_SURF_DATE`、相关性以 `TRD_DT` 为准。尤其曲面实例入模没有按源当天 `BUSI_DATE` 过滤，处理日期不等于每个实例的参数日期。
