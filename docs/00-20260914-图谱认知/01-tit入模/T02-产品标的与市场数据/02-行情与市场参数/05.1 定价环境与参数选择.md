# 05.1 定价环境与参数选择

**一套定价环境可以关联多条曲线、多个标的的波动率曲面。环境先有自己的编号和名称，再按币种、交易类型、标的及看涨／看跌范围配置具体参数。**

例如，某环境下给标的 A 选择曲面 V、分红曲线 D，这两条配置保存的是“选谁”。要取得某日、某期限的参数值，还要继续查 V 的曲面实例和 D 的曲线行情。

## 1. 从哪里取，进入哪张表

| 配置内容 | 取数原表 | 入模表 | 来源分组／调度 |
| --- | --- | --- | --- |
| 环境身份 | `ODATA_N_TIT.R_CFG_PRICING_ENV_DEF` | `PDATA_NEWS_N.T02_FIN_PRCG_ENV_CURV` | TIT／02；226617 |
| 环境选择普通曲线 | `ODATA_N_TIT.D_CFG_PRICING_ENV_CURVE` | 同上 | TIT／01；103238、103239 |
| 环境选择分红曲线 | `ODATA_N_TIT.D_CFG_PRICING_ENV_DIV_CURVE` | `PDATA_NEWS_N.T02_FIN_PRCG_ENV_DIVD_CURV` | TIT／01；103252、103253 |
| 环境选择波动率曲面 | `ODATA_N_TIT.D_CFG_PRICING_ENV_VOL_SURF` | `PDATA_NEWS_N.T02_FIN_PRCG_VOL_CURV_SURF` | TIT／01；103249、103251 |

四类都取处理业务日 `BUSI_DATE` 的源记录。入模主要承接配置；普通曲线配置转换币种，分红曲线和曲面配置按标的内码左关联 TIT 主数据补统一证券编号。

## 2. 环境身份与选择关系怎样区分

`T02_FIN_PRCG_ENV_CURV` 一张表保存两种内容：

| 目标分组 | 主要取数原字段 → 入模字段 | 这条记录描述什么 |
| --- | --- | --- |
| TIT／02 | `KEY_PRICING_ENV_ID` → `PRCG_ENV_ID`、`REC_ID` | 环境自身的编号 |
| TIT／02 | `PRICING_ENV_NAME`、`PRICING_ENV_TYPE` → `PRCG_ENV_NAME`、`PRCG_ENV_TYPE` | 环境名称与类型，源值直接承接 |
| TIT／01 | `ID` → `REC_ID`；`KEY_PRICING_ENV_ID` → `PRCG_ENV_ID` | 某环境下的一条曲线选择配置 |
| TIT／01 | `CURRENCY`、`TRADE_TYPE` → `CRRC_CD`、`TRD_TYPE_CD` | 该条配置适用的币种、交易类型 |
| TIT／01 | `KEY_CURVE_ID` → `DIVD_CURV_ID` | 选中的普通曲线编号 |

两组通过 **`PRCG_ENV_ID`** 联系。02 没有填曲线、币种和交易类型；01 没有填环境名称和类型。读取环境的完整说明时，可以把身份资料和选择配置按环境编号组合起来，不能把两组当作同一种重复记录。

**TIT／01 的 `DIVD_CURV_ID` 实际来自普通配置的 `KEY_CURVE_ID`。** 这个目标字段虽然名为“分红曲线编号”，本分支仍应按普通曲线选择关系理解；专门的分红曲线选择在下一张表中。

币种通过 `T02_PUB_COVT_CONST` 的 **WD／`fin00001`** 转换。`TRADE_TYPE`、环境类型没有在这几项 SQL 中另行转换；具体枚举需依据对应源字典，不能借用合约表的业务类别代码解释。

## 3. 分红曲线与波动率曲面怎样选

| 选择关系 | 取数原字段 → 入模字段 | 读取要点 |
| --- | --- | --- |
| 共同的环境 | `KEY_PRICING_ENV_ID` → `PRCG_ENV_ID` | 这条配置属于哪套环境 |
| 共同的标的 | `KEY_INSTRUMENT_ID` → 拼接 `UNDRL_SRC_SYS_PRDNO`，关联取得 `UNDRL_SECU_ID` | 给哪个工具选择参数 |
| 分红曲线 | `KEY_DIV_CURVE_ID` → `DIVD_CURV_ID` | 该标的选用哪条分红曲线 |
| 波动率曲面 | `KEY_VOL_SURFACE_ID` → `CURV_SURF_ID` | 该标的选用哪张曲面 |
| 曲面权利范围 | `CALL_OR_PUT` → `RIGH_DIV` | 看涨、看跌或任意范围，直接承接 |

源 `CALL_OR_PUT` 使用 `CallPut` 字典；已列的值为：

| 值 | 含义 |
| --- | --- |
| `CALL` | 看涨 |
| `PUT` | 看跌 |
| `ANY` | 任意 |

若同一环境和标的同时存在 `ANY`、`CALL` 等记录，当前入模没有替使用者判断优先级。它保存全部来源配置，具体匹配顺序仍要看源端选择规则或实际消费。

这两张表的 `SRC_SYS_PRDNO` 是 **`TIT-`＋环境编号**，`UNDRL_SRC_SYS_PRDNO` 才是 **`TIT-`＋标的内码**。两个字段的编号对象不同。

## 4. 怎样继续找到具体参数值

```text
环境 PRCG_ENV_ID
    ├─ 普通曲线配置 DIVD_CURV_ID（源 KEY_CURVE_ID）
    │    └─ 普通曲线定义 CURV_CD_SRC
    │         └─ 定义引用的 CURV_ID_SRC → 收益率曲线行情 REC_ID
    ├─ 分红曲线配置 DIVD_CURV_ID
    │    └─ 分红曲线定义与相应曲线行情编号
    └─ 曲面配置 CURV_SURF_ID
         └─ 曲面定义与实例 CURV_SURF_ID
              └─ 曲面日期、期限、执行价对应的数值
```

这是依照已保存业务键继续查参数的路径。查询时同时保留来源和分组；曲线、曲面还需要选定日期及节点维度。环境配置本身没有收益率或波动率数值。

## 5. 目前哪些用途已经确认

| 消费目标／调度 | 实际范围与作用 |
| --- | --- |
| `DM_CTMS_N.WT_TIT_SYS_USER_PRICING_RIGHTS_RT`；208181 | 用户资源类型限定 `PRICINGENV`，按资源 ID 关联环境 TIT／02 的 `REC_ID`，补环境名称；权限来自用户角色资源资料 |
| `DM_FIN_N.CIV_FIN_PRCG_ENV_CURV`；226709 | 只读取 TIT／02 环境身份资料，承接名称、类型等；不读取 01 曲线选择分支 |
| `DM_FIN_N.CIV_FIN_PRCG_VOL_CURV_SURF`；226067 | 读取 TIT／01 的环境—标的—曲面配置并分发 |

现有图谱没有检出专门读取 `T02_FIN_PRCG_ENV_DIVD_CURV` 的直接消费；同表环境 01 曲线选择分支也不能用上述仅取 02 的消费代替证明。当前可以讲清配置保存的关系，具体某份合约如何调用它还需定价过程的对应记录。
