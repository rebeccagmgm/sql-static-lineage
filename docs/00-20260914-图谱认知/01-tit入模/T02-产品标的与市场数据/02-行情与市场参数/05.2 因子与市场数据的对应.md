# 05.2 因子与市场数据的对应

**这里的因子可以先理解为风控识别一项市场数据的编号。因子定义把这个编号与工具或曲线联系起来，行情消费再为它配上具体日期的价格、净值或曲线数值。**

例如，工具 A 的报价按工具内码匹配到因子 F，输出就带上 F 的因子编号；分红曲线 D 的各期限数值，也可以通过曲线因子定义对应到另一个因子。A、F、D 在这里仅用于说明三种编号的角色。

## 1. 主体来自 LBR，TIT 参与哪些环节

| 资料 | 取数原表 | 入模表 | 来源分组／调度 |
| --- | --- | --- | --- |
| 权益类因子 | `ODATA_N_LBR.M_REF_EQUITY_FACTOR_DEF` | `PDATA_NEWS_N.T02_FIN_EQUI_FCTR_INFO` | **LBR／01**；168302 |
| 曲线类因子 | `ODATA_N_LBR.M_REF_FACTOR_CURVE_DEF` | `PDATA_NEWS_N.T02_FIN_CURV_FCTR_DEF` | **LBR／01**；170265 |

两项都按处理业务日读取 LBR 源表，再做三类补充：

1. 按源 `UNDERLYING_INS_ID` 左关联 **TIT** 工具主数据的 `IN_CODE`，取得 `SECU_ID`。
2. 按 **WD／`fin00001`** 转换币种代码。
3. 使用 **TIT 的 `D_CFG_DICTIONARY_DESC`／Exchange 字典**补交易所或日历名称。

源因子编号直接保留，入模没有生成新的行情数值。主体来源为 LBR，不因关联了 TIT 资料就改成 TIT 因子。

## 2. 权益因子怎样对应到工具

| 取数原字段 → 入模字段 | 表示什么 |
| --- | --- |
| `KEY_FACTOR_ID` → `FCTR_ID`、`REC_ID` | 因子自己的编号 |
| `UNDERLYING_INS_ID` → `TIT-`＋内码写 `SRC_SYS_PRDNO` | 因子对应的工具身份 |
| 按内码关联 → `SECU_ID` | 对应工具的统一证券编号 |
| `UNDERLYING_CODE`、`UNDERLYING_NAME` → `SCR_CD`、`SCR_NAME` | 来源提供的证券代码、名称 |
| `SECURITY_TYPE` → `SRC_SCR_TYPE` | 保留源证券类型 |
| `CURRENCY` → `CRRC_CD` | 转换后的币种 |
| `EXCHANGE` → `EXCH`，字典补 `EXCH_CH_NAME` | 市场代码与说明 |

**`FCTR_ID` 是因子编号，工具编号藏在 `SRC_SYS_PRDNO` 的来源对应中。** 查名称、证券类别时沿工具键回主数据；查某个因子的行情时沿因子 ID 查结果。不要预设一个工具在所有因子定义中只对应一个因子。

## 3. 曲线因子又多保存了什么

| 内容 | 取数原字段 → 入模字段 | 业务含义 |
| --- | --- | --- |
| 因子身份 | `KEY_FACTOR_ID` → `FCTR_ID`、`REC_ID` | 标识这项曲线因子 |
| 工具对应 | `UNDERLYING_INS_ID` → **`LBR-`＋内码**写 `SRC_SYS_PRDNO`；同时关联 TIT 工具编号 | 源标的对应关系；该字段前缀与权益因子表不同 |
| 工具说明 | `UNDERLYING_CODE`、`UNDERLYING_NAME` → `SCR_CD`、`SCR_NAME` | 源代码与名称 |
| 双币种 | `CURRENCY`、`CURRENCY2` → `CRRC_CD`、`CRRC_CD2` | 两列分别转换，是否都适用由源记录决定 |
| 因子类型 | `CURVE_TYPE` → `FCTR_TYPE` | 保留源类型，不在本任务另作分类换码 |
| 分红曲线对应 | `KEY_DIV_CURVE_ID` → `DIVD_CURV_ID` | 后续连接分红曲线行情的明确编号 |
| 计息规则 | `COMPOUNDING_TYPE`、`COMPOUNDING_FREQ`、`DAYCOUNT` → `COMPD_INTR_REGU`、`COMPD_INTR_FREQ`、`DAY_COUNT_CONVN` | 复利规则、频率和日算惯例 |
| 日期规则 | `DATE_ROLL`、`CALENDAR` → `DATE_ADJ_CONVN`、`EXCH` | 工作日调整规则与日历代码 |
| 数值扩展规则 | `INTERPOLATION_TYPE`、`EXTRAPOLATION_TYPE` → `INTRP_METHOD`、`EXTRP_METHOD` | 内插、外插方法配置 |
| 两项开关 | `EOM`、`ALLOW_NEGA_RATE` → `MONTH_END_REGU_FLAG`、`PERM_NEGA_INTR_FLAG` | 月末规则、是否允许负利率；`Y→1`、`N→0`，其他值写空串 |

两张因子表的 `SRC_ID` 都是 LBR，但 `SRC_SYS_PRDNO` 拼接前缀分别是 TIT、LBR；曲线因子的标的内码仍被当前入模拿去匹配 TIT 主数据。理解编号要按这条实际关系，不能只凭前缀判断它必然属于另一套工具键。

这些字段描述因子定义及规则。是否真的执行内插、允许负利率如何作用到某次计算，要看计算方，本次入模只承接配置。

## 4. 一项工具行情怎样变成价格类因子行情

消费 **182738** 输出 `DM_RSK_N.PRIC_FCTR_MKT_QUOT_DAY`，其中 TIT 数据分支的主线是：

```text
TIT 工具行情：工具内码＋报价日＋价格／净值
    ↓ 按工具内码对应
LBR 权益因子定义：工具内码 → FCTR_ID
    ↓
价格类因子行情：FCTR_ID＋报价日＋相应数值
```

普通行情分支读取 `TYZX_EXCH_QUOT_H_FK` 的 TIT／01，按工具内码连接权益因子定义；还可连接该任务另外读取的外汇因子定义，要求至少匹配一种因子。权益因子命中时优先取其因子 ID。

风管行情分支读取 `T02_PRD_UNIT_NAV_S_TIT` 的 TIT／01，**内关联权益因子定义**，主要输出收盘价与单位净值。同工具、同报价日已有风管记录时，普通 TIT 行情对应记录被排除；这是整条来源选择，不是各价格字段逐项补空。风管分支还须命中权益因子，不能保证所有源行情最终都有因子输出。

该消费另有 LBR 结果分支。本篇说明 TIT 工具数据与权益因子之间的连接，不据此将整个输出全部归为 TIT 行情。

## 5. 分红曲线怎样接到因子行情

消费 **182230** 输出 `DM_RSK_N.DIV_CURV_FCTR_MKT_QUOT`：

1. 从 `T02_FIN_FCTR_DEF` 选 LBR／01 且处理方式为 **`DIV_CURVE_DEF_SYNC`** 的因子。
2. 按 `FCTR_ID` 连接本章曲线因子定义，取得 `DIVD_CURV_ID`。
3. 用 `DIVD_CURV_ID` 连接 `T02_FIN_CURV_MKT_QUOT` 的 TIT／02 `REC_ID`。
4. 输出因子 ID、曲线编号、日期、期限与 `YIELD`。

```text
FCTR_ID → DIVD_CURV_ID → 曲线行情 REC_ID
                              └─ 日期＋期限＋YIELD
```

这条已查链路同时保留了因子与曲线两套编号；当前查询没有取 TIT／03 的另一来源分红曲线行情。

## 6. 怎样继续读其他因子

波动率、相关性等消费还会使用各自的 LBR 因子定义和总因子表，按处理方式与曲面／标的对进行连接。本章两张表只覆盖权益类和曲线类，不能把它们当作全部风险因子定义。

其中，TIT 相关性表虽然把两端命名为 `FCTR_X`、`FCTR_Y`，已查源注释和消费表明它们对应 TIT 工具内码；它们与 LBR 的 `FCTR_ID` 需要通过各自映射关系连接。
