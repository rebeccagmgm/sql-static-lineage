# 02 汇率与利率

**本组保存两个不同对象的每日数值：币种对应人民币的中间价，以及利率工具在某一天的报价。**

汇率围绕币种和报价日期查找；利率报价围绕金融工具内码和报价日期查找。利率工具的期限、计息惯例等放在基础资料中，具体报价放在这里。

## 1. 两组资料的入口

| 子篇 | 取数原表 → 入模表 | 主要内容／调度 |
| --- | --- | --- |
| [02.1 汇率中间价](02.1%20汇率中间价.md) | `ODATA_N_TIT.D_REF_RMB_MIDRATE`、`ODATA_N_TIT.D_REF_RMB_MIDRATE_PB` → `PDATA_NEWS_N.T02_FXR_CFETS_QUOT` | 币种、报价日期、中间价；105616、144298 |
| [02.2 利率报价](02.2%20利率报价.md) | `ODATA_N_TIT.M_REF_CBOND_RATE` → `PDATA_NEWS_N.T02_IRA_INDX_INFO` | 利率工具、报价日、`RATE × 100`；165804 |
| 同篇的利率批次 | `ODATA_N_TIT.M_REF_CBOND_RATE_P` → `PDATA_NEWS_N.T02_IRA_INDX_INFO_PB` | 0830h 批次报价；239826 |

以上目标均为 `SRC_ID='TIT'、GRP_ID='01'`；利率批次另带 `TIME_FLAG='0830h'`。

## 2. 查找方式为什么不同

| 要查什么 | 查找维度 | 还要结合什么 |
| --- | --- | --- |
| 某币种某天的人民币中间价 | 源币种 `CURRENCY`＋`QUOTE_DATE` | 币种转换、报价方向及源端单位 |
| 某项利率某天的报价 | `KEY_INSTRUMENT_ID`＋`QUOTE_DATE` | 主数据名称和外部代码；工具的币种、期限、计息惯例 |
| 同一利率的批次报价 | 工具＋报价日期＋目标批次 | 批次标识与源取数条件 |

汇率入模没有使用金融工具主数据补证券身份。利率报价则需要通过工具内码关联主数据，才能解释报价属于哪个利率工具。

## 3. 数值与日期最容易混淆的地方

- **汇率不在入模中取倒数或调整倍率。** `MIDRATE` 直接写 `MID_PRICE`，标准币种中的一端固定为人民币 `156`。
- **利率在入模中乘 100。** 例如源 `RATE=0.025`，模型 `INTRT=2.5`，含义为 `2.5%`；风控消费 166041 再除以 100。
- **报价日期决定数值属于哪天。** 目标处理日不是报价日；利率批次源条件甚至使用 `BUSI_DATE='h0830'` 这个固定标识。

汇率中间价适合解释外币与人民币的换算依据；它没有买价、卖价和外汇远期条款。利率报价是单个工具的日期序列；按不同期限组织的一组曲线节点在收益率曲线主题展开。
