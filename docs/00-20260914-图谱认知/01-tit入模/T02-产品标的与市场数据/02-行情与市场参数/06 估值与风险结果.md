# 06 估值与风险结果

**这一组保存源端已经得到的价格、敏感度、损益和估值。读一条记录，首先要知道它算的是哪笔交易、哪个工具或哪项标的，以及对应哪个日期。**

例如，同一份期权可以有交易层面的 NPV，也可以有分别针对两个挂钩标的的 Delta，还有标的之间的交叉敏感度。这几项结果分别回答不同问题，不能只凭“都是期权风险指标”就混成一张汇总表。

## 3. 拿到数据后，按这个顺序理解

1. **确认对象。** `TRADE_ID` 是交易编号，`KEY_INSTRUMENT_ID` 是工具编号，X／Y 是结果涉及的标的对；三者各有用途。
2. **确认结果日期。** 区分调度日、源业务日、行情日和到期／解禁日；限售股入模未按源 `BUSI_DATE` 过滤，实际估值日读 `TRD_DT`。
3. **确认数值层次。** 价格与 NPV、普通敏感度与单位敏感度、风险指标与损益金额，需要分别阅读。
4. **沿实际消费判断用途。** 相似表名只能帮助定位，连接关系仍以读取的物理表和字段为准。
