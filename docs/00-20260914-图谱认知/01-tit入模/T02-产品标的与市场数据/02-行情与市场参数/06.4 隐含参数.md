# 06.4 隐含参数

**这张表保存某个标的在指定观察日、指定到期日对应的隐含远期价格和隐含分红率，并注明其关联的隐含波动率曲面。**

例如，同一标的在同一天可以对应多个期权到期日，每个到期日各有一组隐含远期价和分红率。读数时需要保留到期维度，不能只留下“标的＋日期＋一个参数”。

## 1. 从哪里取，进入哪张表

| 取数原表 | 入模表 | 来源范围 | 调度 |
| --- | --- | --- | --- |
| `ODATA_N_TIT.D_REF_IMPLIED_METRICS` | `PDATA_NEWS_N.T02_TIT_IMPL_VOLA_SRFC_INDX_INFO` | `SRC_ID='TIT'、GRP_ID='01'` | 240855 |

目标表名含“隐含波动率曲面指标”，但该 TIT 分支实际只有隐含远期价格、隐含分红率两类结果。它没有承接波动率节点，也没有完整执行价维度。

## 2. 取数逻辑

1. 按源 `BUSI_DATE` 取处理业务日的数据。
2. 用 **`KEY_INSTRUMENT_ID = T02_TIT_SCR_BASE_INFO.IN_CODE`**，关联 TIT／01 工具资料，取得 `SECU_ID`。
3. 工具内码加 `TIT-` 写 `SRC_SYS_PRDNO`；标的、曲面、隐含结果直接承接。
4. 将 `AS_OF`、`EXPIRY_DATE` 的日期部分整理成日期键，分别保存观察日期和期权到期日。

主数据未匹配的源结果仍保留。入模没有读取期权市场报价、选择模型或反推出这些隐含值，结果已由源表提供。

## 3. 一条记录由哪几个维度描述

| 维度 | 源字段 → 入模字段 | 说明 |
| --- | --- | --- |
| 标的 | `KEY_INSTRUMENT_ID` → `SRC_UNDRL_ID` | 源注释明确为标的 ID；同时补统一证券编号 |
| 曲面 | `VOL_ID` → `SRC_SRFC_ID` | 源注释为标的对应的隐含波动率曲面 ID |
| 观察日期 | `AS_OF` → `OCCU_DATE` | 这组参数属于哪个观察时点的日期 |
| 期权到期日 | `EXPIRY_DATE` → `OPT_MATY_DATE` | 这组隐含值面向哪个到期日 |
| 入模数据日期 | 调度处理日 → `BUSI_DATE` | 区分模型处理日与上述观察日期 |

**先按标的、曲面、观察日期、到期日一起阅读。** 这组维度是理解记录的业务坐标；SQL 未做唯一性校验，目标 `REC_ID` 也为空，不能把某一单列当成唯一键。

## 4. 两个数值到底是什么

| 源字段 → 入模字段 | 保存内容 | 读数要点 |
| --- | --- | --- |
| `IMPLIED_FORWARD` → `IMPL_FWD_PRIC` | 对应到期日的隐含远期价格 | 按源端已经给出的价格读取；没有在入模用即期价、利率和分红率重算 |
| `IMPLIED_DIVIDEND` → `IMPL_DIVD_RATI` | 对应到期日的隐含分红率 | 不等于公司已经宣布的每股现金分红；本表没有除息日或派息事件字段 |

这里“隐含”是源字段的业务定义。具体由哪些市场报价、使用什么模型得到，当前资料没有源端生成算法，不能仅凭两列值判断反解方法。

本分支没有乘以或除以 100。分红率使用小数还是百分数、是否年化，远期价格使用什么币种和报价单位，当前源注释未充分说明；应保留源值，结合源端规则后再换算。

## 5. 与工具主数据、曲面实例有什么关系

```text
标的 KEY_INSTRUMENT_ID
    └─ 工具主数据：名称、类别、证券编号

隐含结果：标的 + VOL_ID + AS_OF + EXPIRY_DATE
    ├─ 隐含远期价格
    └─ 隐含分红率
```

| 想查什么 | 去哪里找 | 本表是否已经给出 |
| --- | --- | --- |
| 标的名称与工具类别 | 金融工具主数据，按工具内码查 | 本表主要保留编号 |
| 该到期日的隐含远期价、分红率 | 本篇结果表 | 是 |
| 曲面名称、规则及标的关系 | 曲面定义 `D_REF_VOL_SURFACE` | 本表只有 `VOL_ID` 引用；跨表连接仍需核对其与 `KEY_VOL_SURFACE_ID` 的对应 |
| 曲面某个期限、执行价的波动率 | 曲面实例 `D_REF_VOLSURFACE_INSTANCE` | 否 |
| 某笔交易实际使用哪个参数 | 该交易的定价结果、环境和参数选择记录 | 本表没有交易编号，不能单独证明 |

因此，用这张表可以展开一个标的在不同到期日的两类参数；要还原完整波动率曲面或某笔交易的定价过程，还需要对应定义、实例及交易使用关系。

## 6. 日期和创建时间怎么读

`AS_OF` 说明参数观察日期，`EXPIRY_DATE` 说明面向的到期日。`CREATED_DATETIME` 写 `SRC_CREATE_TIME`，`UPDATED_DATETIME` 写 `REC_UPD_TIME`，描述源记录创建与更新；它们不是额外的报价或到期日期。

入模对观察时间只保留日期部分。如果源端同一天生成多次结果，本表当前字段不足以单凭 `OCCU_DATE` 区分所有时点，不能自行认定某条就是当日最终值。
