# 03 收益率与分红曲线

**这一组回答：在某个日期，针对不同期限，分别使用什么利率或分红参数。**

曲线可以先理解为一张“期限 → 数值”的表。与一条单独的利率报价相比，曲线还需要说明自己叫什么、使用什么币种和日期规则，以及引用哪组行情。TIT 将这些定义和每日节点数值分别提供给数综。

## 1. 分成哪两类

| 主题 | 主要讲什么 | 阅读入口 |
| --- | --- | --- |
| 收益率曲线 | 普通曲线定义怎样引用 WIND 行情曲线；怎样取得各日期、期限上的到期、即期和远期利率 | [03.1 收益率曲线](03.1%20收益率曲线.md) |
| 分红曲线 | 某标的对应哪条分红曲线；怎样取得分红收益率，怎样对应到 LBR 因子 | [03.2 分红曲线](03.2%20分红曲线.md) |

分红曲线在这里描述定价使用的分红收益率参数；逐次分红的金额、除权日和登记日等事件资料，属于产品基础资料中的公司行为。

## 2. 三层资料怎样配合

| 层次 | 回答什么 | 主要入模表 |
| --- | --- | --- |
| 曲线定义 | 这条曲线叫什么、服务哪个币种或标的、采用哪些规则？ | `PDATA_NEWS_N.T02_FIN_CURV_DEF` |
| 外部曲线代码对应 | 引用的 WIND 曲线编号对应什么外部代码和描述？ | 同表的 `TIT／03` |
| 曲线行情 | 这条行情曲线在某日、某期限上提供什么数值？ | `PDATA_NEWS_N.T02_FIN_CURV_MKT_QUOT` |

普通曲线中，**定义自身的编号与它引用的行情曲线编号是两个字段**。分红曲线还要保留所属标的，才能回答“这是谁的分红参数”。

## 3. 来源和入模分支

以下原表均在 `ODATA_N_TIT`，目标表均在 `PDATA_NEWS_N`。

| 内容 | 原表 → 入模表 | 来源／分组 | 调度 |
| --- | --- | --- | --- |
| 普通曲线定义 | `D_REF_CURVE` → `T02_FIN_CURV_DEF` | TIT／01 | 103203 |
| 分红曲线定义 | `D_REF_DIV_CURVE_DEF` → `T02_FIN_CURV_DEF` | TIT／02 | 103207 |
| WIND 代码对应 | `TIT_R_REF_INSTRUMENT_WIND_CURVE_S` → `T02_FIN_CURV_DEF` | TIT／03 | 172069 |
| 收益率行情 | `D_REF_WIND_YIELD_CURVE` → `T02_FIN_CURV_MKT_QUOT` | TIT／01 | 103198 |
| 分红行情 | `D_REF_DIV_CURVE` → `T02_FIN_CURV_MKT_QUOT` | TIT／02 | 103200 |
| 另一来源分红行情 | `M_REF_DIV_CURVE` → `T02_FIN_CURV_MKT_QUOT` | TIT／03 | 228422 |

两张模型表各有自己的分组含义：**定义 03 是 WIND 代码对应，行情 03 是另一来源的分红数值。** 连接时使用业务编号，不能仅凭分组号相同配对。

## 4. 读懂这一组，抓住三条关系

- **普通曲线定义 → 行情曲线**：定义的 `CURV_ID_SRC` 来自 `QUOTE_REFERENCE_ID`，与收益率行情的 `REC_ID` 对应。
- **标的 → 分红曲线 → 曲线节点**：分红定义保存工具内码；分红行情按曲线编号、报价日期和期限给出数值。
- **LBR 因子 → 分红曲线**：因子定义中的 `DIVD_CURV_ID` 对应 TIT 曲线行情编号，因子编号本身不是曲线编号。
