## 1. 交易对手怎样变成模型当事人

ref_counterparty

`CONCAT('TIT060-', ID)`：确定**是哪一个当事人**

| TIT 源字段条件                   | 模型码值     | 字典含义        |
| --------------------------- | -------- | ----------- |
| `CTPTY_TYPE = 'INDIVIDUAL'` | `190400` | **我司个人关联人** |
| 其他情况                        | `290203` | **自营交易对手**  |


| #   | 贴源表                            | 这块关注的信息     | 参与加工的 T01 模型表                                                                                                                                                                                                        |
| --- | ------------------------------ | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
