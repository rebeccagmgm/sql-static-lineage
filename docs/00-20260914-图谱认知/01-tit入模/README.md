# TIT 从源系统到入模

核对日期：2026-09-14。当前图谱版本：`8651e582`，本次在线查询状态为 `READY`。

TIT 已有足够证据开展入模分析。调查入口应同时看原库对象、TIT 贴源表、加工任务和模型目标；`odata_n_tit` 库名、任务名称及 `src_tbl` 标签都不能单独证明真实来源。

## 先看三个结果

**源头能够继续往前追。** 在 638 个本地发现的 TIT 源名中，603 个匹配到当前图内实际写入；其中 549 个的写入任务包含身份已确认的非 Hive 原库读取。原库入口包括 `titans_dm`、`titans_tradeflow`、`titans_product`、`titans_margin` 等。部分贴源对象经过 Hive 再加工，部分汇合其他系统输入，不能全部当作原系统直拷贝。原库对象之后的视图定义、应用同步和当前在用任务仍需分别取证。

**“未进十大主题”需要分开判断。** 按已存 SQL 检索候选分类，638 个源名分成以下四组。分组互斥，目标共现仍不等于逐字段贡献。

| 源名分类 | 数量 | 当前能说到哪里 |
|---|---:|---|
| 命中 T01～T10 候选 | 166 | 至少一个候选任务与十大主题写入共现 |
| 命中其他模型候选 | 84 | 未命中十大主题，命中 T00、T98、T99 或 REF |
| 有其他加工去向 | 137 | 包括 `pdata_nds`、贴源再加工、其他层或应用输出，不能统一称作未入模 |
| 本地索引未发现消费任务 | 251 | 其中 239 个仍有图内写入证据；只证明本轮没找到后续消费 |

**图谱缺口不能直接按名字扩大。** 主模型库 `pdata_n`、`pdata_news_n` 中有 305 个检索候选任务；核对实际读取后，297 个取得了 TIT 参与任务的证据，另有 5 个实际读取 LSS、3 个宏来源声明为 LSS 但参数未闭合的旁支。297 个中，292 个已投影、4 个在图外、1 个只有调度节点。投影存在仍不保证字段或加工证据完整。

## 证据与完成范围

本轮完成源名清单、任务与主题候选、原库上溯索引、缺口甄别，以及代表字段的具体解读。297 个任务尚未全部逐字段解读；239 个“有写入而未发现消费”的对象也没有被定性为未入模。

源名起点复用 2026-09-12 的已存发现索引，并核对 666 个 TIT 候选任务的 SQL 哈希与当前本地证据库一致。源元数据快照分布于 2026-08-21～2026-09-08。图谱加工详情绑定当前发布版本；其中 SQL 的固化日期是快照参数，不代表当天运行。

原始对象说明中的【AI】及其他目录注释保留其来源状态；未按表名前缀补造业务定义。没有查询业务行数据，没有验证调度在用状态、生产关联唯一性、金额正确性或字典转换覆盖率。静态图谱及本地快照不是生产运行证明。
