# 02 合约主数据与条款

**合约主资料先说明是哪一笔业务，再描述这笔业务的本金、币种、日期、双方角色及专有条款。** 普通互换、极速互换、场外期权和外汇远期共享部分身份与关系表达，各自的条款结构仍需分别阅读。

## 1. 四类合约从哪里读

| 合约类型 | 主要贴源表 | 本篇组重点 | 阅读入口 |
| --- | --- | --- | --- |
| 普通互换（TRS） | `ODATA_N_TIT.D_REF_TRS` | 互换类型、生成渠道、双方身份、本金与计息等条款 | [02.1 普通互换](02.1%20普通互换.md) |
| 极速互换（极速 TRS） | `ODATA_N_TIT.D_REF_FAST_TRS` | 快速互换的源结构、Party B 资料及与普通互换的字段差异 | [02.2 极速互换](02.2%20极速互换.md) |
| 场外期权 | `ODATA_N_TIT.D_REF_OTC_OPTION_DEAL` | 合约条款、结构明细、费用及触发、终止、结算日期 | [02.3 场外期权](02.3%20场外期权.md) |
| 外汇远期 | `ODATA_N_TIT.D_REF_FX_FORWARD` | 双币种、双方支付金额与汇率用途 | [02.4 外汇远期](02.4%20外汇远期.md) |

以上是各篇的主要业务源表；结构、持仓或辅助资料在对应子篇展开。每篇保留来源字段、字典与入模调度，不能只凭产品名称把四类条款合成一套字段解释。

## 2. 合约资料与 OTC 交易主资料如何分工

`D_REF_TRS` 等合约资料描述具体品种的业务事实；`ODATA_N_TIT.D_TRD_OTC_TRADE` 通过 `KEY_OTC_TRADE_ID` 与合约匹配，提供账簿、工具键、业务类别和内部交易号等公共信息。

| 想知道什么 | 主要读取位置 | 继续阅读 |
| --- | --- | --- |
| 合约属于哪种品种，约定哪些条款 | 对应合约及结构资料 | 本组四个子篇 |
| 归哪本账簿 | 交易主资料中的 `KEY_BOOK_ID`，结合合约类别 | [03.3 合约→账簿](03.3%20合约→账簿.md) |
| 对应哪个金融工具记录 | 交易主资料中的 `KEY_INSTRUMENT_ID` | [05 合约与金融工具的关系](05%20合约与金融工具的关系.md) |
| 按哪种业务类型管理 | 交易主资料中的 `BUSINESS_TYPE` | [06.1 业务分类](06.1%20业务分类.md) |
| 谁是交易对手 | 对应合约资料中的当事人引用 | [04 当事人与角色](04%20当事人与角色.md) |
| 当前处于什么状态 | 合约资料中的 `CONTR_STATUS` 及转换规则 | [06.2 合约状态](06.2%20合约状态.md) |

完整来源矩阵见 [00.1 公共协议模型](00.1%20公共协议模型.md)。一份合约的完整资料需要按业务问题取用这些信息，不能把交易主表或某张合约表单独理解成全部业务资料。
