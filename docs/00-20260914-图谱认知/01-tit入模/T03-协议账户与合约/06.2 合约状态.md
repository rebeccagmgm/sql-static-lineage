# 06.2 合约状态

**协议状态回答：一份合约处于什么状态。** 普通互换、极速互换、期权、外汇远期均取源字段 `CONTR_STATUS`，经状态转换后写入 `PDATA_N.T03_AGT_STAT_H`。

## 1. 状态类型与状态值

| 信息 | 字段／字典 | 本次含义 |
| --- | --- | --- |
| 状态类型 | `Agt_Stat_Type_Cd`；CD040/AGT_STAT_TYPE_CD | 固定 `10`，字典名称“协议状态” |
| 源状态值 | `CONTR_STATUS`；TITANS 源域 `ContrStatus` | 源系统记录的草稿、生效、终止等状态 |
| 入模状态值 | `Agt_Stat_Cd`；标准字典 CD041/AGT_STAT_CD | 优先取转换表给出的标准码；标准码为 NULL 时保留源状态值 |

**`10` 表示记录“协议状态”这个维度，不表示合约已经生效。** 要判断具体状态，还要读 `Agt_Stat_Cd`。本地 CD040 还有其他状态维度，本次四个任务均只使用 `10`。

### 源状态字典：ContrStatus

| 源代码 | 字典名称 |
| --- | --- |
| `DRAFT` | 草稿 |
| `TOTRADE` | 待交易 |
| `EFFECTIVE` | 生效 |
| `TERMINATED` | 终止 |
| `CANCELED` | 作废 |

上表是源字典完整的五个业务码值，不是入模后的标准码对照，也不表示这些状态必须按表中顺序流转。

### 标准状态字典：CD041

本地 CD041 包含多个业务对象的 288 项状态。以下列出与本页状态阅读相关的部分名称，**尚未确认它们与上述源代码逐一对应**：

| 标准代码 | 字典名称 |
| --- | --- |
| `101` | 正常、生效 |
| `218` | 作废 |
| `225` | 待终止 |
| `226` | 已终止 |
| `229` | 未生效 |
| `252` | 待审核终止 |
| `253` | 待交易 |
| `255` | 草稿在途 |

“标准代码叫什么”由 CD041 定义，“源代码转换成哪个标准代码”由 `REF_CD_CVT_MAP` 定义。当前未取得转换表的实际映射行，不能仅凭中文相近认定 `TERMINATED → 226` 或 `DRAFT → 255`。

| 适用合约 | 合约源表 | 对象编号字段 | 状态源字段 | 协议类型／修饰符 | 调度 ID | 入模表 |

| 普通互换 | `D_REF_TRS` | `KEY_OTC_TRADE_ID` | `CONTR_STATUS` | `20206` | 103938 | `T03_AGT_STAT_H` |
