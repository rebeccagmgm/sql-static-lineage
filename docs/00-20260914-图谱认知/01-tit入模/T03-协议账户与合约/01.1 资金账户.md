# 01.1 资金账户

**资金账户是 TITANS 中承载业务资金管理的账户对象。** 账户资料回答“账户是谁的、使用什么币种、是否启用”；某份合约关联哪个账户，另由合约上的账户引用表达。

## 1. 来源与入模分工

原库逻辑表沿用已有资料：`titans_dm.capital_account`；主要贴源表为 `ODATA_N_TIT.D_CAPITAL_ACCOUNT`。

| 保存的内容 | 实际取数来源 | 入模表 | 调度 ID |
| --- | --- | --- | --- |
| 账户身份、持有人、币种和启用状态 | `D_CAPITAL_ACCOUNT`，身份任务 SQL 用源表参数读取 | `PDATA_N.T03_AGT` | 103929 |
| 持有人、管理人关系 | `ODATA_N_TIT.D_CAPITAL_ACCOUNT` | `PDATA_N.T03_AGT_PTY_RELA_H` | 103932 |
| 持有人、管理人关系的另一取数分支 | `ODATA_N_TIT.D_CAPITAL_ACCOUNT_P`，`BUSI_DATE='h1930'` | `PDATA_N.T03_AGT_PTY_RELA_H` | 222317 |

后两项的输入不同，不能仅凭相同目标表认定它们读取同一个快照。

## 2. 账户身份怎样表达

| 业务信息 | 源字段 | 入模表达 |
| --- | --- | --- |
| 账户编号 | `KEY_CAPITAL_ACCT_ID` | 写入 `Agt_Id`；修饰符与协议类型均为 `10220` |
| 持有人 | `KEY_CTPTY_ID` | 加 `TIT060-` 前缀，写入 `Agt_Holder` |
| 币种 | `CURRENCY` | 原样写入 `Crrc_Cd` |
| 创建日期 | `CREATED_DATETIME` | 取前十位日期并转换后写入 `Vld_Date`；这是 SQL 对目标生效日期的取值来源 |
| 启用状态 | `ENABLED` | 先按 `REF_CD_CVT_MAP` 转换；未取得非空标准码时保留源值，写入 `Agt_Stat_Cd` |

`103929` 的转码范围限定为 TIT、`CAPITAL_ACCOUNT.ENABLED → T03_AGT.Agt_Stat_Cd`。本次核对的取数段没有显式源 `BUSI_DATE` 条件，也没有只取已启用账户的筛选；源表参数与运行快照范围应分别看待。

## 3. 谁持有账户，哪份合约使用账户

**账户与当事人的关系**由 `103932 / 222317` 保存：`01` 为协议持有人，`12` 按 SQL 注释及已有手工映射解释为协议管理人。两类关系都取 `KEY_CTPTY_ID`，不能据此认定源表提供了两个不同主体。详细取数与代码依据见 [04 当事人与角色](04%20当事人与角色.md)。

**合约与账户的关系**从合约源资料的账户字段取得，见 [03.1 合约→资金账户](03.1%20合约→资金账户.md)。账户主资料自身不列出所有使用它的合约。

## 依据与导航

依据本地任务 `103929 / 103932 / 222317` 的 SQL 快照及已有 [公共协议模型](00.1%20公共协议模型.md) 来源矩阵；本次为静态取数核对。账户代码、日期和状态不等于账户当日余额或实际收付款。
