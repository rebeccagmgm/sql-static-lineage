## 2. 关系代码与对象编号分别表达什么

| 信息 | 对应字段 | 怎样理解 |
| --- | --- | --- |
| 当前对象 | `Agt_Id`、`Agt_Modifr` | 从哪份合约或哪本账簿出发 |
| 关系类型 | `Agt_Rela_Type_Cd` | 两个对象是什么关系，如 A17、N08 |
| 当前协议类型 | `Agt_Type_Cd` | 左端具体是哪种协议对象，如互换、期权 |
| 关联对象 | `Rela_Agt_Id`、`Rela_Agt_Modifr` | 关联到哪个具体账户、合约或账簿 |

**关系类型是字典码值，具体对象是编号。** 例如 `TRS-A — A17 → 账户 B` 中，A17 表示关系类型，账户 B 才是关联对象；本地 A17 字典记录未给出下级分类或进一步说明。

协议类型字典为 **`CD039 / AGT_TYPE_CD`**，本组用到的名称如下：

| 代码 | 字典正式名称 | 本次用途 |
| --- | --- | --- |
| `20206` | 场外衍生品互换合约 | 普通互换、极速互换合约 |
| `20207` | 场外衍生品期权合约 | 期权合约 |
| `20208` | 场外衍生品外汇远期合约 | 外汇远期合约 |
| `10220` | 投资管理客户资金账户信息 | 资金账户关联端使用的修饰符值 |
| `20411` | 场外衍生品交易账簿 | 账簿关联端使用的修饰符值 |

本组已查 SQL 的修饰符使用上述部分数字，但查到的是协议类型字典 CD039，不将它称为独立的修饰符字典。合约左端的协议类别固定为 `202`，对应 **CD038“场外合约”**。

## 3. 共同取数口径

- 各明细表中的源表均位于 `ODATA_N_TIT`，按 `BUSI_DATE = 加工日期` 取数。
- 账户、配对合约关系直接取合约表上的引用字段；账簿关系需要同时看合约表和交易表，具体来源在明细中分列。
- 关系记录中的编号不单独证明关联对象存在、资金已结算或合约仍存续。读取历史关系时，按 `Strt_Date <= 查询日期 AND End_Date > 查询日期` 选择有效版本，并保留来源、关系类型和两端修饰符。
