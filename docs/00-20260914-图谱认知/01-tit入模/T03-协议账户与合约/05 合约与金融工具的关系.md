**这条关系把合约编号接到交易表中的金融工具编号。** 工具自身的类别、名称与代码，在 T02 金融工具主数据中继续查；合约挂钩的股票、指数或篮子，要再按结构或持仓中的标的关系查。具体区别见 [T02：合约怎样找到自己的工具记录](../T02-产品标的与市场数据/01-产品基础资料/01%20金融工具主数据.md#41-合约怎样找到自己的工具记录)及[挂钩标的从哪里找](../T02-产品标的与市场数据/01-产品基础资料/01%20金融工具主数据.md#42-挂钩的股票指数或篮子从哪里找)。

以下保留原笔记的问题与交易样本分析；其中“未核验产品主数据”限定的是该次交易导出分析，工具主数据的后续整理以以上 T02 专题为准。

**这里保存的是“合约编号 → 交易表中的产品键 `KEY_INSTRUMENT_ID`”。** 任务 **105386** 从 `D_TRD_OTC_TRADE` 取得两端编号，写入 `PDATA_N.T03_AGT_PRD_RELA_H`。`D_REF_TRS` 等合约表只用于识别合约类别，不提供这条关系的产品编号。

这里的“产品键”是入模 SQL 对该字段的用途。源字段注释为“场外合约交易流水号”；本次导出没有产品名称、证券代码或产品结构，具体产品对象仍需产品资料解释。

## 1. 关系与字典

关系字段为 `Agt_Prd_Rela_Type_Cd`，字典域为 **`CD718 / AGT_PRD_RELA_TYPE_CD`（协议产品关系类型代码）**。本地该域的七个码值如下，本任务只使用 `01`。

| 关系代码 | 字典正式名称 | 本任务使用 |
| --- | --- | --- |
| `01` | 协议和交易标的 | 是 |
| `02` | 协议和所属产品主体 | — |
| `03` | PRD托管单元对应MOT产品 | — |
| `04` | 配比PRD托管单元对应PRD产品 | — |
| `05` | 配比PRD托管单元对应管理人企业 | — |
| `06` | PB资金账户对应PB产品 | — |
| `07` | PB资产单元对应PB产品 | — |

这里的 `01` 只表示协议与产品的关系类型。`Prd_Id` 和 `Src_Prd_Id` 保存同一个源键的两种形式，前者加 `TIT-` 前缀，后者保留原值；“源产品”并不是另一种产品类别。

| 对象关系       | 合约源表（类别识别）              | 合约修饰符   | 交易源表（合约→产品编号）     | 调度 ID  | 入模表                  |
| ---------- | ----------------------- | ------- | ----------------- | ------ | -------------------- |
| 普通互换合约→交易表产品键 | `D_REF_TRS`             | `20206` | `D_TRD_OTC_TRADE` | 105386 | `T03_AGT_PRD_RELA_H` |
| 极速互换合约→交易表产品键 | `D_REF_FAST_TRS`        | `20206` | `D_TRD_OTC_TRADE` | 105386 | `T03_AGT_PRD_RELA_H` |

| 取数内容   | 来源／取法                                | 入模字段                   |

| 当前合约编号 | 交易表 `KEY_OTC_TRADE_ID`               | `Agt_Id`               |

合约修饰符 `20206 / 20207 / 20208` 分别标识互换、期权、外汇远期。目标表本分支保存 `Agt_Modifr`，不另写 `Agt_Type_Cd`；协议类型名称参照 [对象关系总览](03%20%E5%AF%B9%E8%B1%A1%E4%B9%8B%E9%97%B4%E7%9A%84%E5%85%B3%E7%B3%BB.md) 的 CD039 对照。

## 3. 取数条件与业务含义

- 各源表位于 `ODATA_N_TIT`，均取 `BUSI_DATE = 加工日期`，按 `KEY_OTC_TRADE_ID` 关联。
- 合约类别依次匹配普通互换、期权、外汇远期、极速互换，取先匹配的一类。均未匹配时，合约修饰符为空，交易记录仍保留，关系类型仍填 `01`。
- 本任务没有用产品主表校验 `KEY_INSTRUMENT_ID` 是否存在，也没有过滤空产品编号；没有增加极速互换的 `LONG_SHORT_SWAP` 排除条件。

例如，交易记录中合约编号为 A、`KEY_INSTRUMENT_ID` 为 123，则关系中填入“合约 A → `TIT-123`”，并在 `Src_Prd_Id` 保留 123。要继续取得产品名称或其他属性，需要另查以这个键关联的产品资料。

| 检查内容 | 本批结果 | 怎样理解 |
| --- | --- | --- |
| 业务日期 | 全部为 `2026-09-14` | 同一业务日的交易样本 |

| `KEY_INSTRUMENT_ID` | 500 个不同值，无空值；与同一行合约键均不相等 | 是另一套编号，本批可看到合约键与产品键的对应 |

| `BUSINESS_TYPE` | 13 个非空取值，另有 8 条为空 | 业务分类详见 [业务分类](06.1%20业务分类.md) |
| `INTERNAL_TRADE_ID` | 497 个不同值 | `UNKNOWN20240005`、`UNKNOWN20240006`、`UNKNOWN20240011` 各出现两次，不能替代合约键关联 |

这批数据按业务类型和产品键分散抽样，**不能从样本中两个键各自唯一，推断全表必然一对一，也不能用样本条数判断各业务规模。**
