# 02 部门配置与账簿归属

**账簿按部门代码匹配配置，下游由此取得本币；配置同时保存所属公司和跨币种履保开关。** 配置记录不产生持仓数量、汇率或本币金额。

## 1. 对象与关系

```mermaid
flowchart LR
    B["账簿：部门、公司"] -->|部门代码匹配| P["部门配置：ID、部门、公司"]
    P --> L["部门本币"]
    P --> F["跨币种履保开关"]
    L --> H["持仓／合约标的本币字段"]
```

| 对象 | 粒度与职责 | 关联标识 |
| --- | --- | --- |
| 账簿 | 保存自身部门、公司引用 | 源 `D_REF_BOOK.DEPARTMENT`；消费 185234 使用 `Bel_Dept` |
| 部门配置 | 一条配置记录；一个部门是否多条需看数据 | 源 `ID → Src_Id`；部门 `DEPARTMENT → Inr_Org_Id` |
| 部门本币 | 部门采用的本币币种 | `BASE_CURRENCY → Lcrrc_Crrc_Cd` |
| 履保开关 | 是否启用跨币种履保 | 不完整定义币种组合、折算、折扣或追保规则 |

## 2. 字段与规则

入模 **165638、211773** 的已查模板均写入 `PDATA_N.T04_OTC_DERI_DEPT_ADTNL_INFO`。

| 源字段／处理 | 目标字段／方式 | 业务含义与限制 |
| --- | --- | --- |
| `ID` | `Src_Id`，原值 | 配置身份，不作为账簿关联部门的键 |
| `DEPARTMENT` | `Inr_Org_Id`，原值 | 部门代码 |
| `COMPANY` | `Bel_Co_Inr_Org_Id`，原值 | 配置中的所属公司 |
| `BASE_CURRENCY` | `Lcrrc_Crrc_Cd`，原值 | 此处不转码；实际编码形式待样本核对 |
| `ENABLE_CURRENCY_MARGIN` | `Cross_Crrc_Perf_Guar_Flag` | `Y → 1`、`N → 0`；其余原样，空值不自动改为 `0` |
| 创建／更新人和时间 | 未承接为对应业务字段 | 模型加载／更新时间取加工参数，不替代源维护记录或审批记录 |
| 来源分区写入 | 按 `SRC_TBL` 执行 `INSERT OVERWRITE` | 读取指定源 `BUSI_DATE`，目标无按业务日多版本分区、无配置有效期 `Strt_Date/End_Date` |

| 关联层次 | 条件 | 读取要点 |
| --- | --- | --- |
| 源表核对 | 同日 `D_REF_BOOK.DEPARTMENT = D_BK_DEPARTMENT_PROPERTIES.DEPARTMENT` | 先匹配部门，再比较两侧公司，避免用公司相等条件藏掉差异 |
| 模型消费 185234 | `LEFT JOIN`，`RB1.Bel_Dept = DP.Inr_Org_Id`；DP 限定 TIT 部门配置来源 | 未按 `Src_Id`／公司连接；该子查询未按日期筛选或去重 |
| 历史重现 | 源业务日分区或当时模型快照 | 当前附加表只提供已装载版本，不能靠任意历史日期恢复旧配置 |

## 4. 查询入口

[第一二批取数 SQL](第一二批-机构用户角色取数.sql)：第 01 段取配置；第 03 段先按部门统计配置匹配数和候选值，再关联账簿。

### 源配置字段速查（最多 500 条）

```sql
SELECT
    ID                       AS "部门属性ID",
    DEPARTMENT               AS "部门代码",
    COMPANY                  AS "所属公司代码",
    BASE_CURRENCY            AS "部门本币",
    ENABLE_CURRENCY_MARGIN   AS "跨币种履保开关原值",
    CREATED_BY               AS "配置创建人引用",
    UPDATED_BY               AS "配置更新人引用",
    CREATED_DATETIME         AS "配置创建时间",
    UPDATED_DATETIME         AS "配置更新时间",
    BUSI_DATE                AS "业务日期"
FROM ODATA_N_TIT.D_BK_DEPARTMENT_PROPERTIES
WHERE BUSI_DATE = '2026-09-15'
ORDER BY DEPARTMENT, ID
LIMIT 500;
```

### 185234：账簿补本币的实际 Join 摘录

```sql
-- 摘录：RB1 为该消费中的账簿资料别名，DP 为部门附加配置。
LEFT JOIN (
    SELECT *
    FROM PDATA_N.T04_OTC_DERI_DEPT_ADTNL_INFO
    WHERE SRC_TBL = 'ODATA_N_TIT.D_BK_DEPARTMENT_PROPERTIES'
) DP ON RB1.Bel_Dept = DP.Inr_Org_Id
-- 输出 DP.Lcrrc_Crrc_Cd AS Lcrrc_Crrc_Cd
```
