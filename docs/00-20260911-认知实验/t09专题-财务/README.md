# T09 学习入口：钱怎样被核算、估值与分配

整理日期：2026-09-14。**T09 是财务主题（FIN）。它把业务事项放进账套、科目和期间，记录凭证、余额、估值、费用、资产折旧及收入分配。理解它，要先分清“经济上发生了什么”和“财务上怎样记录这件事”。**

例如采购一台设备，可能先有申请及分包，再有记账单或凭证，随后形成资产卡片、期间折旧和报表指标。这是帮助理解对象分工的概念例子；本次没有把这些表之间的整条端到端生产链当作已核实事实。

本专题采用 T03 的“全貌 → 单维度 → 交叉案例”结构，参照 T01、T05、T06 对身份、来源、时间和真实 SQL 的分析深度。正文从 T09 对象出发；每个主要分支都有具体模型内容或加工案例，证据不足的对象单独说明。
