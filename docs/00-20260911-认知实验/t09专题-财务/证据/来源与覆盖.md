## 2. 七个主要分支各自的证据深度

| 分支 | 已形成的实质解释 | 边界 |

| 凭证与余额 | ERP 批头行、余额公式、财务消费；LPS 账户机构链；FMS 账单 | 全来源凭证勾稽、借贷平衡、付款和回单匹配未验数 |

| 报表成本与档案 | FMS 报表项与指标投影、FAF 附件转换；成本动因与费用对象 | 成本分摊正式 SQL、公式及消费尚未取得；附件正文未读取 |

## 3. 查询方法与可复核性

元数据和平台目录采用字面 `t09_` 前缀匹配；两套记录各自保留，主库只做名称对照。字段目录按每条物理记录独立取字段，避免跨来源拼注释。目录统计中的 PARSED 是旧元数据解析状态，不等于数据库验证结果。

SQL 只在已知调度证据库做一次 T09 范围检索。候选索引去掉注释与字符串后，词法提取 FROM、JOIN、INSERT、CREATE 线索；这个提取不是 SQL 语义解析器，会漏掉宏、动态拼接和嵌入脚本，也不负责跨任务物理绑定。正文里的关键 Join、条件与金额表达另行读取源码确认。

43 份案例和辅助对照见 [SQL 案例索引](00-20260911-认知实验/t09专题-财务/证据/SQL案例索引.md)。网络地址、作者头部按行脱敏，语义字段投影保留；文件只作证据，未经执行。
