# LPS 凭证怎样连接账户与机构

[业务入口](00-20260911-认知实验/t09专题-财务/业务/02-凭证账单与余额.md)

证据为 [任务 172017](attachments/06-LPS凭证与账户机构/IMG-06-LPS凭证与账户机构-20260914111012616.sql)，写入 `T98_LEGAL_SETT_VCHR_INFO`。它展示了 T09 怎样与 T03 账户和 T04 机构一起消费。

## 1. 先把凭证自己的层级连齐

凭证行、凭证头、LPS 凭证附加信息各限定 LPS 的指定来源集合。行按创建日期下界，头按过账日期下界，附加信息按业务日期下界取近三个月起的数据；上界条件在本片段中被注释掉。

连接不是只有凭证 ID：

| 两侧 | 已读条件 |
|---|---|
| 行 → 头 | `Vchr_Head_Id` 相等，且行创建日期转换后等于头 `Pst_Date` |
| 行 → 附加信息 | `Vchr_Head_Id` 相等，且行创建日期转换后等于附加 `Busi_Date` |

日期条件参与区分同一编号在不同日期的记录；去掉它们会改变原查询含义。

## 2. 再通过账户及关系补机构、账套和科目

| 链路 | 已读条件与限定 |
|---|---|
| 行 → T03 协议 | `Acct_No = Agt_Id`；LPS 账户来源，`Del_Flag='0'` |
| 协议 → T04 机构 | `Bel_Inr_Org_Id = Inr_Org_Id`；LPS 结算部门来源，未删除 |
| 行 → T03 账户科目关系 | `Acct_No = Agt_Id`；参数日在 `Strt_Date / End_Date` 左闭右开范围 |
| 关系 → T09 账套 | `Sob_Id` 对应；指定 LPS 账套来源和参数日快照 |
| 关系 → T09 科目 | `Subj_Id` 对应；指定 LPS 科目来源和参数日快照 |
| 凭证状态 → 字典 | CD502，按状态值内连接说明 |

所以“凭证行在哪个部门、属于哪套账”不只是直接取某个 ORG 字段，而是沿这个消费中的账户和关系解释。

## 3. 这条链会选择范围，也会丢掉无法匹配的记录

上述连接全部是内连接。缺少账户、机构、有效关系、当天账套科目或状态字典的凭证行不会进入输出。查询成功不代表所有源凭证都被覆盖。

它用参数日有效的账户科目关系解释回看范围内的凭证，不能自动叫历史时点还原。科目连接只按 `Subj_Id`，未在这个 ON 子句额外带账套或方案；若限定来源当天仍有重号，就有放大风险。是否实际存在重号尚未验数。

这也是 T09 与 T03、T04 合作的具体例子：模型给出了连接材料，最终消费决定来源、日期、状态和保留范围；它不证明所有来源都能沿同样条件连接。
