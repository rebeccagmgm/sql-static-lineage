# 重点字段与缩写：按用途查，不按英文猜业务

[学习入口](00-20260911-认知实验/t09专题-财务/README.md)

## 1. 身份和连接字段

| 字段 | 常见含义 | T09 中要保留的区别 |
|---|---|---|
| `Sob_Id` | 账套编号 | 不等于资金账号；ERP 会计期间分支中该列为空 |
| `Sob_Plan_Id / Subj_Plan_Id` | 账套方案 / 科目方案 | 来源间含义不同；新旧科目关系字段也有差异 |
| `Coa_Id` | 会计科目表或核算结构编号 | ERP 来自 `CHART_OF_ACCOUNTS_ID`，不是某一具体科目 |
| `Subj_Id / Subj_Comb_Id` | 科目 / 核算组合 | CIV 估值将源组合 ID 写入 `Subj_Id`，必须看来源 |
| `Vchr_Bat_Id / Vchr_Head_Id / Vchr_Line_No` | 批 / 头 / 行号 | 一张凭证多行；行号需结合头及来源 |
| `Bill_Id / Bill_Det_Id` | 账单 / 账单明细 | FMS 明细金额不与主单身份混用 |
| `App_Doc_Id / App_Doc_Det_Id / Proj_Scontr_Id` | 申请 / 申请明细 / 项目分包 | PMS002、PMS004、PMS011 的前缀有实际区别 |
| `Ast_Id / Ast_Card_Id / Ast_Sob_Id` | 资产 / 卡片 / 资产账簿 | 需要具体映射，不靠名字或编号尾段连接 |
| `Recv_Id / Det_Id / Attach_Id` | 实收 / 明细 / 附件 | 跨对象不是统一编号体系 |

## 2. 核算维度与金额

| 字段 | 解释方向 | 不能省略的条件 |
|---|---|---|
| `Co_Seg / Dept_Seg / Subj_Seg` | 公司、部门、科目段 | 有些来源带前缀，有些直接保留段值 |
| `Busi_Prd_Seg / Mng_Seg / Proj_Seg` | 业务产品、管理、项目段 | 它们是核算维度，不必是 T02 产品或业务项目实体 ID |
| `Crrc_Cd` | 币种 | ERP 凭证行的该列留空；应结合头和来源 |
| `Dr_Amt / Cr_Amt` | 借方 / 贷方金额 | 不能先合成“交易额”；净额公式由业务口径决定 |
| `Lcrrc_* / Ocrrc_*` | 本币 / 原币金额 | 本币、原币及人民币列不能自动互相替换 |
| `Pd_Begn_* / Pd_End_* / Pd_*_Occu_Amt` | 期初、期末、期间发生额 | 存量和期间变化不相加；要保留期间及其他核算维度 |
| `Cost / Valu / Valu_Incrs` | 成本、估值、估值增值 | 代码投影本身不证明公式恒等或财务勾稽 |
| `Mth_Depr_Amt / Year_Depr_Amt / Accum_Depr_Amt` | 月、本年、累计折旧 | 累计项不再按多个期间简单累加 |
| `Income_Amt / Idx_Val / Driv_Val` | 收入金额 / 指标值 / 动因值 | 指标值和动因值不一定是金额；收入金额还分头、明细、奖励 |

## 3. 时间、状态与来源

| 字段 | 阅读方式 |
|---|---|
| `Busi_Date / Acctnt_Pd / Acctnt_Date / Nav_Date` | 先看 SQL 的实际表达和格式；日期、年月、英文期间可并存 |
| `Strt_Date / End_Date` | 在已核实拉链分支中判断有效期；不要套到所有同名结束日期 |
| `Cfm_Flag / Det_Flag` | 确认与明细标志；来源生成方式不同，不能跨来源直接统计比例 |
| `Del_Flag / Vld_Flag` | 删除与有效标记要结合各源规则，不能随意互换 |
| `Data_Src_Cd` | 业务来源系统代码；不是元数据的采集来源 |
| `Real_Src_Tbl / Src_Tbl` | 真实源描述 / 来源分区标签，有时不同 |
| `Data_Etl_Date / Data_Upt_Date / Data_Time` | 加载、更新和处理时间，不自动等于业务发生或估值时间 |

## 4. 常见词根

`SOB` 对应账套，`SUBJ` 科目，`COMB` 组合，`VCHR` 凭证，`BILL` 账单，`PD` 期间，`VALU` 估值，`PRVS` 计提，`APRN` 分摊，`DEPR` 折旧，`BDGT` 预算，`APP_DOC` 申请单，`SCONTR` 分包，`RECV` 收入或实收记录，`DISTR` 分配/下发，`RELA` 关系，`ADTNL` 常用于附加信息。以表中文说明与具体 SQL 为准，不把缩写扩展当成业务证明。

完整字段、类型、注释、分区与来源，请从 [逐表对象目录](00-20260911-认知实验/t09专题-财务/资料/逐表对象目录.md) 进入独立证据。平台字段引用不带可靠物理类型及分区信息；尤其会计期间的个别字段注释错位和资产期间余额的版本冲突，见 [冲突台账](00-20260911-认知实验/t09专题-财务/证据/冲突与待核问题.md)。
