# T00 学习入口：跨主题对象怎样组织业务

整理日期：2026-09-14。**T00 确实存在，正式名称为 CSA / Cross Subject Area / 跨主题。它为跨业务使用的项目、需求、任务、档案、试卷、系统、数据资产和产品池提供模型表达。** 这些对象有自己的身份、状态和关系，并不都能归并为客户、产品、协议或事件。

例如一个种子基金项目可以关联管理人、拟投产品、业务负责人、审批需求和附件；一份产品池可以影响营销筛选；一张数据库表本身又是数据管理的对象。理解 T00，应先确定正在描述哪一种对象，再判断它与其他主题如何连接。
