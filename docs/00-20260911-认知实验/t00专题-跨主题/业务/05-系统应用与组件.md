# 系统、应用与组件：职责、接口和调用配置分开

[返回入口](../README.md) · [本组字段](../资料/字段/05-系统应用与组件.md) · [目录补充对象](../资料/目录独有对象与DDL.md)

## 1. 一套系统为什么有这么多表

| 对象 | 模型 | 应当回答的问题 |
|---|---|---|
| 业务系统登记 | `t00_busi_sys_info`、`t00_sys_info`、应用系统基本信息 | 是什么系统，职责和建设状态是什么 |
| 应用与版本 | `t00_app_info`、`t00_app_ver_info` | 系统下面的具体应用、版本或部署资料 |
| 功能清单 | `t00_sys_func_info`、`t00_sys_func_subdv` | 系统提供哪些功能及细项 |
| API与调用应用 | `t00_api_info`、`t00_api_app_info`、`t00_api_app_rela_h` | 接口身份和版本，哪个应用获得何种授权 |
| 工具能力及AI技能 | `t00_inst_ablt_compnt_base_info`、技能附加表、组件关系历史 | 哪种组件、怎样配置、声明关联哪些工具 |
| 资源与安装资料 | `t00_res_item_*`、员工设备软件安装信息 | 资源属性、标签及安装记录，不能全视作系统主表 |

这些对象最终可以连接T04的用户、员工和组织，但一套系统里“维护人”“授权应用”和“使用人”承担不同角色。

## 2. 系统来源有不同登记体系

ACM分支为应用配置管理CMDB资料；BDP103的 `t00_sys_info` 从 `P_T_META_BUSINESS_SYSTEM` 保存系统ID、业务唯一命名、源系统号、系统代码、中英文名、状态、形态、层级、建设及上线下线日期。[62991.sql](../证据/SQL/62991.sql)、[196126.sql，68行起](../证据/SQL/196126.sql)

因此 `Sys_Id` 不能跨ACM、BDP与其他来源无条件对齐。目录新增的 `t00_sys_stati_info_h` 又在ISM分支将CMDB的INSTANCE_ID与OBJECT_ID对应保存，类型01注释为“系统内部唯一标识”；所谓“统计信息”在这一分支其实保存标识说明，不是计量数值。[244437.sql，41–54行](../证据/SQL/244437.sql)

## 3. API代码需要先映射到有效版本

API基本信息把 `Api_Id` 拼成 `BDP055-` 加源版本ID，同时另存API原始代码、联合编号和元数据GUID。三种标识各有用途。[143524.sql，79行起](../证据/SQL/143524.sql)

授权关系从 `N_GW_APP_API` 取应用与接口代码，内连接当天 `N_DS_API_BASE_INFO` 中 `IS_VERSION_ACTIVE='Y'` 的记录，条件是 `A.API_ID=B.API_CODE`；输出再使用 `BDP055-B.Api_Id`，应用编号用 `BDP057-A.APP_ID`。[143527.sql，30–50行](../证据/SQL/143527.sql)

若代码没有有效版本，它会在内连接处被排除；若一代码出现多个有效版本，可能扩成多条。现有SQL不证明这两种情况不会发生。关系表保留授权时间、状态、方式及有效期，也不等于API此刻可访问或调用成功。

## 4. TIT功能清单不是权限树

TIT分支从 `A_ADM_FUNCTION` 保留功能ID、名称、代码、路径属性、微服务名、开放接口标志等。父功能编号、父功能代码和层级在本分支显式为空。[242362.sql，61行起](../证据/SQL/242362.sql)

所以可以据此认识功能清单，但不能由通用DDL里存在 `Prnt_Func_Id` 就画出TIT完整功能树。是否拥有角色权限、是否能够授权别人，需要T04或系统权限关系的额外证据。`spdata_n` 中ADS/XIR也有同名功能模型，目录独有的SQL入口单列，不串用普通库注释。

## 5. AI技能与工具：记录的是配置关系

AI技能是本次由平台目录与SQL补回的对象。234469从 `H_GUANGZHI_SKILL` 构造 `MIO072-ID`，保存技能指令内容、参考信息、共享标志、快捷指令开关、所属平台以及允许工具列表，按业务日期留快照。[234469.sql，32–52行](../证据/SQL/234469.sql)

组件关系任务从 `ALLOW_TOOLS` 拆出工具名称，左连同日 `H_GUANGZHI_TOOL.NAME`，形成技能 `MIO072-ID → 工具MIO069-ID` 的关系，类型01注释为调用关系。没匹配到工具时，目标组件号可为空。[234480.sql，24–33行](../证据/SQL/234480.sql)

这说明的是技能配置声明关联的工具，不是已经观测到的真实调用链；按名称匹配也不自带唯一性保证。JSON列表拆分采用字符串替换与分隔，复杂内容是否完整支持尚未验收。本专题只读SQL和结构，不读取任何实际技能指令、凭证或调用用户数据。
