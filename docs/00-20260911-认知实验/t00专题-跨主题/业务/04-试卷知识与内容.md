# 试卷、知识与内容：定义和业务回答不是一回事

[返回入口](../README.md) · [本组字段](../资料/字段/04-试卷知识与内容.md)

## 1. 试卷要拆成四个层次

| 层次 | 模型 | 粒度与职责 |
|---|---|---|
| 试卷 | `t00_papr_info`、`t00_papr_stat_h` | 哪一份、哪个版本，叫什么，是否启用 |
| 题目与选项 | `t00_qstn_info`、`t00_qstn_ans` | 某题库中的问题，以及该问题的一项备选答案 |
| 组卷关系 | `t00_papr_qstn_rela_h`、`t00_papr_stru_strg` | 试卷采用哪些题目、如何组题 |
| 评分规则 | `t00_elig_ans_scor_def`、`t00_cc2_clbk_ans_scor_def`、`t00_papr_test_lvl_def` | 哪个版本和适用对象下，答案多少分、结果如何分级 |

这里的 `qstn_ans` 是答案定义，不能自动当作客户真实选择。客户完成一次测评或回访产生的事件，应去相应业务记录及T05分支查，而不是把T00选项行数当答题人数。

## 2. CC2：同一道题产生两种题库身份

62980从同一份 `C_CCB_QUESTION` 做两段投影：人工题库用 `QUESTION_CONTENT/QUESTION_ENABLE`，题库类别为 `CC2-QSTN-MAN`；自动题库用 `QUESTION_SELF_CONTENT/QUESTION_SELF_ENABLE`，类别为 `CC2-QSTN-AUTO`。两者保留同一个 `QUESTION_ID`。[62980.sql，31–98行](../证据/SQL/62980.sql)

因此“问题编号相同”不是冗余证明。若只按 `Qstn_No` 查题面，可能拿到另一种回访方式的文本和启用状态。使用时需要来源、题库类别和业务日期。

试卷主表则将 `PAPER_ID` 与 `PAPER_VERSION` 一起编码为 `CC2030-<编号>-<版本>`。组卷关系按同一个规则生成Papr_Id，并分别关联人工、自动两套题库。虽然生产任务后缀是CC2024/CC2025，身份前缀却是CC2030；编号语义必须来自投影，不能从任务名推导。[156795.sql，33–51行](../证据/SQL/156795.sql)、[156794.sql，29–60行](../证据/SQL/156794.sql)

关系历史再带 `Strt_Date/End_Date`。连接一份历史试卷时，要同时考虑试卷版本、关系期间与题目快照日；取当前题面并不自动还原当年问卷。

## 3. RCC：同一个选项分值可能依适用范围而变化

RCC评分生产直接保留试卷类型、产品TA编号、机构标志、问题编号、固定题库类别 `RCC-QSTN`、答案序号、答案分值及适当性试卷版本，按当天来源写入。[62888.sql，31–51行](../证据/SQL/62888.sql)

所以评分匹配不能只有“问题编号+答案序号”。还要确认试卷类型、版本、TA、适用主体标志及业务日期。单纯把所有选项分数相加，也不能等同客户评估得分；需要客户实际选择、题型及评分规则的业务证据。

IBS在 `spdata_n` 下有试卷、题目、答案、组卷及等级定义；CRM有回访问卷扩展。它们已逐表列入，不与CC2或RCC以相同编号合并。本次没有把所有来源的评分算法视为已核验。

## 4. 知识库：问题与答案有独立身份和状态

GKS问题来自 `M_QUESTION`，模型ID为 `GKS008-ID`，保留问题内容、原分类、作者、标签、分数及最新答案字段。GKS答案来自 `M_ANSWER`，模型ID为 `GKS009-_ID`；只有QUESTIONID非空才拼对应 `GKS008-QUESTIONID`，否则关联问题为空。[62875.sql，36–55行](../证据/SQL/62875.sql)、[62951.sql，37–59行](../证据/SQL/62951.sql)

这使得问题与答案能分别变更，也容许尚未绑定问题的答案。不要把问题的 `LAST_ANS` 默认当成与模型 `ANS_ID` 同格式的外键；本次只确认原值投影，没有确认转换规则。

答案状态历史又分两种状态类型：01取审核状态 `AUDITSTATUS`，并保存审核阶段与审核用户；02取举报状态 `REPORTSTATUS`。同一个答案可能同时有两种状态维度，不能只保留一条“最新状态”。[63004.sql，28–53行](../证据/SQL/63004.sql)

字段 `QSTN_CATE_CD` 在试题与知识问题中存在同名异域情况，必须区分CD167与CD899。[字典说明](../字典/README.md)

## 5. 内容集合：组织方式与内容本体不同

`t00_cont_set` 及课程关系、用户关系、状态历史表达内容集合及其组成。LMS专栏附加表从 `I_LMS_SUBJECT` 构造 `LMS040-SUBJECT_ID`，保存封面、简介展示、子分类导航、阅读权限、课程数量和学分合计等。[224865.sql，39–64行](../证据/SQL/224865.sql)

课程数量是源集合属性，不能先把专栏与每门课程Join后再把同一个数量求和。课程和学习记录仍属其各自模型；这里是内容的组织与展示设置。元始股星球主题、论坛主题、运营素材及IQA知识扩展也在本组目录，保留各自说明及证据深度。
