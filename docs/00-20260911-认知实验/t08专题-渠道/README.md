# T08 学习入口：业务经由哪里接入、触达与分发

整理日期：2026-09-14。**T08 管理渠道、入口及其运行配置，也管理承载接入和服务的设备。** 理解这个主题，要先分清“入口本身”“入口上的内容与配置”“经由入口发生的业务”。

一次客户开户、一笔基金交易、一次直播观看都可能带渠道信息。渠道表能解释入口、归属或分类；开户是否完成、交易金额和观看行为，需要继续读取对应的业务记录。结算分发和监管报送也有渠道，它们描述数据送往哪里的配置。

本专题采用 T03 的“全貌 → 分维度 → 交叉理解”以及 T01、T06 的对象、身份、时间、来源和真实消费案例标准。范围从原始目录、字段、码值、SQL 与 Wiki 重建，包含整个 T08；没有把渠道缩成开户引流一个分支。
