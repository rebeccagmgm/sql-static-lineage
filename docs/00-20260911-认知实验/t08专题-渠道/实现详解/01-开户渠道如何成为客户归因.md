## 1. 迁移源系统而保留仓库身份

62878 的核心表达可缩成：

```sql
SELECT CONCAT('GKS030-', CHANNEL) AS Chan_Id,
       CHANNEL AS Src_Chan_Id,
       'OAO' AS Data_Src_Cd,
       'ODATA_N_GKS.J_CHANNELTYPE' AS Src_Tbl,
       'ODATA_N_OAO.C_CHANNELTYPE' AS Real_Src_Tbl
FROM ODATA_N_OAO.C_CHANNELTYPE
WHERE Busi_Date = '${data_day_str}';
```

这段节选说明：编号和写入分区延续旧契约，读取源已是OAO。消费者继续按旧来源分区选数据，并不自动意味着它读到了旧系统。[62878原文](../../../attachments/01-开户渠道如何成为客户归因/IMG-01-开户渠道如何成为客户归因-20260914110950618.sql)

专有属性62891还加入四类补充：上传分类的三级分类/财务分类、AUM打折集合、OSC有效联动渠道、OAO优先级。优先级按CHANNEL分组取ID最大的记录，投影为 `Bel_Prior`；源“允许修改”标志转换为目标“锁定”标志。`Real_Src_Tbl` 只记录主要来源，无法替代这四条依赖说明。[62891原文](../../../attachments/01-开户渠道如何成为客户归因/IMG-01-开户渠道如何成为客户归因-20260914110951899.sql)

## 3. T98才开始回答客户如何归因

67780处理中，非网上开户与网上开户分支分别使用申请、预约、订单等记录。与T08直接相关的步骤如下：

1. 通过源渠道号匹配引流专有资料；特殊来源还读取渠道关系，将关联渠道编号还原到源编号。
2. 读取有效期时用 `Strt_Date <= d AND End_Date > d`。网上开户分支另限定关系类型01；另一处特殊分支没有同样的类型条件。
3. 通过打折和金钥匙分类资料解释引流来源；部分源值先按冒号拆分再关联。
4. SQL中出现按窗口排序保留首条/末条、按渠道取某个引流营业部的规则，防止一个客户多行。窗口条件和排序值属于归因实现，不能从T08表名自行补出。

该任务的输出是客户、引流机构、渠道等信息，和单纯的渠道目录不是同一粒度。是否符合实际业务归属仍需业务验收。[67780的T08连接段](../../../attachments/01-开户渠道如何成为客户归因/IMG-01-开户渠道如何成为客户归因-20260914110953199.sql)

## 4. 精确匹配和正则匹配怎样决定分类

84962分别读取 `Mode='equal'` 与 `Mode='like'` 的有效金钥匙分类资料：

```sql
-- 摘录核心连接；两路均另有限定分类非空、del_flag='0'
t.CUST_SRC_CODE = exact_rule.Src_Chan_Id
t.CUST_SRC_CODE RLIKE regex_rule.Src_Chan_Id
```

下游先用 `coalesce` 优先取精确分类，其次取正则分类；把渠道、三级分类、财务分类和负责人拼成一个字符串，再按客户、产品渠道等分组，用 `max(array(...))` 选择结果。**这不是按 `Bel_Prior` 排序，也不是已验证的“最具体正则优先”。** 多个规则命中时，实际由这段表达式决定。

未匹配或特殊来源还进入“其他”“自来”等CASE分支；同一SQL另有APP转化补充路径。源码中 `Dvrs_Chan2='qrcode' AND Dvrs_Chan2='jgqrcode'` 对单值不可能同时成立，作为静态条件异常保留；本文没有把它改成OR后继续推理。[84962](../../../attachments/01-开户渠道如何成为客户归因/IMG-01-开户渠道如何成为客户归因-20260914110954666.sql)

## 5. 费用为什么不能按渠道直接相加

186145的关键Join是分类表与费用表的三级分类名称 `TCATEGORY` 相等，随后把分类表中的CHANNEL拼成渠道编号。用一个明确的假设例子说明影响：如果分类X有渠道A、B两行，费用记录F属于X且金额100，连接后可能出现A/F/100和B/F/100。两个100来自同一来源费用记录，不能据此认定共支付200。

实际是否这样展开，需要核查分类与费用行的唯一性；本次只确认了Join条件及金额投影。若要使用费用，先按来源记录ID、月份与分类核对展开，明确它是分摊、归属展示还是重复，再决定汇总。[186145](../../../attachments/01-开户引流与合作渠道/IMG-01-开户引流与合作渠道-20260914110957252.sql)
