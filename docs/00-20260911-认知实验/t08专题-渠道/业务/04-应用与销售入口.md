# 应用与销售入口：同叫渠道，身份层级不同

[返回入口](../README.md) · [销售入口消费案例](../实现详解/02-销售入口如何进入交易统计.md)

## 1. 应用对象与页面入口

Wiki《0.5 渠道统计规范》把应用渠道参数用于产品中心的调用入口；`source` 常表示页面，`sub_source` 常表示页面内模块。文中分别说明场外基金与场内基金使用的参数，并不是一套场外衍生品合约分类。[参数原文](../../../attachments/02-销售入口如何进入交易统计/IMG-02-销售入口如何进入交易统计-20260914110950619.json) · [场外产品示例](../../../attachments/04-应用与销售入口/IMG-04-应用与销售入口-20260914110951437.json)

所以一个 APP 可包含多个页面，一个页面可包含多个模块；一笔交易带来的来源参数不必是一条 `t08_chan.Chan_Id`。

| 模型入口 | 表达对象 | 来源与关键连接 |
|---|---|---|
| `t08_sip_chan_info` | 产品销售/场内交易的两级入口分类 | SIP 的 `SOURCE/SUB_SOURCE` → `Lvl1_Entr/Lvl2_Entr`，按来源与日分区选择 |
| `t08_pmb_acs_chan_info` | 积分商城接入应用 | PMB `J_T_APP`，`PMB012-` 身份；消费用APP_ID连接源渠道号 |
| `t08_agent_app_chan_info` | 智能体应用的专有配置 | LLM `P_APPS.ID` → `LLM013-`，保留模型配置、工作流、发布与接入标志 |
| `t08_ew_chan_adtnl_info` | 企微来源二维码配置 | WCM028 的主子来源组成身份，附有效天数、欢迎语、标签等 |
| `t08_chan` 的其他应用来源 | 注册来源APP、企微应用、ATP接入终端、产品中心应用 | CFM007、WCM032、BMA017、SSO010、PRD102 各自保留编号规则 |

## 2. SIP 入口是一张参数模型

[86942](../../../attachments/04-应用与销售入口/IMG-04-应用与销售入口-20260914110952789.sql) 从产品销售来源参数表取两级入口和三级分类，`Chan_Busi_Type_Cd='PRD_SALE'`。[86944](../../../attachments/04-应用与销售入口/IMG-04-应用与销售入口-20260914110954288.sql) 从场内交易来源参数表取同类结构，类型为 `OST_DEAL`，还保存入口的中英文名称。两路都按来源和业务日期写入；其字段没有 `Chan_Id`。

给交易补入口说明，应同时使用两级参数，选定适用业务类型/来源和日期。只用一级入口会把多个模块混在一起；省略日期会把同一参数的多日快照连成多行。

86942 的 `Modif_Date` 表达式实际为 `CONCAT(UPDATE_TIME,1,10)`。它不是截取前10位日期，不能在本文中悄悄改写成 `SUBSTR`。该表达式的预期需源码维护者核实。

## 3. 智能体应用为何分成三处

166753 写共用渠道信息：应用 ID、名称、MODE 转换后的渠道类型、源 STATUS 和类别10。166754 写应用专有字段：租户用户、模型配置、工作流、WEB/API 接入、模板和已发布标志。166755 写渠道用户关系，渠道为 `LLM013-ID`，租户用户为 `LLM014-TENANT_ID`。

三处都来自 `P_APPS`，却各自回答身份、能力配置和参与关系。租户用户不是必然的最终使用人；`Had_Lnch_Flag` 说明源应用发布标志，不证明某次调用或工作流成功。[166753](../../../attachments/04-应用与销售入口/IMG-04-应用与销售入口-20260914110955781.sql)、[166754](../../../attachments/逐表对象目录/IMG-逐表对象目录-20260914110955116.sql)、[166755](../../../attachments/04-应用与销售入口/IMG-04-应用与销售入口-20260914110957531.sql)

## 4. 企微二维码与企微应用

WCM028 使用 `SOURCE/SUB_SOURCE` 组合标识二维码配置，附二维码有效天数、是否永久、标签、欢迎语和终端；WCM032 用 `AGENT_ID` 描述企微应用，共用表类别11。前者是获取/承接用户的配置，后者是应用本身，不能因系统相同就按源编号直接连接。[172912](../../../attachments/04-应用与销售入口/IMG-04-应用与销售入口-20260914110958600.sql)、[189130](../../../attachments/04-应用与销售入口/IMG-04-应用与销售入口-20260914110959002.sql)

## 5. 接入配置怎样进入消费

积分商城流水宽表 [142073](../../../attachments/04-应用与销售入口/IMG-04-应用与销售入口-20260914110959284.sql) 读取有效的 `t08_pmb_acs_chan_info` 来源分区，以流水 `APP_ID=Src_Chan_Id` 取得渠道资料。流水积分量来自业务记录，T08提供解释维度。

该专有表还定义 `Acs_Key`，它是接入口令字段。本次只整理字段用途，没有读取或展示口令值。其他应用来源也只能从配置说明入口是什么；不能推导当前接入可用或调用权限已经生效。
