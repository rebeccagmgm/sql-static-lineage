# 运营位、素材与名单：位置、策略和受众不是一行

[返回入口](../README.md) · [逐字段加工案例](../实现详解/03-运营位如何连接配置与客户.md)

## 1. 四个问题对应四种记录

| 业务问题 | 表 | 行粒度及核心字段 |
|---|---|---|
| 在哪里投放 | `t08_ad_oper_site_info` 与渠道主表 | 一个来源运营位；`Chan_Id`、源运营位号、分类、指标配置和 SQL 模板 |
| 使用什么 AI 模型、何时有效 | `t08_oper_site_ai_mdl_plac_info` | 一条 `Plac_Id` 配置；运营位、资源、AI 模型、分数阈值、生效/失效时间 |
| 放了哪份素材 | `t08_ad_oper_site_mtrl_plac_rec` | 一条源放置记录 `Src_Id`；运营位、资源项、上报数据号、创建时间 |
| 针对哪些对象或排除哪些对象 | `t08_chan_cust_list` | 一个日期分区内的名单项；名单类型、客户标识类型、客户值、来源记录 |

运营位的存在不证明素材已经展示，素材配置不证明用户点击，名单成员不证明触达成功。T05 或应用事件才可能提供实际行为，必须另查对应粒度和结果。

## 2. 两套运营位来源

MIO014 来源 `H_INDEX_BUSICODE` 用 `BUSINESS_CODE` 生成 `MIO014-` 渠道身份；MIO054 来源 `H_CW_BUSICODE_CONFIG` 用 `BUSICODE` 生成 `MIO054-` 身份。它们分别写渠道主表和运营位专有表。专有字段包括三级分类、有效指标标志、配置状态、触达及浏览的参数与 SQL 模板。

AI 配置来源 MIO042 使用 `MIO014-BUSICODE` 关联运营位；名单 MIO053 使用 `MIO054-BUSICODE`。因此同一个裸 BUSICODE 字面值，也不能跨这两路自动当成同一运营位。已读 SQL 未给出两套编号的完整转换表。[91857](../../../attachments/03-运营位素材与名单/IMG-03-运营位素材与名单-20260914110950606.sql)、[91858](../../../attachments/逐表对象目录/IMG-逐表对象目录-20260914110950624.sql)、[171312](../../../attachments/03-运营位素材与名单/IMG-03-运营位素材与名单-20260914110951323.sql)、[171320](../../../attachments/03-运营位素材与名单/IMG-03-运营位素材与名单-20260914110952734.sql)、[156751](../../../attachments/03-运营位如何连接配置与客户/IMG-03-运营位如何连接配置与客户-20260914110950621.sql)

## 3. 名单不一定拥有具体渠道编号

MIO 名单生产 [171321](../../../attachments/03-运营位如何连接配置与客户/IMG-03-运营位如何连接配置与客户-20260914110952083.sql) 把类型固定为 `DF_STRG_OPER_SITE_CUST`，客户类型由 `PLAYER_KIND` 转码；源值为 portal 时，客户号变为 `CFM001-PLAYER_ID`。这说明该记录可表示某种系统用户，不一定直接是交易客户号。

无线天利的两路名单 [199850](../../../attachments/03-运营位素材与名单/IMG-03-运营位素材与名单-20260914110954149.sql)、[199851](../../../attachments/03-运营位素材与名单/IMG-03-运营位素材与名单-20260914110955672.sql) 只取 `ENABLED='1'`，类型分别为 `95575_MSG_CHN_BL` 和 `CAM_CHN_BL`；客户类型固定10，客户值取手机号，渠道编号明确为空。空编号有来源语义，不能直接按“缺渠道”删除这些记录。

## 4. 怎样避免把配置当效果

运营位含浏览 SQL 模板和触达参数，只能说明统计配置存在；素材表的上报数据编号只是保存的关联标识；AI 配置的分数阈值只是一条策略参数。若要回答“某次投放使多少客户成交”，还需要曝光/触达事件、客户身份对应、交易事实、时间窗口和归因规则。本次没有从配置字段推导营销增量收益。

对当前配置，可按运营位与有效时间理解；对历史投放，至少保留 `Plac_Id` 或素材源记录、事件发生时间以及当时使用的配置，不能连接到渠道最新属性后声称还原当时状态。
