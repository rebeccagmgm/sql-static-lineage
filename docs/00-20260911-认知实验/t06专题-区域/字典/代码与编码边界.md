# 代码与编码边界：不要把所有“区域码”接在一起

[返回入口](00-20260911-认知实验/t06专题-区域/README.md) · [完整相关代码域记录](attachments/02-来源与加工职责/IMG-02-来源与加工职责-20260914105651316.json)

本页的代码域来自本地资产 SQLite，码值快照状态为 `UNVERIFIED`。下面报告实际存在的定义与记录，不宣称其为现行全量标准，也不把名称相近的代码域自动绑定到 T06 字段。

## 1. 五种容易混淆的编码

| 表／字段或代码域 | 解释对象 | 已核对例子 | 与 T06 的关系 |
|---|---|---|---|
| `T06.ADDR_ID` | 行政区域节点 | 人工样例 `710100` 对应台北市 | 正式区域模型的节点身份 |
| `T06.ADMIN_AREA_LVL_CD` | 区域层级 | SIP SQL 派生 `1/2/3`；人工样例有 `1/2` | 字段本身的层级值，不是区域编号 |
| `T06.AREA_CD` | 电话区号 | 台北市人工样例为 `02`；SIP 对部分区域写固定区号 | 名称相同不等于代码域 CD583 |
| CD010 / `NAT_AREA_CD` | 国家和地区 | `CHN`、`HKG`、`MAC`、`TWN`、`999` | 客户国家字段等邻近用途，不能直接与六位区域编号 Join |
| CD583 / `AREA_CD` | 业务区域分类 | `01=华南`，`101=综金` | 本次未证明与 T06 电话区号字段有关 |

邮编也是字符串。正式样例包含 `000800`、`100` 等不同形态；不要为了“标准化”统一转成整数而丢掉前导零。

## 2. 行政区域层级的直接依据

本次在代码域定义表中未命中 `ADMIN_AREA_LVL_CD` 对应的独立定义。可以确认的依据是 61790 的 CASE 以及下游显式过滤：

| 取值 | SIP 派生规则 | 消费侧解释 |
|---|---|---|
| `1` | 编号后四位为 `0000`；补出的省级行也写 1 | 省、直辖市等一级区域 |
| `2` | 不满足上一分支且后两位为 `00` | 地市层级 |
| `3` | 不满足前两分支且后两位不是 `00` | 县区层级 |

这是本模型已见实现的解释，不是独立导出的完整行政区划标准。人工样例“台东县”的层级为 `2`，所以不能用“县”字覆盖实际字段值。[字段与层级](00-20260911-认知实验/t06专题-区域/01-区域对象与层级.md)。

## 3. CD010：定义与实际记录一起看

定义表说明采用国家和地区的三位编码，并引用一份历史标准名称。本地实际有 **260 条**码值记录，记录日期范围为 2020-09-14 至 2021-12-17。包含国家地区代码、洲别和兜底值，不能把 260 当成国家数量。

| 值 | 本地含义 | 来源表 | 记录日期 |
|---|---|---|---|
| `CHN` | 中华人民共和国 | MANU_MATN | 2020-09-14 |
| `HKG` | 中国香港特别行政区 | MANU_MATN | 2020-09-14 |
| `MAC` | 中国澳门特别行政区 | MANU_MATN | 2020-09-14 |
| `TWN` | 中国台湾 | MANU_MATN | 2020-09-14 |
| `1` | 亚洲 | MANU_MATN | 2020-09-14 |
| `999` | 其他 | MANU_MATN | 2020-09-14 |

因此，“三位编码”不能不经核对就说成“三位数字”。SMP 客户任务直接写 `CHN/999`，与本地字典可对照；本次未取得国家地区码与 T06 所有区域编号之间的正式转换关系。

## 6. 来源系统代码用于解释职责

SIP 在 CD100 中为“GF-SMART智能化平台”，AMS 为“资管运营系统”，TA5 为“资产管理TA5”，CRM 为“金管家综合服务系统”，ICR 为“内部评级系统”。这些记录来源为 `MANU_MATN`，上述记录日期均为 2021-06-18；其他本次相关系统也在 JSON 的 `sourceSystems` 中保留。

系统代码解释“资料来自哪个系统”，不解释区域本身属于哪个行政层级。人工样例的 `DATA_SRC_CD` 为空，也不能据此丢掉已经明确标为 `MANUAL` 的来源事实。

## 7. 实际查值顺序

先确认字段实际内容和来源；查域定义；再查该域中的值、类型备注、来源和记录日期。`999999` 在已读客户任务中是区域字段的兜底字面值，本次未核实它是 T06 中真实存在的区域行；不要借用 CD010 的 `999=其他` 给它补一个正式行政区域定义。
