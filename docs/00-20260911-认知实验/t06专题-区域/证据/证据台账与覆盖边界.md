## 2. 本地 SQL 检索的完整性口径

在 `schedule-evidence.sqlite` 的 `evidence` 中执行字面检索：`format='sql' AND instr(lower(payload_text),'t06_admin_area')>0`。这覆盖该库内所有命中文字面的 SQL 记录，不设结果截断；总量为 21。它会命中 DDL、注释及读写，因此先做候选检索，再按实际语句核对角色。

人工核对结果为 1 个行政区域主加工、20 个直接读取任务。其中 233986 在测试主题；4 对任务的业务 SQL 在移除整行注释并折叠空白后相同，全部仍保留独立任务 ID。该内容比较只是方便阅读，不是任务身份或当前运行合并的依据。

检索不能找到不使用该字面名称的动态 SQL、外部程序、库外消费者或本地未采集任务。手机号归属草稿来自额外源码核对，单独列为设计证据，不加入正式 SQL 生产者统计。
