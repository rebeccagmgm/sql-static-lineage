# 本地任务覆盖与统计口径

范围来源：2026-09-11 的本地 SQLite 检索。以下为当时的统计口径，2026-09-12 整理目录时未重跑全库扫描。当前学习入口见 [T01专题](00-20260911-认知实验/t01专题-当事人/README.md)。

## 2. 到底有多少对象、多少任务

### 对象范围

本地元数据目录中，表名严格以 `t01_` 开头的对象有 **718 个**，另有 **59 个**名称中含该片段的相关对象。这里按目录物理记录计数，包含不同平台、库、临时对象及未成功解析对象；不能称为 718 张在用业务表。

Hive `pdata_n` 有 218 个前缀对象，其中 163 个元数据可解析、55 个未支持解析。以前反复出现的“163 张”，只指这个子集。全目录的字段与分区详情见[对象目录](00-20260911-认知实验/t01专题-当事人/资料/物理对象目录.md)。

### 调度与 SQL 范围

| 本地任务主题 | 目录任务 | 每日任务 | 手工任务 | AVAILABLE SQL |
|---|---:|---:|---:|---:|
| EDW_PTY | 1,030 | 985 | 45 | 988 |
| SEDW_PTY | 220 | 212 | 8 | 212 |

**1,197 个每日任务全部有 AVAILABLE SQL、任务详情及上下游一跳调度证据。** 53 个手工任务中，3 个有 AVAILABLE SQL，49 个没有 SQL 证据，1 个标为 UNAVAILABLE。逐任务结果见[核心调度覆盖](attachments/任务覆盖口径/IMG-任务覆盖口径-20260914111022602.json)。这说明主主题日任务的本地资料相当充足，不应继续限于 22 个样例。

但主题不等于 T01 边界。全库子句检索还命中香港、资管、NDS、其他主题与测试任务。反过来，核心主题内也有 T04、T09 任务，所以不能拿主题任务总数当成 T01 生产任务数。

| 全库检索结果 | 数量 | 应怎样理解 |
|---|---:|---|
| hive-task 证据 | 26,043 | 包括不可用 SQL |
| AVAILABLE SQL | 22,537 | 本轮实际检索范围 |
| 选入对照的任务 | 1,744 | 核心主题可用任务，或读/写子句命中 T01 的任务 |
| INSERT 写入候选任务 | 1,341 | 含未限定库名和辅助对象，不能直接当正式生产者 |
| 限定名称 FROM/JOIN 读取候选任务 | 617 | 包含自读、测试、辅助加工，不等于 617 个业务消费者 |
| 按限定名命中写候选的前缀目录对象 | 267 / 718 | 名称覆盖，不是物理血缘认证 |
| `pdata_n` 可解析子集命中写候选 | 163 / 163 | 全部命中限定名写候选；存在结构冲突，见[来源与消费第6节](00-20260911-认知实验/t01专题-当事人/06-来源时间与消费.md) |

617 个读取候选中，9 个任务所读的 T01 名称都同时出现在本任务写候选中；另外 608 个至少读取一个没有在本任务 INSERT 候选中出现的 T01 名称。这个区分只用于排查，不证明其为外部消费或没有其他写入方式。

本地任务目录的采集运行标为完成，唯一任务数为 172,750；另一个主题清单快照给 EDW_PTY/SEDW_PTY 的计数是 1,196/253，与这里的 1,030/220 不一致。两套口径或版本尚未对齐，不能将本地覆盖率外推成当前平台全量覆盖率。
