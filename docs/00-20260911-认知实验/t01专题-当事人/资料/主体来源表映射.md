## 这份映射怎么读

```text
CSV real_src_tbl
    ├─ source_table_comment：T01 SQL 明写的来源表中文说明
    ├─ metadata_*：本地 Hive 元信息快照中的状态和分类
    ├─ t01_task_count：本地证据中出现该来源表的 T01 任务数量
    └─ schema_*：已采集来源 DDL 的字段清单和证据任务
```

`source_table_comment` 是最适合读者理解“这张表是干什么的”的字段；`schema_fields` 是技术结构，不等于字段中文注释。多个中文说明并列时，说明不同 T01 任务对同一来源表存在不同写法，原样保留，不强行合并。
