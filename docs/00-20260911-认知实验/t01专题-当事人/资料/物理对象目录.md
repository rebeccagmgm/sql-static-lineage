来源：[原始元数据 SQLite](<E:/02_area/股衍数据-数据cookbook/sql-static-lineage-cache/schedule-evidence/tasks-sqlite/table-metadata-catalog/table-metadata-4877b15fb9a9accd-e5c48df0-e117-4469-8eb4-e62d3568950b.sqlite>)。使用只读连接查询 `tables` 与 `fields`，按 `tables.id = fields.table_id` 关联。

精确的候选检索条件为 `lower(qualified_name) GLOB '*t01_*'`；再检查最后一个点号之后的对象短名是否以字面量 `t01_` 开头。这里的下划线是字面字符，不使用未转义的 SQL LIKE 下划线通配符。

同一份数据源下的记录也可能保留不同采集信息；目录没有按简称合并对象。整个目录覆盖校验：163 + 555 + 59 = 777，目录行号不重复。
