# 消息、分发与回访

[返回入口](00-20260911-认知实验/t07专题-营销/README.md)

## 1. 触达包含不同层次

| 层次 | T07 对象 | 本层能说明什么 |
|---|---|---|
| 内容或策略配置 | 推送策略附加信息、触发事件定义/参数、金钥匙分发营销 | 准备用什么内容和规则触达 |
| 消息 | `t07_push_msg` | 广播或定向消息的身份、内容、应用渠道与发送相关时间 |
| 行为明细 | `t07_gks_distr_det` | 特定来源分发行为什么时间、由谁记录 |
| 活动组织 | CC2 活动、参与人员、回访策略 | 活动设置、待联系范围与回访安排 |
| 任务记录 | `t07_cc2_clbk_task`、`t07_mio_ai_call_out_task` | 分配、执行、结果相关字段；其中也有尚未生成执行任务的任务池记录 |
| 回执及消费 | T05 推送事件、推送效果明细 | 发送、接收、点击由另外的事实来源提供 |

## 2. 广播和定向消息共用一张表

99670 将广播 `S_BROADCASTS` 的 `MID` 拼为 `MSC001-`，消息类别写 `BROADCASTS`；99671 将 `S_MESSAGES` 拼为 `MSC002-`，类别写 `DF_MSG`。同一个裸 MID 不自动是同一条消息。[广播](attachments/04-消息分发与回访/IMG-04-消息分发与回访-20260914110643014.sql)、[定向消息](attachments/04-消息分发与回访/IMG-04-消息分发与回访-20260914110645151.sql)

两者读取窗口和分区日期不同：广播从当日源分区读取近七天消息，按消息时间的日期写目标；定向消息读取调度日及此前三天的源分区。消息类型取 `EXTERN` 中的 `pushMsgType`，未必只是一项短代码。

表内有消息，不足以证明具体设备已收到或用户已阅读。应用渠道与消息编号也不能代替客户身份。

## 3. 一个明确的效果消费例子

184621 的 `pdata_nds.wt_ecom_push_info_det` 从 T05 推送事件取设备、实际推送时间、接收确认时间、阅读点击时间，再按 `Msg_Id` 内连接 T07 消息。[完整 SQL](attachments/00-全貌与范围/IMG-00-全貌与范围-20260914110647092.sql)

它只保留 `msg_type_cd like '%edios%'` 的消息，在七天窗口内从该字符串拆出策略号。时间为 `'0'` 时转为空值。这里的策略号由字符串协议提取，未证明等于 `t07_cam_strg.Cam_Strg_Id` 的完整带前缀身份。

Join 仅写消息号，左右日期并未一并等值连接；同一消息在窗口内是否重复，需要行数据验证。内连接还会丢掉没有消息元数据匹配的事件。因而该明细是特定消费口径，不能直接称所有推送的完整到达率分母。

## 4. 金钥匙：内容对象与行为明细

`t07_gks_distr_cam` 保存分发内容、标题、摘要、链接与二维码等，`t07_gks_distr_det` 保存分发编号、活动编号、业务类型、统计类型、员工与客户识别码。

63001 和 63002 分别生成 `GKS006-`、`GKS007-` 分发编号；命中内容关联时活动号使用 `GKS004-RESOURCEID`。前者员工来自 `ERPID`，后者来自 `USERID`。两分支的“员工编号”不能仅凭目标列同名就当成同一编码体系。[63001](attachments/04-消息分发与回访/IMG-04-消息分发与回访-20260914110648974.sql)、[63002](attachments/差异与待核问题/IMG-差异与待核问题-20260914110652490.sql)

63002 的来源注释写 `M_STATISTICEVERYRECORD2_F`，实际 `FROM` 为 `M_STATISTICEVERYRECORD2`。来源说明、真实读取与目标来源分区要分别核对。

## 5. 呼叫中心活动、成员、策略与任务

`t07_cc2_act_info` 管理活动时间、执行部门、问卷、免打扰、是否自动分配和二次回访等设置；`t07_cc2_act_mem_info` 是参与人员及联系安排；`t07_cc2_clbk_strg` 是活动下的策略参数/序号。

`t07_cc2_clbk_task` 进一步保存任务状态、分配人、执行人、执行次数、结果、资产账户、质检、合并、失效等信息。它是业务回访任务，不是 Horae 调度任务。

| 来源 | 已见行为 | 统计影响 |
|---|---|---|
| `C_CCB_TASK`，62903 | 任务号取源值，活动号为 `CC2008-ACT_ID`，保留执行次数/结果/通话时长 | 行数是任务记录数，不能直接等于拨打次数 |
| `C_CCB_FIL_TASK`，136985 | 回访任务历史来源进入同一目标 | 是否与当前任务重复、应如何优先选择，需要源关系核实 |
| `C_CCB_TASK_POOL`，233453 | 仅取未删除且 `TASK_GENERATED_FLAG='0'`，多项执行字段留空 | 这是尚未生成任务的池记录，不能计为成功执行 |

证据：[62903](attachments/04-消息分发与回访/IMG-04-消息分发与回访-20260914110653993.sql)、[136985](attachments/04-消息分发与回访/IMG-04-消息分发与回访-20260914110655414.sql)、[233453](attachments/差异与待核问题/IMG-差异与待核问题-20260914110654640.sql)。
