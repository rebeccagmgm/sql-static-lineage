## 2. 任务名 GMP014 不等于实际来源系统

四个任务名均带 GMP014，但已见 SQL 使用 `ODATA_N_HCC.G_RIGHTS`，`Data_Src_Cd='HCC'`；任务配置也指向香港库。主资料取 `BATCH_ID`，中文名从 `BATCH_NAME` 的 `zh_cn` 属性读取；市场代码使用香港默认 schema 下的 `T99_CD_CVT_MAP`。

这说明任务名称后缀、业务来源标志、真实源表、代码转换表是四项不同证据。不能以任务名把这组资料解释为境内礼品系统，也不能用境内 `REF_CD_CVT_MAP` 代替当地转换表。

## 3. 数量列为什么不能直接合计

160668 的可见投影如下：

| 源字段 | 目标字段 | 注释含义 |
|---|---|---|
| `TOTAL` | `Gift_Tot` | 礼品总数 |
| `YLQ` | `Had_Draw_Vol` | 已领取数量 |
| `SYZ` | `Enga_Vol` | 使用中数量 |
| `YFF` | `Had_Distr_Vol` | 已发放数量 |
| `DFF` | `Wait_Distr_Vol` | 待发放数量 |
| `BFF` | `Not_Distr_Vol` | 不发放数量 |
| `YGQ` | `Had_Exp_Vol` | 已过期数量 |

投影直接保留源数量，没有证明它们互斥，也没有验证相加等于总数。已领取与已发放可能是不同流程口径，必须有状态定义和数据检查才能给出守恒公式。同一批次的多期历史更不能跨日期相加成库存。
