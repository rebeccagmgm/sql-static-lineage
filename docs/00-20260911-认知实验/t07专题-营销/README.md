# T07 学习入口：从营销安排到参与、触达与反馈

整理日期：2026-09-14。

**T07 组织的是营销活动、策略、客群、内容和激励，以及围绕它们产生的部分参与与执行记录。读懂它，要先分清“安排了什么”“面向谁”“做过什么”和“观察到什么结果”。**

例如一次直播，可以同时有活动主记录、直播详情、产品关联、客户报名、观看统计和销售汇总。这些表并不处于同一种粒度；报名不等于观看，观看不等于购买，购买也不能仅凭时间接近就归因于这场直播。

本专题吸收 T01 的对象推导与真实案例、T03 的分维度阅读与交叉矩阵、T05/T06 的逐表覆盖与证据边界。范围从 T07 原始目录、字段、字典、Wiki 和任务 SQL 重建。正文围绕整个营销主题展开。
