## 1. 先从活动和服务这两个对象开始

61527 将 `N_CRM_ACTIVITY_SERVICE.OBJID` 转为 `RMS011-ACT-OBJID`。61635 读取活动服务关联表，将活动端点转为 `RMS011-ACT-ACTIVITYID`，服务端点转为 `RMS005-SERV-SOURCEID`；关系类型为 `01`，并保留是否手动签到生成的标志。[活动](attachments/06-投研内容与活动办理/IMG-06-投研内容与活动办理-20260914110645561.sql)、[关系](attachments/02-关系时间与连接/IMG-02-关系时间与连接-20260914110643755.sql)

这是一条可复核的跨主题连接：T07 活动关联 T05 服务事件。服务号不等于活动号，关系行不等于服务行；同一活动可以关联多个服务对象，具体基数需数据确认。

## 2. 报名另外拥有自己的身份

94137 从 `P_PORTAL_ENROLL` 生成 `RMS036-ID` 报名号、`RMS011-ACT-SOURCE_ID` 活动号、`RMS034-OBJID` 参与人号。报名状态、签到时间、签到标志、是否外呼分别保存。[报名 SQL](attachments/03-投研活动服务报名与合集/IMG-03-投研活动服务报名与合集-20260914110646390.sql)

代报名员工经过组织对象、系统用户、OA 用户映射，优先取 ERP 编号，未匹配可回退用户名。不能把全部 `Emp_Id` 无条件当作 ERP 员工主键。

该 SQL 中服务类型的转换条件仍使用 `T07_ACT_ENRL_INFO / Rms_Serv_Type_Cd`，实际目标却是 `T07_PROM_ENRL_INFO / Serv_Type_Cd`。可能涉及历史命名或共享映射，但本次没有转换表行值，故不声明映射覆盖已验证。

## 3. 活动下的日程与员工参与

99330 将日程编号拼为 `RMS051-OBJID`，活动编号为 `RMS011-ACT-SOURCEID`。产品需以证券代码、类型和市场连接 RMS 证券资料，生成 `RMS-GUID`；不能仅用证券代码替代该 Join。[日程 SQL](attachments/03-投研活动服务报名与合集/IMG-03-投研活动服务报名与合集-20260914110649756.sql)

99949 使用同一日程号，按不同源标志分别写参与类型：`01` 计划、`02` 实际、`03` 历史流程、`04` 有效参与。若同一员工同时满足多个标志，将处于不同类型记录中；四种行数不相加作实际员工人数。[参与 SQL](attachments/02-关系时间与连接/IMG-02-关系时间与连接-20260914110647398.sql)

角色关联中的来源快照过滤和身份回退都需要保留；本次没有把这些查询转成可以直接用于全主题的通用 Join 模板。

## 4. 路演主记录经过选择规则

61582 按路演申请连接服务，限制服务 `STATUS='100'`、特定类型与删除标志，再对每个 `REQUESTID` 按创建时间升序取第一条。结果的活动号却是 `RMS005-服务OBJID`。[SQL](attachments/06-投研内容与活动办理/IMG-06-投研内容与活动办理-20260914110649289.sql)

这解释了为什么路演申请、服务事件和 T07 路演活动不能简单按相同裸 ID 互连。若一个申请对应多次服务，代表活动的选择规则也不同于统计所有服务。

## 5. 投研合集是另一条内容路径

134984 从研究合集定义产生 `RMS079-ID`，保留类别、展示类型、父级与草稿关联；134985 的内容关系将该集合连接 `RMS081-TARGET_ID`。元素资料另有标题、简介、类型和有效标志。[合集](attachments/03-投研活动服务报名与合集/IMG-03-投研活动服务报名与合集-20260914110652292.sql)、[元素关系](attachments/02-关系时间与连接/IMG-02-关系时间与连接-20260914110650569.sql)、[元素快照](attachments/03-投研活动服务报名与合集/IMG-03-投研活动服务报名与合集-20260914110654527.sql)

父级、草稿字段未随 `Set_Id` 一起加前缀，元素 SQL 也有格式压缩及类型 Join 候选。这里只确认对象与可见关联规则，不从它构造未经验证的全量内容树。

## 6. 一个连贯的阅读练习

先选某个 RMS011 活动及来源，分别查询其报名、日程、活动员工和服务关系。每张表先保留自身身份、角色和时间，再决定最终是统计报名人、实际参与员工还是服务记录。只有知道需要的是哪种事实，才选择相应路径。合集内容可以作背景，但不要直接并入同一活动粒度。
