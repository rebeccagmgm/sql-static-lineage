## 1. MIO015：先建立策略，再解释活动端点

112262 的通用策略只取当日 `H_GENERAL_STRATEGY` 中 `STATUS='configed'` 的记录。策略号为 `MIO015-ID`，分类为 `MIO_COMN_CAM_STRG`。策略有效状态在这里写常量 `01`，不能从它反推每一次推送都成功。[主策略 SQL](attachments/03-来源职责与交叉矩阵/IMG-03-来源职责与交叉矩阵-20260914110643657.sql)

112265 对同一批源记录建立策略活动关系，关系类型为 `01`，对应字典“策略对应的具体活动”。活动端点分三种来源处理：

```sql
-- 原SQL关键投影节选；完整过滤和历史维护见112265。
case
  when source = '魔方活动' then concat('MMP004-', ACTIVITY_ID)
  when source = '自研活动' then concat('MSA015-', B.ID)
  else source
end as Prom_Id1
```

自研活动的 `B.ID` 不是拿源 `ACTIVITY_ID` 直接当号，而是用 `A.ACTIVITY_ID = B.ACTIVITYNAME` 匹配当日 `I_MARKET_INFO`。[关系 SQL](attachments/差异与待核问题/IMG-差异与待核问题-20260914110643041.sql)

**直接结论：源活动字段在不同分支里可能承载编号、名称或其他来源文本。** “策略表有活动字段”不足以证明它可直接连接公共活动主键。

## 2. 名称匹配和历史比较各有一层风险

这段名称 Join 没有显示按名称去重。若源活动同名，可能出现多个关系候选；未匹配时活动号可能为空。该分支的历史比较键是 `Cam_Strg_Id + Strg_Prom_Rela_Type_Cd`，活动端点作为可变属性比较。这是在按策略和关系类型维护一个端点的设计。

若某策略同一时点实际可以关联多个同类型活动，需要进一步核对源的基数约束及现存数据；不能把这个未验证前提写成一对一业务事实。

历史采用 `Strt_Date <= d AND End_Date > d` 取开链；源消失或端点变化会生成关闭/新版本的处理。这里的 d 是加工观察日，不自动等于源配置真实变更时间。

## 3. CPL：规则号与关系端点不一致

86912 的分群规则关键投影为：

```sql
ID as Cust_Seg_Id
-- 取同名规则中ID最大的记录
row_number() over(partition by NAME order by ID desc) as RN
```

143762 的分群关系则为：

```sql
concat('CPL001-', CLUSTER_ID) as Cust_Seg_Id1,
'10' as Cust_Seg_Rela_Type_Cd1,
concat('CPL014-', GROUP_ID) as Rela_Cust_Seg_Id1
```

[规则 SQL](attachments/03-客群名单与参与/IMG-03-客群名单与参与-20260914110643005.sql)、[关系 SQL](attachments/01-策略到活动与客群/IMG-01-策略到活动与客群-20260914110646014.sql)

至少有两件事要分别核实：一是编号前缀，二是同名规则去重后关系端点是否仍被保留。仅补一个字符串前缀不能证明关系全量正确；正文不生成未经证实的通用 Join。

## 4. CPL019 提供另一种“策略与客群”的记录

238508 的策略号明确为 `MIO020-STRATEGY_ID`，保存业务日、客群文件号和客户号，却把 `Cust_Seg_Id` 写空。这个对象回答的是策略对应哪份名单及客户，而不是规则层的客群关系。[SQL](attachments/03-来源职责与交叉矩阵/IMG-03-来源职责与交叉矩阵-20260914110650389.sql)

它只按来源分区覆盖，`Busi_Date` 是普通业务列。若希望追踪某策略每天全部成员的变化，必须先核对该源快照是否包含历史业务日，以及被覆盖后是否保留完整历史。

## 5. 活动进入组合标签的真实消费

92199 限定 MIO 来源、指定项目、活动状态 `31`，并按活动开始日期限制范围；用 `Prom_Id` 连接 `grp_def` 中的 `MIO_CAMPAIGN`，再将 `Prom_Stg` 映射为标签。[消费 SQL](attachments/01-策略到活动与客群/IMG-01-策略到活动与客群-20260914110652134.sql)

这能说明所选活动怎样得到“阶段标签”，不能说明全部营销活动均已进入组合，也不能从一条标签记录推断活动触达或转化成功。
