## 如何理解这个映射

- A/B/C 是按“记录主要描述什么”组织的目录：主体及资料、连接关系、围绕主体的业务记录。不是数据仓库加工层，不声明外键或实体继承。
- 每个对象只给一个主要导航位置，以便查找；并不否认其字段同时涉及多个方面。业务范围、来源、schema 和时间方式不是同级目录。
- 所有归类都是阅读解释，主要依据原始表/字段元数据；已读 SQL 只核实对应来源分支。分类覆盖不等于全量 SQL 验证覆盖。
- “结构入口”列出前六个非分区字段，供判断对象语境，不代表主键。日期、来源另外显示，避免与业务层级混合。
- 暂挂项保留歧义，未知项单列。未解析及其他实现范围继续在 [完整物理目录](<E:/02_area/股衍数据-数据cookbook/sql-static-lineage/docs/00-20260911-认知实验/04-t01-对象目录-2.0.md>) 查找。
