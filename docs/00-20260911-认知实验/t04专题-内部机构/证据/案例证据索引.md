## 3. 候选检索怎样复核

另补 [按来源系统汇总](00-20260911-认知实验/t04专题-内部机构/资料/来源系统汇总.md) 与 [源表到模型的任务映射](attachments/来源表与模型映射明细/IMG-来源表与模型映射明细-20260914110757655.json)：识别显式 USE 后的 T04 写入，按贴源库汇总明文读取，并将来源注释后的模板读取另列。该口径与下面原有逐表候选不同，统计不可混用；它没有取代正文中的逐段 SQL 核验。

[候选索引](attachments/README/IMG-README-20260914110801911.json) 按任务保存 INSERT、FROM、JOIN 的词法候选。未限定 schema 的标识按采集头部 hiveDb 解释，模板变量保持未解析，CTE 可能误入候选；它既不覆盖所有 SQL 方言，也不等于项目正式静态血缘。

按表找到候选后，要打开对应完整 SQL，区分 CREATE、实际写入、自读、临时表和普通读取，再看来源参数、分区及具体 Join。不能直接把所有候选连线发布成数据图。

本版没有写入业务数据库、修改采集器、重建图谱或更改 T01–T03 文档。新建内容全部位于 t04专题目录。
