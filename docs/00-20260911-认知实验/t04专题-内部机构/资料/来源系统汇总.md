## 范围与计数

本次从已有 T04 SQL 候选中识别 1,070 个含 T04 模型写入的任务，写入对象涉及 266 个模型表名（跨 `pdata_n`、`pdata_nds`、`pdata_hk`、`spdata_n`、`spdata_nds` 及历史快照；不等于主阅读集合的 226 张 pdata_n 表）。其中 845 个任务含可识别的 ODATA 明文读取。

来源分为 111 个贴源库分组：**523 张表有明文 FROM/JOIN 引用，另有 136 张仅有来源注释与模板读取配对，共 659 张来源表候选。** 同一表既有明文读取又有模板时只归入前一列；模板配对尚不证明运行参数。

T01 参照文件以一份 `real_src_tbl` 导出 CSV 为范围，并保留 `_col2`。本页依据 SQL 快照，未取得与之同口径的 T04 实值统计，所以不填写数据量、占比或来源行数。

## 几个名称需要特别解释

- **PAS**：库目录旧名为“绩效考核系统”；数据源目录同码同时出现“智慧人力系统”和带“大易云招聘数据库”别名的记录。正文分别解释组织人事与招聘分支，不把 PAS 全部写成绩效得分来源，也未把两套来源合成一条已核实物理连接。
- **IOA 与 OAS**：IOA 本地名为“企业门户2.0”，OAS 为“广发证券办公自动化系统”。已读 IOA 部门／用户加工可保留 OAS 来源标签；两者在本页仍分别保留。
- **LMS 与 MLS**：LMS 名称来自本地库目录“移动学习系统(爱学)”；CD100 的 MLS 也有这一名称。本页没有据中文名相同擅自改库来源码。
- **SSO 与 ATP**：SSO 库目录称“华锐ATP极速柜台系统”，数据源目录也有 ATP 名称；保留 SSO 库分组，不按缩写猜成通用单点登录系统，也不与 ATP 库合并计数。
- **GTS**：数据源目录同码出现黄金交易与税务管理两个系统，当前表组为用户／角色／权限相关对象，尚未逐表核定采集连接，不能沿用 T01 某张交易表的名称结论。
- **KAS 等待核实名称**：保留来源表和任务入口；不按单张用户表的内容虚构系统正式名称。

## 怎样使用这些数量

任务数按库内任务 ID 去重，同一任务可读取多个系统，因此各行任务数不能相加。IOA 被大量任务用于账号或部门对齐，命中多不等于该系统提供了最多的主体业务数据。

映射的单位是“同一任务内读取了源表，并写入这些 T04 表”。多写任务中尚未逐写入分配每张源表，明细会列出全部候选目标；没有将这种同现关系标作字段血缘。模板缺参、仅经模型中间表输入、或当前词法检索未覆盖的来源仍可能不在表中。
