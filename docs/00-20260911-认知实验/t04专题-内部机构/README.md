# T04 机构专题

整理日期：2026-09-14。证据来自本地 SQLite 快照、已采集任务 SQL 和本次读取的 Wiki 正文。

**T04 把“公司怎样组织人、怎样在系统中分配身份和职责、怎样记录相关管理活动”放进同一个主题。** 内部机构只是其中一类对象。员工、职位、团队、系统用户、角色、课程、应聘和商机各有自己的身份与记录粒度。

最值得先建立的认识是：**组织归属、身份对应、权限授权、业绩分配是四种关系。** 它们可以连接同一个人，却不能用同一张组织树解释。

## 用真实取数把知识连起来

读 [07 从模型到下游消费](00-20260911-认知实验/t04专题-内部机构/07-从模型到下游消费.md)。这里串起三条已经读到具体连接条件的路径：

1. 员工及机构关系 → 员工基本信息宽表：看身份映射和历史选择如何改变结果。
2. 行政机构、柜台编码与分公司归属 → 营业部归属宽表：看“同一机构的不同编号”如何参与一次查询。
3. TIT 账簿部门配置 → T04 部门附加信息 → 互换持仓标的汇总：看机构配置怎样决定一笔交易使用的本币。

场外分支集中在 [01 的 TIT 案例](00-20260911-认知实验/t04专题-内部机构/业务专题/01-机构体系与跨系统映射.md) 和第三条消费链。它是整域的一部分。

## 这版到哪里为止

本版完成整域对象组织，并为六个主要分支提供了实际 SQL 案例；本地所有 T04 前缀元数据对象都有可检索位置，跨库对象和新旧快照差异单独保留。**逐表有目录不等于逐表完成生产、消费和业务验收。**

平台目录是 `PARTIAL`，码值快照是 `UNVERIFIED`。SQL 是静态证据，不能证明今天的运行结果、实际唯一性或当前权限生效。图库本次返回 `ARCADEDB_UNAVAILABLE`，没有将候选检索包装成已核实图谱闭包。具体快照时间、统计口径和未闭合环节见证据页。
