# 编码与关系：分清身份对应和业务关联

[返回入口](README.md)

同一对象的不同编号，需要身份对应规则；不同对象之间的持有、管理、成分或挂钩，需要业务关系。两者不能混成一种Join。

先读 [对象身份](建模基础/01-对象身份与层次.md)，再读 [时间与连接](建模基础/02-时间与连接.md)。具体对应见 [编号与XLA加工](实现详解/01-证券身份与XLA加工.md)，企业两端见 [股东关系](业务专题/05-企业股东与治理关系.md)，指数成分见 [参考体系](业务专题/09-指数利率汇率与宏观.md)。

`NEWS_SECU.grp_val` 在已采集定义中明确来自 `secu_id`；`TGT_SECU` 则来自两融表的 `tgt_secu_id`。定义原文见 [组合快照](资料/组合类型.json)。
