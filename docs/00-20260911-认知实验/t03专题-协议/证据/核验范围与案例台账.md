## 2. 全集发现过程和范围

元数据按 T03 前缀发现 1,073 条物理记录，不将不同平台、来源或 schema 的同名表合并。Hive / pdata_n 中有 346 条，PARSED 256、UNSUPPORTED 90。[[00-20260911-认知实验/t03专题-协议/资料/逐表对象目录|逐表目录]]为256条提供学习分组，其余记录仍在完整 JSON 中，不能误认为没有结构或没有业务价值。

SQL 检索母集为 26,043 条 hive-task 记录，保留 2,348 个 T03 文本候选。INSERT 写入候选 1,592、FROM/JOIN 读取候选 1,619，有交集，不做加法。检索未承担语法解析器职责，注释、同表自读取、动态变量、宏、不同 schema 和同名临时对象均需后续识别。

为避免“只列抽样任务，却不知道遗漏哪些表”，另建[[00-20260911-认知实验/t03专题-协议/证据/逐表SQL候选覆盖|逐表候选覆盖]]与[[00-20260911-认知实验/t03专题-协议/证据/逐表SQL候选映射.json|完整任务映射]]：覆盖256条可解析对象，限定显式 pdata_n 表名或默认 schema 明确为 pdata_n 的未限定表名。2026-09-12 修正默认库大小写及空库名误读下一行的问题后，该口径下26条没有写候选、117条没有读候选；空库名仍不推定物理库。修正说明见[[00-20260911-认知实验/t03专题-协议/证据/全域分支补充/覆盖与证据|全域补充台账]]。**没有候选不等于没有生产者或消费者**：可能有未采集任务、变量化表名、其他默认库或扫描方式未识别的 SQL；也可能是目录遗留对象，当前不能判定。

分类观察含77种路径，覆盖546个GUID；采集状态PARTIAL。通用分类、业务路径和技术目录不能混成一棵唯一业务树。[[00-20260911-认知实验/t03专题-协议/资料/平台分类说明|平台分类说明]]保留全部路径，正文采用独立学习分层。
