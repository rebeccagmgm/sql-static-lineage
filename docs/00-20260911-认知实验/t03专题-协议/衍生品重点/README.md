# 场外衍生品：从一笔互换进入T03

本分支位于T03全貌中的“交易合约”部分，覆盖互换、期权、外汇远期，以及围绕交易的账户、组合、履保、运营和收付款。账户、订单、其他经营合同的全域位置仍见[[00-20260911-认知实验/t03专题-协议/README|T03整体入口]]。

## 从这里开始，读到这里可以停

第一次学习，直接读[[00-20260911-认知实验/t03专题-协议/衍生品重点/01-一笔衍生品交易如何贯穿模型|一笔互换怎样贯穿模型]]。它始终跟着同一份S1：先确定双方的计算和付款约定，再发生部分终止，最后区分剩余持仓、组合要求、结算与付款。

读完能解释“为什么要有这些记录、业务变化时哪一类记录会变”，就可以停。下面的实现说明按问题进入，文件编号不表示必须依次读完的课程。

互换在例子中用腿表达不同收益或支付组成；期权还可能需要子交易和观察条件，远期结构需要区分币种、数量、方向和汇率。S1帮助理解对象为何分开，不能替代其他合约的具体条款与实现。

## 来源职责与主题边界

TIT的已读来源提供交易主信息、互换/期权要素、腿与工具、账户、组合、持仓及收付款。OIS提供客户资料及条件、报告安排与执行、产品、合约开发关系和参数。应先判断正在描述哪个对象，再选择该对象实际使用的来源和关联。

这些信息会跨主题表达：T01保存相关当事人资料及部分客户条件，T02保存产品，T03保存相应协议与关系，T05保存相关事件，部分归属结果及参数还涉及T98/T99。客户本身是产品型主体时，也不能与交易所引用的股票标的混成同一个“产品”。按T03前缀筛掉所有其他主题，会失去理解这笔业务所需的上下文。

通用协议身份、专用合约、内部结构、存续记录和管理关系的模型位置，集中在[[00-20260911-认知实验/t03专题-协议/衍生品重点/00-模型层与贴源层如何对应#1. 从模型入口看：不是一张主表下面挂所有附表|模型层次对照]]。那里说明共性身份与专用表达的关系；它不表示所有专表都由T03_AGT逐层加工产生，也不证明所有关系已经有完整物理连接。
