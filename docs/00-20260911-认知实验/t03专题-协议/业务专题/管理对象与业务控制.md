# 管理对象与业务控制：哪些账户和交易放在一起管理

所属位置：全貌中的“管理对象与安排”分支。读完应能区分账户、资产单元、投资计划、账簿和保证金组合，知道“归到哪里管理”与“允许做什么”各由什么信息表达。

有了账户和具体交易，系统还需要组织管理范围：哪些资产属于同一管理单元，哪个计划采用什么策略，哪些交易归属一个账簿，哪些合约合并管理履保。管理对象因此有自己的身份、成员或关联信息，以及适用配置。

这些对象回答不同问题。账簿侧重交易的管理归属和配置；投资计划保留策略与运行阶段；保证金组合通过成员与账户关系界定管理范围；权限则限定某个操作员或对象能办理哪些业务。不能因都叫“组合”就先把它们认成同一个对象。

| 场外保证金组合 | 组合成员、关联账户、参数及结果分层 | [[00-20260911-认知实验/t03专题-协议/衍生品重点/00-模型层与贴源层如何对应\|组合成员入模链]] |

## 管理范围与控制属性分开看

管理对象回答“哪些对象放在一起管理”；关系记录成员是谁；权限、额度和参数说明这个范围内采用什么规则；追保或其他结果则记录业务处理情况。这四者可以关联，但不能互相替代。

例如一组场外合约通过组合成员关系纳入同一保证金组合，组合再关联账户及履保参数。参数存在只说明有条件配置；是否产生追保要求要看结果记录。OIS中的客户条件又可能落在T01，不能因为都服务于场外业务就归成T03合约属性。
