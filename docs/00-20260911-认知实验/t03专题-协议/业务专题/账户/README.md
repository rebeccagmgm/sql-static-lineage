# 账户：钱、证券、登记与管理分别落在哪里

在全貌中，本篇对应“账户”分支。读完应能区分资金账户、证券账户、基金登记账户、渠道交易账户，以及内部管理账户；遇到一个账号时，知道还需什么信息才能确定它代表的对象。

## 先建立业务认识

一项投资业务往往同时涉及钱、证券和不同渠道。客户身份回答“是谁在办理”，账户则回答“在哪个登记或核算范围办理”。同一客户可以有多个账户，同一个资金账号也可能关联不同市场的证券账户。

因此账户模型要同时保留两类信息：一类是账户本身的身份、持有人和使用配置；另一类是账户之间、账户与产品之间的关系。余额和持仓在这些身份之下继续增加币种、产品、日期等维度。查“有哪些账户”和查“持有多少资产”从这里开始分开。

## 怎样接回整个T03

合约会引用账户，订单可能申请开立账户或通过账户办理业务；管理单元把账户、产品或交易放进某个管理范围。账户本身通过主体关系或持有人字段连接T01，通过产品关系或持仓中的产品身份连接产品侧。

完成本分支后，应能画出所学来源中的“客户—账户—产品或持仓”关系，并指出每个编号属于哪一层。各系统的账号体系需要分别核对，具体差异在三条路径中展开。
