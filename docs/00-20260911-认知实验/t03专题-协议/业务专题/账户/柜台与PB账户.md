# 柜台与PB账户：一个资金账号为何对应多个模型身份

所属位置：[[00-20260911-认知实验/t03专题-协议/业务专题/账户/README|账户分支]]。本篇解释RCC/ICC的资金与证券账户分工，以及XPB的父子账户分工；读完应能说明“内部对象ID、资金账号、证券账号”为什么有时不同，有时又会在不同记录中重复。

RCC是零售柜台新一代清算系统，ICC是机构柜台新一代清算系统，XPB是迅投PB主经纪商系统。客户办理证券业务时，资金侧需要账户承担资金管理与业务配置，证券侧需要按市场登记证券账户；PB系统又保留内部管理对象，所以不能预设所有来源都是“一个客户一个账号”。下面分别还原两套实现。

## 模型对应：先分清一行是谁

| 对象 | 模型 | 一行的业务定位与主要信息 |
|---|---|---|
| 柜台资金侧账户 | `T03_AST_ACCT` | 以资金账号及10201定位；保存持有人、费用、权限等配置 |
| 柜台证券账户 | `T03_SCR_ACCT` | 以资金账号及“10101-市场-证券账号”定位；对应特定市场的登记账户 |
| XPB子账户 | `T03_PB_FND_ACCT` | 已读分支以子账户ID定位，资金账号和共用属性来自父账户，产品归属经父账户关系取得 |

例如同一资金账号关联沪、深两条证券账户，它们共享资金侧定位，但证券登记身份不同。XPB中多个子账户又可能引用同一父账户，因此内部子账户数与不同资金账号数也可能不同。

这解释了为什么不能只数 `Agt_Id` 或 `Fnd_Acct` 就同时得到客户数、账户数和产品数：这些字段指向的对象不同。此处按已读来源说明身份构造，记录的历史版本仍按具体模型处理。
