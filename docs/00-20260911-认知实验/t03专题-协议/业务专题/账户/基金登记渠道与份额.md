# 基金登记、渠道与份额：买了什么，通过哪里办理，登记在哪

所属位置：[[00-20260911-认知实验/t03专题-协议/业务专题/账户/README|账户分支]]。读完应能区分基金登记账户、渠道交易账户和确认单份额，并理解它们为什么需要三种身份。

购买基金时，投资者既要在登记体系中被识别，也要通过某个销售渠道办理申请。登记账户用于识别登记侧的投资者账户，渠道交易账户保留通过哪个销售商、网点及交易账号办理。一次办理得到确认后，又可能形成带确认编号、日期、收费类别和剩余份额的记录。

所以“某人在哪登记”“通过哪里办理”“某笔确认还剩多少份额”是逐步深入的三个问题。一位投资者的多次办理可以汇集到同一登记账户，但渠道和确认明细仍需保留。下文用STA（资产管理分TA系统）与TA5（资产管理TA5）说明对应关系；这两条来源的具体拼键格式有差异。
