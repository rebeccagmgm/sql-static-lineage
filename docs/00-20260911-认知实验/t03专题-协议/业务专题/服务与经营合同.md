# 服务与经营合同：约定、履行明细与现金流

所属位置：全貌中的“服务签约与经营合同”分支。读完应能识别合同约定与履行记录的层次，知道为什么合同、计费周期、提款、付款和现金流不能各算作一份独立合同。

合同先表达双方建立什么安排：提供投顾服务、开展托管、融资租赁、借款或采购等。之后的履行过程才会产生计费、放款、提款、支付和其他明细。一份合同可以分多次履行，每次履行又可能对应多个日期或费用项目，所以模型需要同时保留合同身份和明细身份。

下文有两条较完整的已读链：投顾的“签约—计费周期—收费事件—收入消费”，租赁的“父合同—放款批次—现金流”。托管、借款、采购、劳工与存款用于对照不同业务的模型落点。其中现金流是否为计划、应付或实际支付，按具体字段解释；合同身份尚未填齐的分支明确保留缺口。

| 业务 | 先理解的对象关系 | 主要来源 |
|---|---|---|
| 投顾服务 | 签约说明服务条件，计费周期说明本次如何计算，收费事件记录处理 | CRM，金管家综合服务系统 |
| 托管 | 合同与相对方、所代表产品、托管产品分别关联 | GCM，广发合同管理系统 |
| 融资租赁与借款 | 合同下分批放款或提款，金额按明细和日期继续展开 | GLM，广发租赁业务管理系统 |
| 采购与劳工 | 付款及合同处理记录；已读来源身份完整程度不同 | 本地中文来源说明见对应节，不猜系统全称 |
| 公司存款 | 存款约定与每日存款记录分别核对身份和日期 | ALM，自有资金管理系统；另有协议候选待核验 |
