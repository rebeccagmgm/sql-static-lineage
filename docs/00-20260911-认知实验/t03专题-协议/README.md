# T03学习入口：先全貌，再单维度，最后交叉理解

## 第一步：建立全貌

读[[00-20260911-认知实验/t03专题-协议/00-全貌与证据边界|T03全貌]]，先知道它管理什么对象、与当事人和产品有什么联系，以及TIT/OIS等系统分别提供哪些信息。此时不要求记字段和加工条件。

## 第二步：每次沿一个维度学清楚

| 阅读维度  | 入口                                           | 读完应该能回答                       |
| ----- | -------------------------------------------- | ----------------------------- |
| 业务对象  | [[00-20260911-认知实验/t03专题-协议/维度学习/业务对象\|业务对象]]   | 账户、合约、合同、订单和管理对象分别为何存在？       |
| 模型表达  | [[00-20260911-认知实验/t03专题-协议/维度学习/模型表达\|模型表达]]   | 身份、属性、关系、结构、业务事实和控制信息分别保存什么？  |
| 来源职责  | [[00-20260911-认知实验/t03专题-协议/维度学习/来源职责\|来源职责]]   | TIT/OIS等系统各贡献哪部分信息，源对象层级怎样组织？ |
| 加工与消费 | [[00-20260911-认知实验/t03专题-协议/维度学习/加工与消费\|加工与消费]] | 拼身份、转码、关联、维护历史及下游使用分别改变了什么？   |

“模型表达”中的分类属性是对象的一种描述，另用字典解释；它不与业务对象、来源系统混排。各维度页提供具体认识和深入入口，详细SQL保留在对应实现文档。

## 第三步：用矩阵把知识连起来

读[[00-20260911-认知实验/t03专题-协议/维度学习/交叉矩阵|业务对象 × 模型表达 × 来源 × 实现]]。先定位业务对象，再横向看模型和来源；选一个具体业务追到底，而不是把整个矩阵一次背完。

进入场外分支时，直接读[[00-20260911-认知实验/t03专题-协议/衍生品重点/01-一笔衍生品交易如何贯穿模型|一笔互换贯穿模型]]，用同一份交易的变化串联已经认识的维度。读到能够区分各类记录即可停；需要核对真实来源或具体疑点时，再到[[00-20260911-认知实验/t03专题-协议/衍生品重点/README|场外分支的按问题入口]]，不必依次通读所有实现文档。
