## 2. 仓库属性和源性质并存

旧命名域 `FIX_AST_PROP_CD / CD2070` 的 `1/2/3/4/5/6` 分别为公共、部门、员工、闲置、第三方使用、待分配资产，来源 `MANU_MATN`，日期 2026-05-15。新 `AST_PROP_CD / CD043` 的固定资产维度使用 `31…36`。

代码也有两种保存方式：主表把 `ASSET_NATURE` 转码，分类历史类型 `03` 原样保留。相同中文含义可以支持核对，但本地没有独立转换表明细，**不能证明真实映射一定是 `1→31`、`2→32`**。财务消费者读的是分类历史的原性质，不可直接换成主表仓库属性值。

## 4. 鉴别与联系人有一处明确差异

`IDTY_INFO_TYPE_CD / CD006` 命中 `40200 / 序列号`、`40201 / 硬盘序列号`，来源 `MANU_MATN`，业务日期 2023-06-28。SQL 的 `SN_NO` 和 `DISK_SERIAL_NUM` 分别使用这两个值。

同份 SQL 的 MAC 分支使用 **`40101`**，本地该域只命中 **`40100 / MAC地址`**。状态应是“SQL 已使用、本地字典未收录”，不能静默替换为 `40100`，也不能仅凭本地缺失认定 `40101` 错误。[236114.sql](../证据/SQL/236114.sql)

`LKMAN_TYPE_CD / CD028` 的 `61 / 租借使用人`，备注“我司固定资产租借”，来源 `MANU_MATN`，日期 2026-05-15。这支持把联系人资料与责任员工关系分开。
