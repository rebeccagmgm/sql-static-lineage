# T10 资产专题：一项资产是什么，怎样变化，由谁负责

整理日期：2026-09-14。

**T10 确实存在，主题编码为 AST / Party Asset / 资产。本次找到的主模型是一套以资产台账为中心的表达，已读生产来源集中在 FAM 我司固定资产。** 它把资产身份、分类状态、设备资料、责任关系和固定资产专属信息拆开保存。理解它，先分清“资产本身”“资产的某种状态”“资产与人的关系”和“某日的财务附加信息”。

例如一台电脑可以只有一个资产标签号，同时具有在用、投保和入账三种状态；它的使用部门、成本承担部门、责任员工、租借使用人也可能不同。把这些记录直接连在一起，一项资产就可能变成多行。
