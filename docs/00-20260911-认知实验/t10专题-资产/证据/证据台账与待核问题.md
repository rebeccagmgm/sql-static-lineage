## 已知差异与待核问题

| 问题 | 已确认 | 对使用的限制 / 下一步证据 |
|---|---|---|
| 资产地址 | 236112 是测试任务，日期替换且部分 SQL 注释压平 | 需正式物理对象、有效源码及部署状态；不列入十张主模型 |
| 分类类型 `03` | 236117 写源性质，236331 实际读取 | 旧分类类型域未收录，需要正式 AST 域或登记说明 |
| MAC 类型 `40101` | SQL 写 `40101`，本地 CD006 只有 `40100` | 核对当前字典；不自动改码 |
| AST 与旧 FIX_AST 域 | 旧域部分含义与 SQL 角色对应 | 正式字段绑定未确认，不能凭命名接续 |
| 转换完整性 | 多字段映射未命中回退源值 | 缺转换表实值、覆盖率与重复映射核验 |
| 固定权属自有 | 主表固定 `01/GF` | 源是否有其他权属未验，不用代码常量证明业务正确 |
| 制造商 | 源“供应商”写入 `Mfr` | 两种业务角色是否可合并未知 |
| 责任员工 | 取 `DISTINCT USER_ID,EMP_ID`，未按关系类型和有效日过滤 | 需映射基数、历史解释与源完整性验证 |
| 空端点、多行 | 多分支未过滤空状态/人员/机构/鉴别内容 | 需业务数据核验；有关系行不等于存在有效关联 |
| 账簿端点 | 账簿编号转小写后存关系 | 缺确认的账簿主对象及实际 Join，不造 T09 边 |
| 财务时点 | 全性质历史连某日 FA 快照，右侧未限来源 | 需消费者确认时点口径、映射基数与历史 FA 变化 |
| 后续投递 | 调度下游存在 236449 | 缺接收端完整物理身份、当日接收数据与验收 |
| 运行质量 | 有 49 个 T10 质量任务 | 未取得具体日期运行与结果；检查配置不等于检查通过 |

## 增补原则

新增来源先核对物理身份和模型对象，再解释粒度、类型、时间与实际转换，不按新 `t10_` 前缀直接扩域。后续优先验证财务映射时点与基数、责任员工转换，以及字典 `03/40101` 的登记差异。不会因主模型目录覆盖完整，就称来源、运行和业务已全部闭合。
