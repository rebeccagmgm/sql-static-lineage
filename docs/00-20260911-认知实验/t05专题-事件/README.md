# T05 学习入口：发生了什么，怎样留下记录

整理日期：2026-09-14。**T05 围绕业务的发生、办理、变化和执行留下记录。理解它，关键是分清“一件业务”和“这件业务产生的多种记录”。**

例如一份互换合约可以有存续变动、结构化腿明细、收付单、结算通知和保证金台账。它们各自回答不同问题，不能把行数相加当交易次数，也不能把同名的金额直接相加。

本专题参照 T01 的对象推导与完整案例，以及 T03 的分维度阅读方式。从原始元数据、平台分类、码值、任务 SQL 和本地 Wiki 镜像重建内容；TIT/OIS 是重点分支，其余主要业务也有模型与加工说明。T04 的整理在另一个任务中，本目录仅说明与内部机构编号的连接边界。
