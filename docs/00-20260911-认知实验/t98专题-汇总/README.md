# T98：全域盘点与使用地图

整理日期：2026-09-14。**这一版先解决“有哪些表、各自用来做什么、从哪里继续查证”。** 全域指本次已取得的 T98 前缀目录范围，不代表平台全部正式在用资产。

T98 的共同点是把数据组织成某种使用者需要的结果。这个结果可能是员工资料宽表、客户销售明细、合约估值、奖励分配，也可能是指标配置和技术统计。**先看一行代表什么，再看表有多宽、名字是否含 SUM。**

## 建议从这里读

1. [全貌与盘点边界](00-全貌与盘点边界.md)：认识范围、数量口径和 T98 的不同形态。
2. [业务用途与找表路线](01-业务用途与找表路线.md)：从问题进入，分清相近表的用途。
3. [来源、消费与关联规则](02-来源消费与关联规则.md)：区分目录、SQL、组合配置和存量图谱分别能证明什么。
4. [差异与待核问题](03-差异与待核问题.md)：集中看注释错配、目录差异、粒度和时间风险。
