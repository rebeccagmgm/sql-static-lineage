# 对照图映射

所有图使用同一静态 HTML/SVG 画布、同一字体、同一颜色与线型：青绿色实线表示确认，琥珀色虚线表示候选，灰色虚线表示未知或 gap。A/B 每对图的来源、字段、深度和状态固定不变。

| 案例  | 比较问题             | 主字段                       | A/B 差异               | 支持的判断                 |
| ----- | -------------------- | ---------------------------- | ---------------------- | -------------------------- |
| S1/S2 | 动态多写是否应拆卡   | agt_id、agt_modifr、end_date | B 也不拆               | writeId 不足以成为拆卡依据 |
| S3    | 简单路径是否被复杂化 | key_leg_id、quantity、value  | 仅范围标签位置不同     | 单路径优先最少节点         |
| S4    | 四个明确成员如何读   | init_nom_prin 等             | 一卡四边 vs 四张范围卡 | 明确成员可按需展开         |
| S5    | 多来源是否共同参与   | dyna_nom_prin                | 集合标签 vs 四卡汇入   | 不强迫单选                 |
| S6    | 单个确认成员如何读   | init_nom_prin                | 边标签 vs 范围卡       | B 对聚焦范围更直接         |
| S7    | 单一候选是否会被误读 | init_nom_prin                | 两版均保留虚线         | 范围卡不改变证据状态       |
| S8    | 多字段分支是否清楚   | index_val、grp_id、status    | B 增加范围摘要但不硬拆 | 控制关系不混入值来源       |
| S9    | 多跳与 gap 能否并存  | actl_idx_val、rpt_date       | B 显示异构范围仍不硬拆 | 可达性不等于完整证明       |
