- 86840、86841、86842、220650 写同一表的 `grp_id=01/02/03/04`；103457 的日期限定读会同时接续四个确认来源。

## 设计判断

- 物理表保持一个资产锚点。
- 动态或未知范围不因 `writeId` 拆卡；写发生差异留在关系与证据层。
- 明确、可比较且当前问题确需区分的范围，可以在路径视图中展开子卡。
- 多个匹配成员可以同时参与；不强迫单选。
- 字段值来源与 JOIN/FILTER 等控制关系继续分开。
