# 主键与码表：先确定被检查的粒度和允许值

[质量检查总览](quality-check-families.md) · [逐任务证据](../evidence/quality-review.json)

本页解释 129 项主键相关规则与 205 项码表规则。它们主要约束“标识怎样重复”和“代码能否识别”，不是全字段完整性或业务内容正确性检查。

<a id="quality-key-groups"></a>
## 分组重复：检查的是 GROUP BY，而不是名称里的“主键”

124 项使用 `GROUP BY … HAVING COUNT(*)>1` 或等价的 `COUNT(1)>1`。其中 121 项是单查询模板，68345 和 104883 有生效的 `UNION ALL` 分支，112286 有已经注释掉的第二分支。通常最多返回一组重复键；226105、68345、104883 没有 `LIMIT 1`，可返回多组。

例如 49548 按 `Pty_Id` 检查当事人，51088 按 `Role_Id` 检查角色；这两份查询没有日期或删除标志过滤。53405 则只取计算日个人表再按 `Pty_Id` 分组；65606 对用户表仅取 `del_flag='0'`。一个任务有日期范围，不意味着同类任务都有。

不同业务对象实际采用的粒度包括：

| 对象与例子 | 实际分组粒度 | 含义与边界 |
|---|---|---|
| 名称 53767；协议名称历史 55220 | `Pty_Id,Pty_Cate_Cd`；`Agt_Id,Agt_Modifr,Strt_Date` | 名称类型或版本开始日是否属于键，会改变重复定义 |
| 互换损益 112290/112293 | 簿记名、协议编号及修饰符、内部合约号、标的、标的币种、结算币种 | 不是仅按合约一行；不能将多币种/多标的误当成重复 |
| 持仓 112298 与 112300 | 两者均含持仓、协议、腿、多空及源产品，112300 还按交易市场分组 | 同表检查可以采用不同键，不能相互替代 |
| 履保参数 112295 与 112296 | 一份以合约为首，一份额外引入组合编号；均包含履保类型与保证金账户 | 组合级与合约级不是同一种粒度 |
| 子交易障碍/区间/观察日属性 173281/173297/173294 | 合约、修饰符、产品，加序号或观察日属性及观察日 | 序号/观察属性是实际检查的一部分 |
| 分配日报 113728/121244/237712 | 计算日内的 `agt_id,accrued_date` | 分别落在销售、内部销售、收入日报；不检查分配金额守恒 |
| 系统功能 242471；映射规则 185828 | `sys_id,func_id`；源簿记、目标簿记、选取字段、操作、条件 | 配置对象采用复合键，不能仅用功能编号或簿记编号判断 |

按日检查、全表检查和有效期切片不能混读。72963、129757 取 `strt_date<=D AND end_date>D`；209292 取最近 2 日下界，210289 取最近一个月下界，220885 取最近 30 日下界，这几份都没有另加 `<=D` 上界。186236 的日期过滤被注释，实际按全表 `src_hold_id,busi_date` 分组。204256 实际读取 `spdata_n` 中的主体关系，不能改称同名 `pdata_n` 表。

### 来源例外会改变键

55558/68346 排除了多种需要扩大联合键的来源；68345 对特定来源把 `RELA_AGT_ID` 加入键，另一分支再加 `Rela_Agt_Modifr`。这些任务相互补充，但不应因名称近似就假设其来源集合完全一致。

104883 对普通字典按 `DW_CD_ID,DW_CD_VAL` 检查；对 SQL 列出的 24 个多系统字典，增加 `remark`。字典值跨来源重复在后一分支可能是允许的。55220 的来源过滤只有注释、没有生效，不能把注释内容当作当前豁免。

112286 只检查当日 `src_tbl='ODATA_N_TIT.D_REF_TRS'` 的互换标的行。为其他来源加入 `Undrl_Bngn_Vol` 的分支被整段注释，当前查询没有检查那个分支。128530 排除 `D_KS_CONTRACT_INFO`，133855 同表查询没有这项排除；128802 与 128808 同样在来源排除上不同。172917 排除具有多个英文名称的一个来源，而53767没有这一排除。

主键检查不会要求单个键列非空：单条 NULL 键通常不因 `COUNT>1` 被检出，多条 NULL 可能聚到同一组。它也不会验证键的业务归属、另一张表是否存在对应对象或每行金额是否准确。

<a id="quality-key-difference"></a>
## 重复行差值：返回 0 的含义变了

209840、209856、210262、210279、242508 使用：

```sql
abs(count(*) - count(distinct <key columns>)) as result_value
```

对应键分别是付款计划 `evt_id`、合约文件的协议编号与修饰符、期权协议编号与修饰符、组合编号，以及系统/功能/菜单三列。210262 有计算日过滤，其余四份是全表。

这里 `0` 表示总行数与去重键计数相同；正数是计数差，不是异常组数，也不是标准 `check_result=1` 协议。`COUNT(DISTINCT …)` 对 NULL，尤其多列 NULL 的处理依赖方言；差值可能同时受到空键影响，不能不加区分地标为纯重复行数。多列 DISTINCT 是否受当前执行引擎支持也应由执行环境确认。

<a id="quality-dictionary-all"></a>
## 码表检查：205 项都在找指定字典无法接收的值

共同结构是先用 `NOT EXISTS` 找不到对应 `REF_DW_CD_VAL` 的被查值，再由外层 `COUNT(1)>0` 返回 `0`，否则返回 `1`。这里字典编号、被查列、字典来源限定和外层豁免都是规则本身，不是装饰参数。

| 字段含义族 | 实际字典示例 | 被检查对象举例 |
|---|---|---|
| 人员与客户身份 | 性别 CD003、婚姻 CD004、学历 CD007、国籍 CD010、职业 CD023 | 个人、客户和重要联系人 |
| 合约、交易、资金状态 | 合约状态 CD041、资金变化 CD397、事件状态 CD758、触发变化 CD1473 | 期权/互换、日持仓、资金与保证金事件 |
| 币种、方向、市场与计息 | 币种 CD035、市场 CD042、收付 CD708、计息基准 CD420、频率 CD516 | 远期、互换主表与腿、估值、资金账户 |
| 期权结构 | 障碍类型 CD1103、障碍条件 CD722、估值类型 CD1317 | 子交易障碍、区间、估值指标 |
| 履保方案 | CD1692–CD1697，加履保模式、盯市、费用模式等各自字典 | 客户履保方案的状态、属性和范围 |
| 组织、权限和配置 | 角色类型 CD495、角色类别 CD496、菜单状态 CD1419、功能状态 CD2154 | 角色、用户、权限、系统功能、产品池与指标配置 |

**没有“所有码表都排除空值”的统一事实。** 大多数规则用 `NVL(TRIM(x),'')<>''`、`TRIM(NVL(x,''))<>''` 或 `x<>''` 把空值排除；最后一种仍会因为 NULL 比较为未知而不选中 NULL，但对空格的处理不同。53410/172935 还排除性别默认值 `9`；学历53424/64921还要求未删除并排除 `0/9`；职业53448/65637排除两种来源。通过这些规则，不能证明被豁免的值已经填写正确。

另一些查询没有空值豁免：173247、173252、173256、173300、173360、173446、200638，以及按异常码分组的204035。它们的 `NOT EXISTS` 会把 NULL 当作无法用普通等号匹配的值选入异常；空串是否能匹配，要看字典中实际是否有该值。因此它们不能与“非空值域检查”统一描述。

### 不能省略的模板差异

- **逗号多值先拆分。** 68853 把协议市场代码拆成元素，并对匹配值 `TRIM`；161109、188820 拆分角色类型，但字典等号比较没有 `TRIM`，仅在空值过滤中使用 `TRIM`。带空格的合法码在后一实现中仍可能匹配失败。这几份检查的是拆分后的元素，不是整个字符串。
- **字典自身也有限定范围。** 163335/163339、186251、209808、242466/242476/242478 等限定字典 `src_tbl='MANU_MATN'`。242482/242485 接受指定的三种字典来源，242486 只取一种，242488 取两种；这与检查全字典不是一回事。
- **`remark` 用来缩小业务域。** 173362/173363 限定包含 TITANS 的产品字典项；188708/210270 限定投资期限特定 `remark`，226384 虽检查同类期限代码却未加该限制。找到同码的其他字典记录不一定满足这些规则。
- **历史窗不同。** 163368 为最近15日下界，188736 为当月月初下界，210290等为最近一月，226364/226365/226384为最近7日，220884为最近30日；不能解释成均只检查当天。
- **特定值有明确豁免。** 指标业务分类190763、日历类型190774、联系人类别188606、系统功能业务类型/属性242482/242485、访问级别242488均列有额外豁免。53425/64920保留源文本中的特殊民族值豁免；本文不擅自修正其编码。
- **异常参数保持原样。** 65191 的日期占位符是 `${yyy-MM-dd}`，不同于通常四位年份写法；235789 的字典编号是数字字符串 `124564`，而相邻结算速度任务使用 CD590。仅凭静态文本不能确认占位符的实际展开或字典编号是否配置正确，这两项已记录为待核实。

码表命中只证明该值在本次查询选用的字典集合中存在；不证明它是该合约应选的状态，也不验证代码转换与中文含义在所有下游都一致。实际使用哪张表、哪列和哪个字典，逐项摘要及原 SQL 引用保留在[账本](../evidence/quality-review.json)。
