# 背景

  
按《广发证券信息技术部信息系统重要性级别规范》部门规范要求，titans系统交易部分与客户交易直接相关，应纳入T1级别进行管理。

  
# 本方案目标

* 确认TITANS系统中 与交易相关的最小关键功能集合包括哪些；
* 确认T1服务每次升级前必须回归的关键功能集；
* 厘清T1服务对T2服务的依赖关系，以及确定初步的解决方案；
* 梳理运维部署保障措施，以及补充说明升级流程的注意事项；
* 进度要求：6月底前完成升T1

# 发版流程规范

在现有的发版流程规范上，补充以下措施：

  
(一）升级后验证措施

1、技术验证：每次升级后，相关服务对应的开发负责人，及时验证应用程序是否正常，并反馈。

2、业务验证：目前已有业务生产验证机制。每次开发迭代，项目组各方根据实际情况商定是否进行业务生产验证。
  
  
(二）qc测试流程中，发起上下游变更确认，有利于防范数据、变更对下游的影响。
