## 成果形式

用户最新明确：成果可以是一整个知识库集合，不要求是一篇文章。

正文以相互引用的 Markdown 主题页面保存，建立总览、业务过程、对象与口径、典型问题及证据等阅读入口。每页讲清自己的问题，跨页统一术语、对象和口径；读者既能顺着全貌学习，也能从具体问题进入。可生成本地 HTML 阅读入口，但不以单篇文章、单个 HTML 或固定页面数量约束内容。

“完整”指范围和知识的完整，不以文档数量、目录覆盖率或页面生成成功替代。范围底账、审阅记录与可重现取证脚本为支持材料，不计为业务知识已交付。
