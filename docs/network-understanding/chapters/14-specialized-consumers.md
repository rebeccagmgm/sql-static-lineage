# 专业消费者怎样使用共享业务事实

同一组合约、证券、客户与组织数据，会被不同专业消费者重新组织。这一章从消费用途进入：每个主题都要说明用了哪些共享事实，又加了哪些筛选、映射、计量或接口规则。

<a id="specialized-treasury"></a>

## 资金部：资产、融资和组合履保

[资金部使用股衍数据](../topics/treasury-management.md)完整说明当前 `DM_FMS_N` 14 项，贯通六类加工、对应导出与回执。阅读重点是名义本金与持仓市值、原币与折港币、回购自然日期限、利率缩放、合约与腿的粒度，以及参数业务日与运行时昨天的区别。
